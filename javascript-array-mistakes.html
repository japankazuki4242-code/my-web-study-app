配列で間違えやすいポイント

1番目の要素はindex 0 
const fruits = ["りんご", "みかん", "バナナ"];

人間が数える1番目の要素は「りんご」です。JavaScriptでは、最初の要素をindex 0で指定します。

fruits[0]

fruits[1]ではなく、fruits[0]が1番目の要素です。

lengthと最後のindexは違う 
const fruits = ["りんご", "みかん", "バナナ"];

fruits.length
→ 3

最後のindex
→ 2

lengthは要素の個数、indexは0から始まる位置の番号です。そのため、同じ数字にはなりません。

存在しないindexはundefined

3つの要素がある配列では、使われているindexは0・1・2です。

console.log(fruits[3]);

index 3には値が存在しないため、実行結果はundefinedになります。

undefined
index 0から配列を繰り返すときは「より小さい」を使う

正しい条件

i < fruits.length

fruits.lengthが3の場合、iが0・1・2の間だけ繰り返します。

間違えやすい条件

i <= fruits.length

<=は「以下」という意味です。この条件ではiが3のときも繰り返すため、存在しないfruits[3]まで処理しようとしてしまいます。

確認問題 
["A", "B", "C"]

① 1番目の要素のindexはいくつですか？

② lengthはいくつですか？

③ 最後のindexはいくつですか？

確認問題の答え

① 1番目の要素のindex
→ 0

② length
→ 3

③ 最後のindex
→ 2

「最初のindexは0」「lengthは要素数」「最後のindexはlengthより1小さい」と整理しましょう。
