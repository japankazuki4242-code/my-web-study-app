コールバック関数とは？

コールバック関数は、別の関数へ渡される関数です。

JavaScriptでは、文字列や数値と同じように、関数も値として渡すことができます。

渡された関数は、受け取った側の関数が必要な場所で実行します。

まずは「関数そのものを渡し、受け取った場所で実行する仕組み」と考えましょう。

小さなコード例 
function call(callback) {
  callback();
}

function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

call関数は、仮引数callbackで関数を受け取ります。

printMessage関数をcall関数へ渡すと、callback()によってprintMessageの処理が実行されます。

関数も値のように扱える

関数は、別の関数を呼び出すときの引数にできます。

call(printMessage);

このprintMessageは、表示結果ではなく関数そのものです。

()を付けていないため、この行でprintMessageの中の処理を直接実行しているわけではありません。

call関数へ、あとで実行してもらう関数を値として渡しています。

関数名と関数名()の復習

printMessage
→ 関数そのものを表す

printMessage()
→ 関数をその場で実行する

コールバックとして渡すときは、基本的にcall(printMessage);のように()を付けません。

以前学習した「関数名と関数名()の違い」が、コールバック関数を読むときにも大切です。

コードを小さく分けて読む 
function call(callback) {
  callback();
}

function call(callback)
→ call関数を定義し、仮引数callbackで値を受け取る

callback();
→ callbackに入っている関数を実行する

function printMessage() {
  console.log("こんにちは");
}

→ 渡すためのprintMessage関数を定義する。この時点では中の処理は実行しない

call(printMessage);

→ printMessage関数そのものをcall関数へ渡す

実行の流れ

① call関数を定義する
→ 定義しただけなので、中の処理はまだ実行しない

② printMessage関数を定義する
→ ここでも、中の処理はまだ実行しない

③ call(printMessage);を実行する
→ printMessage関数そのものがcallbackへ渡る

④ callback();を実行する
→ callbackに入っているprintMessage関数が実行される

⑤ コンソールに「こんにちは」と表示される

確認問題 
function run(callback) {
  callback();
}

function showMessage() {
  console.log("学習中");
}

run(showMessage);

① コールバック関数として渡されている関数は何ですか？

② showMessageに()を付けずに渡しているのはなぜですか？

③ コンソールには何と表示されますか？

確認問題の答え

① showMessage関数です。

② その場で実行せず、関数そのものをrun関数へ渡すためです。

③ 学習中と表示されます。

showMessageがcallbackへ渡り、callback()で実行されます。

今回の学習ポイント

コールバック関数は、別の関数へ渡される関数です。

関数そのものを渡すときは、基本的に関数名へ()を付けません。

受け取った側では、callback()のように()を付けて関数を実行します。
