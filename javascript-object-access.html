オブジェクトから値を取り出す

今回使うオブジェクト 
const user = {
  name: "かず",
  age: 50
};

userオブジェクトは、nameとageというプロパティを持っています。

nameの値を取り出す

userオブジェクトのnameプロパティを見るときは、次のように書きます。

console.log(user.name);

実行結果は次のとおりです。

かず

user.nameによって、nameプロパティの値である「かず」を取り出しています。

user.nameを分けて読む
書き方 意味
user 値を取り出したいオブジェクト
. userが持っているものへアクセスする
name 値を取り出したいプロパティ名

user.nameは、「userオブジェクトのnameプロパティを見る」と読みます。

ageの値を取り出す

ageプロパティも、同じように取り出せます。

console.log(user.age);

実行結果は次のとおりです。

50

user.ageは、「userオブジェクトのageプロパティを見る」と読みます。

オブジェクト名.プロパティ名

オブジェクトから値を取り出す基本の形は、次のとおりです。

オブジェクト名.プロパティ名

.の左側にオブジェクト名、右側に見たいプロパティ名を書きます。

console.log()は、ここでは取り出した値をコンソールへ表示して確認するために使っています。メソッドの詳しい説明は、後の教材で学びます。

今回の学習ポイント

user.name
→ userのnameプロパティの値

user.age
→ userのageプロパティの値

「オブジェクト名、ドット、プロパティ名」の順番で読むことを覚えましょう。
