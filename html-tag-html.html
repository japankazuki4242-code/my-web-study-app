<html>

何をするタグ？

HTML文書全体を囲む、一番外側のタグです。
<head> と <body> を中に入れます。

基本の書き方 
<html>
  <head>
  </head>

  <body>
  </body>
</html>
属性名・属性値の例 
<html lang="ja">

lang は、このページで使う言語を指定する属性です。
"ja" は日本語を表します。

よく使う場面

HTMLファイルを作るときに、文書全体を囲むために使います。

実際に使った例 
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
    <meta
      name="description"
      content="HTML・CSS・JavaScriptを学習するためのWebアプリです。"
    >
    <link rel="stylesheet" href="styles.css">
    <title>Web学習アプリ</title>
  </head>

  <body>
    <h1>Web学習アプリ</h1>
  </body>
</html>
