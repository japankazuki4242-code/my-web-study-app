画像

width: 100% 
img {
  width: 100%;
}

画像を、基準となる親要素の幅いっぱいに広げます。必ず画面全体の幅になるわけではありません。

max-width: 100% 
img {
  max-width: 100%;
}

画像の横幅が、基準となる幅の100%を超えないようにします。小さい画像を必ず100%まで広げる指定ではありません。

height: auto 
img {
  max-width: 100%;
  height: auto;
}

height: auto;は、変更した横幅に合わせて高さを自動計算します。画像の縦横比を保ちやすくなります。

width と max-width の違い

width: 100%;
→ 基準幅いっぱいへ広げる

max-width: 100%;
→ 基準幅の100%を上限にする

元の画像サイズや、どこまで広げたいかを考えて使い分けます。

HTMLのwidth / height属性との違い 
<img
  src="photo.jpg"
  alt="写真"
  width="800"
  height="600"
>

HTMLのwidth・height属性は、画像の寸法情報をHTMLに持たせます。

CSSのwidth・heightは、画面上での表示サイズを調整します。

背景画像との違い

<img>
→ HTMLの内容として意味のある画像に使う

background-image
→ 要素の背景やデザインとして画像を使う

「写真だからimg」「大きいからbackground-image」という単純な決まりではありません。その画像がページ内容なのか、背景としての装飾なのかを考えます。

実際に使った例

Black CoffeeのファーストビューはHTMLの画像として配置し、親要素の幅いっぱいに表示しています。

<figure>
  <img src="images/top.jpg" alt="カフェの店内">
</figure>
main .hero figure img {
  width: 100%;
}

kazuki_HP_practice2のファーストビューはCSSの背景画像です。

.fv {
  background-image: url("./img/fv 1.jpg");
  background-size: cover;
  background-position: center;
}

同じ作品の通常の画像には、はみ出しを防ぎながら縦横比を保つ指定があります。

img {
  max-width: 100%;
  height: auto;
}
