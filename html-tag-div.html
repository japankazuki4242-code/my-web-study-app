<div>

何をするタグ？

<div>は、複数のHTML要素をひとまとまりにするためのタグです。

<div>自体には、<header>や<section>のような特別な意味はなく、主にCSSでレイアウトや見た目を指定するためのグループ分けに使います。

<section>は、テーマや内容として意味のあるまとまりに使います。

<div>は、意味を持たせず、レイアウトやデザインのために要素をまとめたいときに使います。

基本の書き方 
<div>
  <h2>おすすめメニュー</h2>
  <p>人気のコーヒーを紹介します。</p>
</div>

<div>の中に、見出し・文章・画像・リンクなどのHTML要素を入れて、1つのまとまりにすることができます。

<div class="container">
  <h2>おすすめメニュー</h2>
  <p>人気のコーヒーを紹介します。</p>
</div>

実際のWeb制作では、<div>にclassを付けて、CSSからそのまとまりの幅・余白・配置などを指定することがよくあります。

HTML：

<div class="container">

CSS：

.container {
  max-width: 1000px;
  margin: 0 auto;
}

<div>
→ HTML要素をまとめる箱

class="container"
→ その箱に名前を付ける

.container
→ CSSから、そのclass名を持つ箱を指定する

属性名・属性値の例 
<div class="container">

属性名：class
属性値：container

classを付けることで、CSSやJavaScriptからこの<div>を指定できます。

CSSでの指定例：

.container {
  max-width: 1000px;
  margin: 0 auto;
}

HTMLではclass="container"と書きますが、CSSでclassを指定するときは、class名の前に「.（ドット）」を付けて.containerと書きます。

「.（ドット）」は、CSSでclassを指定するときに必要です。

HTML
class="container"
       ↓
CSS
.container

containerは、HTMLで決められた特別な名前ではなく、自分で付けるclass名です。

Web制作では、コンテンツの最大幅や中央配置、左右の余白などを整えるためのまとまりにcontainerというclass名がよく使われます。

div
→ タグ（要素）を指定する

.container
→ classを指定する

#header
→ idを指定する

よく使う場面

<div>は、レイアウトやデザインのためにHTML要素をまとめたいときによく使います。

  • 複数の要素を1つのグループにまとめる
  • .containerを作ってコンテンツの横幅を整える
  • 画像と文章をひとまとまりにする
  • Flexboxで横並びにしたい要素をまとめる
  • CSSで背景色・余白・配置などを指定するための箱を作る

<div>は便利なのでよく使いますが、何でも<div>で囲めばよいわけではありません。

<header>・<nav>・<main>・<section>・<article>・<footer>など、内容に合った意味を持つHTMLタグがある場合は、そちらを使うことも検討します。

意味のある内容のまとまり
→ <section>や<article>など

レイアウトやグループ分けのための箱
→ <div>

実際に使った例

実際に作成したBlack Coffeeとkazuki_HP_practice2の例を元に、<div>の2種類の使い方を比較します。

実例1：Black Coffee

Black Coffeeでは、<div class="container">をコンテンツの横幅や中央配置を整えるための箱として使用しています。

<section class="about">
  <div class="container">
    <h2>ABOUT</h2>
    <p>お店についての説明</p>
  </div>
</section>

CSS例：

.container {
  width: 100%;
  max-width: 700px;
  margin: 0 auto;
}

<div class="container">
→ 中のコンテンツを1つにまとめる箱

.container
→ CSSからこの箱を指定する

width: 100%;
→ 利用できる横幅いっぱいまで広がる

max-width: 700px;
→ 横幅が700pxより広がりすぎないようにする

margin: 0 auto;
→ 左右の余白を自動にして中央に配置する

Black Coffeeでは、about・menu・asideなどの中で.containerを使用し、中のコンテンツの横幅を整えています。

実例2：kazuki_HP_practice2

kazuki_HP_practice2では、<div>を画像側・文章側などに分けて、レイアウトのための箱として使用しています。

<div class="feature-box">
  <div class="img-area">
    <figure>
      <img src="./img/sample.jpg" alt="画像">
    </figure>
  </div>

  <div class="text-area">
    <h3>タイトル</h3>
    <p>説明文</p>
  </div>
</div>

CSS例：

.feature-box {
  display: flex;
  justify-content: space-between;
}

.feature-box
→ 画像側と文章側をまとめる親の箱

.img-area
→ 画像をまとめる子の箱

.text-area
→ 文章をまとめる子の箱

display: flex;
→ 子要素を横並びにする

justify-content: space-between;
→ 子要素の間にスペースを作って配置する

比較

Black Coffee
→ .containerとして、横幅や中央配置を整えるための<div>

kazuki_HP_practice2
→ .feature-box・.img-area・.text-areaとして、レイアウトやグループ分けのために使う<div>

<div>は便利ですが、意味のあるまとまりなら<section>や<article>などを使い、レイアウトやグループ分けが目的なら<div>を使う、と考えると分かりやすいです。
