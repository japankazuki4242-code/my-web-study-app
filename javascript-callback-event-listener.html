addEventListener()とコールバック

このアプリで使っているコード

このアプリのscript.jsでは、BACKボタンに次のコードを使っています。

backButton.addEventListener("click", function () {
  history.back();
});

このコードは、「BACKボタンがクリックされたときに、前のページへ戻る処理を実行する」と登録しています。

クリックされるまでは、function () { ... }の中の処理を実行しません。

backButtonを読む 
backButton

backButtonには、このページ下部のBACKボタンを表すHTML要素が入っています。

コードの先頭にあるため、「どの要素へイベントを登録するのか」を表しています。

ここでは、BACKボタンに対してクリック時の処理を登録します。

ここでは「クリックされたとき」という意味です。

"click"の後ろにあるカンマ,で、次に渡すコールバック関数と区切っています。

function () { ... }がコールバック 
function () {
  history.back();
}

この部分が、addEventListener()へ渡しているコールバック関数です。

関数名がないため、無名関数でもあります。

「BACKボタンがクリックされたときに、この関数を実行してね」と、関数そのものを渡しています。

history.back()の詳しい仕組みより、今はこの関数がクリック後に実行されることを確認しましょう。

イベントから実行までの流れ

① ページの読み込み時に、BACKボタンへclickイベントの処理を登録する

② function () { ... }をコールバック関数として渡す
→ 登録しただけなので、history.back()はまだ実行しない

③ ユーザーがBACKボタンをクリックする

④ clickイベントが起きる

⑤ 登録していたコールバック関数を実行する

⑥ コールバック関数の中にあるhistory.back();を実行する

これは、以前学習した「イベント」と「関数・メソッド」がつながっている実例です。

確認問題 
saveButton.addEventListener("click", function () {
  console.log("保存");
});

① イベントを登録するHTML要素を表しているのはどの部分ですか？

② イベント名は何ですか？

③ コールバック関数はどの部分ですか？

④ 「保存」はいつ表示されますか？

確認問題の答え

① saveButtonです。

② "click"です。

③ function () { console.log("保存"); }の部分です。

④ saveButtonがクリックされ、登録したコールバック関数が実行されたときです。

今回の学習ポイント

addEventListener()には、イベント名とコールバック関数を渡します。

function () { ... }は、「クリックされたときに実行する関数」として渡されています。

登録した時点では中の処理を実行せず、指定したイベントが起きたときに実行します。
