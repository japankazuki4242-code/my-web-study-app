要素数を調べる length

今回使う配列

このページでは、3つの果物が入った次の配列を使います。

const fruits = ["りんご", "みかん", "バナナ"];

配列の中には、「りんご」「みかん」「バナナ」という3つの要素があります。

lengthとは？

lengthは、配列に入っている要素の数を表します。

const fruits = ["りんご", "みかん", "バナナ"];

console.log(fruits.length);

実行結果は次のとおりです。

3

この配列には要素が3つあるため、fruits.lengthは3になります。

fruits.lengthを分けて読む
書き方 意味
fruits 要素数を調べる配列
. fruitsが持っている情報へアクセスする
length 要素数を表すプロパティ

fruits.lengthは、「fruitsが持っている要素数を見る」と読むことができます。

indexとlengthの数え方

indexは、配列の最初の要素を0として数えます。

"りんご"
→ index 0

"みかん"
→ index 1

"バナナ"
→ index 2

lengthは、要素の個数を普通に1つ、2つ、3つと数えます。そのため、この配列のlengthは3です。

lengthは最後のindexではない 
const fruits = ["りんご", "みかん", "バナナ"];

最後のindex
→ 2

length
→ 3

lengthは「最後のindex番号」ではなく、「配列に入っている要素の個数」です。

プロパティという言葉

lengthのように、配列が持っている情報を「プロパティ」と呼びます。

ここでは、lengthは要素数を表すプロパティだと覚えれば十分です。プロパティについては、後のオブジェクト教材で詳しく学びます。
