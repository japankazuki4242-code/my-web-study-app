forEach・find・filter・mapを比べる

4つのメソッドを比べる
メソッド 主な目的
forEach() 要素を1つずつ処理する
find() 条件に合う最初の1つを取得する
filter() 条件に合うものをすべて集め、新しい配列を作る
map() すべての要素を変換し、新しい配列を作る

何をしたいかによって、選ぶ配列メソッドが変わります。

同じ配列で確認する 
const numbers = [10, 20, 30];

この同じ配列を使って、4つのメソッドの違いを確認します。

それぞれの例は、「1つずつ表示する」「最初の1つを探す」「すべて選ぶ」「すべて変換する」という違う目的を持っています。

forEach()は1つずつ処理 
numbers.forEach(function (number) {
  console.log(number);
});

10、20、30を順番に表示します。

主な目的は、各要素に対して処理を実行することです。

find()は最初の1つを取得 
const found = numbers.find(function (number) {
  return number >= 20;
});

20以上の最初の要素である20を取得します。

条件に合う30もありますが、find()の結果は最初の1つだけです。

filter()はすべて集める 
const filtered = numbers.filter(function (number) {
  return number >= 20;
});

20以上の要素をすべて集め、[20, 30]という新しい配列を作ります。

filter()自体は、元のnumbers配列を変更しません。

map()はすべて変換 
const doubled = numbers.map(function (number) {
  return number * 2;
});

すべての要素を2倍し、[20, 40, 60]という新しい配列を作ります。

map()自体は、元のnumbers配列を変更しません。

目的からメソッドを選ぶ

各要素を表示したい
→ forEach()

条件に合う最初の要素が欲しい
→ find()

条件に合う要素をすべて集めたい
→ filter()

すべての要素から新しい値を作りたい
→ map()

まず「最終的に何が欲しいか」を考えると、メソッドを選びやすくなります。

実行順と処理の流れを比べる

4つとも、配列の要素を先頭からコールバック関数へ渡します。

forEach()
→ 各要素に処理を行う

find()
→ 条件が最初にtrueになった要素を結果にする

filter()
→ 条件がtrueになった要素をすべて集める

map()
→ 各要素からreturnされた値をすべて集める

確認問題

① 配列の要素を1つずつコンソールへ表示したいときは、どのメソッドを使いますか？

② 条件に合う最初の1つだけを取得したいときは、どのメソッドを使いますか？

③ 条件に合う要素をすべて集めたいときは、どのメソッドを使いますか？

④ すべての要素を2倍した新しい配列を作りたいときは、どのメソッドを使いますか？

確認問題の答え

① forEach()です。

② find()です。

③ filter()です。

④ map()です。

今回の学習ポイント

forEach()・find()・filter()・map()は、目的がそれぞれ違います。

コードを書く前に、「処理したい」「最初の1つが欲しい」「すべて選びたい」「変換したい」のどれかを確認しましょう。

今は基本的な役割を使い分けられれば大丈夫です。
