forEach() - 1つずつ処理

forEach()とは？

forEach()は、配列の要素を先頭から1つずつ取り出して処理するメソッドです。

「それぞれの要素に対して、この処理を行う」と考えると読みやすくなります。

各要素に行う処理は、コールバック関数としてforEach()へ渡します。

基本コード 
const fruits = ["りんご", "みかん", "バナナ"];

fruits.forEach(function (fruit) {
  console.log(fruit);
});

fruits配列から要素が1つずつ取り出され、仮引数fruitへ渡されます。

コールバック関数が要素の数だけ実行され、それぞれの値を表示します。

コードを小さく分けて読む

fruits
→ 処理する配列

.
→ 配列が持つメソッドへアクセスする

forEach
→ メソッド名

()
→ forEachメソッドを実行する

function (fruit) { ... }
→ forEach()へ渡しているコールバック関数

fruit
→ 配列から1つずつ渡される要素を受け取る仮引数

コールバック関数とのつながり 
function (fruit) {
  console.log(fruit);
}

これは、forEach()へ渡している無名のコールバック関数の部分です。

forEach()は配列の要素を1つ取り出すたびに、この関数を実行します。

fruitには、現在取り出している要素が入ります。

実行順を追う

① 「りんご」
↓
仮引数fruitへ渡る
↓
console.log(fruit);で表示する

② 「みかん」
↓
仮引数fruitへ渡る
↓
console.log(fruit);で表示する

③ 「バナナ」
↓
仮引数fruitへ渡る
↓
console.log(fruit);で表示する

配列の先頭から末尾まで、同じコールバック関数が1要素につき1回実行されます。

実行結果 
りんご
みかん
バナナ

配列の3つの要素が、先頭から順番に表示されます。

for文との簡単な違い

for文では、変数iやfruits.lengthを使って繰り返す範囲を自分で書きました。

forEach()では、配列の要素を1つずつ処理する流れがメソッドに用意されています。

今回は、配列の全要素へ同じ処理を行いたいときにforEach()を使う、と覚えれば大丈夫です。

確認問題 
const numbers = [10, 20, 30];

numbers.forEach(function (number) {
  console.log(number);
});

① 配列名は何ですか？

② コールバック関数はどの部分ですか？

③ 仮引数numberには、どの値がどの順番で渡りますか？

④ コンソールには何が表示されますか？

確認問題の答え

① numbersです。

② function (number) { console.log(number); }の部分です。

③ 10、20、30の順に渡ります。

④ 10、20、30が順番に表示されます。

今回の学習ポイント

forEach()は、配列の要素を先頭から1つずつ処理します。

処理はコールバック関数として渡し、仮引数が現在の要素を受け取ります。

コードは「配列 → forEach() → コールバック関数 → 仮引数」のつながりで読みましょう。
