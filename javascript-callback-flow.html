コールバックの実行順を追う

今回読むコード 
function run(callback) {
  console.log("A");
  callback();
  console.log("C");
}

function showMessage() {
  console.log("B");
}

run(showMessage);

このコードでは、showMessage関数をコールバック関数としてrun関数へ渡します。

コードの定義と実行を分けながら、上から順番に追いましょう。

実行結果 
A
B
C

最初にrun関数の中で「A」を表示します。

次に、callback()によってshowMessage関数を実行し、「B」を表示します。

showMessage関数の処理が終わるとrun関数の続きへ戻り、最後に「C」を表示します。

1. run関数を定義する 
function run(callback) {
  console.log("A");
  callback();
  console.log("C");
}

run関数を定義し、実行するときの処理を決めています。

この時点では定義しただけなので、関数の中にある「A」も「C」も表示されません。

callback()もまだ実行されません。

2. showMessage関数を定義する 
function showMessage() {
  console.log("B");
}

showMessage関数を定義し、実行されたときに「B」と表示する処理を決めています。

ここでも定義しただけなので、この時点では「B」は表示されません。

3. run(showMessage)を呼び出す 
run(showMessage);

run関数を呼び出し、showMessage関数そのものを引数として渡します。

showMessageには()がないため、渡す場所ではまだ実行しません。

showMessage関数が、run関数の仮引数callbackへ入ります。

4〜5. Aを表示してcallback()を実行する 
console.log("A");
callback();

④ run関数の先頭から処理を始め、console.log("A");で「A」を表示します。

⑤ 次のcallback();へ進みます。

callbackにはshowMessage関数が入っているため、showMessage()が実行されます。

showMessage関数の中にあるconsole.log("B");によって、「B」を表示します。

6〜7. run関数の続きへ戻る 
console.log("C");

⑥ showMessage関数の処理が終わると、呼び出し元であるrun関数の続きへ戻ります。

⑦ callback();の次にあるconsole.log("C");を実行し、「C」を表示します。

そのため、実行結果は「A → B → C」の順になります。

実行順をまとめる

① run関数を定義する
→ まだ中の処理は実行しない

② showMessage関数を定義する
→ まだ中の処理は実行しない

③ run(showMessage);を呼び出す
→ showMessageがcallbackへ渡る

④ 「A」を表示する

⑤ callback();でshowMessageを実行し、「B」を表示する

⑥ showMessageの処理が終わり、run関数へ戻る

⑦ 「C」を表示する

確認問題 
function start(callback) {
  console.log("1");
  callback();
  console.log("3");
}

function showNumber() {
  console.log("2");
}

start(showNumber);

① 関数を定義しただけの時点で、数字は表示されますか？

② callback()で実行される関数は何ですか？

③ コンソールには、どの順番で数字が表示されますか？

確認問題の答え

① 表示されません。関数は定義しただけでは中の処理を実行しません。

② showNumber関数です。

③ 1、2、3の順です。

「1」を表示したあとにコールバック関数へ移り、「2」を表示します。コールバック関数が終わるとstart関数へ戻り、「3」を表示します。

今回の学習ポイント

関数は定義しただけでは、中の処理を実行しません。

関数名へ()を付けずに書くと、関数そのものを値として扱えます。それを別の関数の引数として書けば、その関数を渡せます。

callback()を実行すると、callbackに入っているコールバック関数が実行されます。その関数の処理が終わると、呼び出し元の続きが実行されます。
