JSON

JSONとは？

JSONはプログラミング言語ではなく、データを決まった形式で表すためのデータ形式です。

JSONは「JavaScript Object Notation」の略です。JavaScriptのオブジェクトと似た書き方で、データを表します。

{
  "name": "かず",
  "skill": "JavaScript"
}

VS Codeのsettings.jsonのように、設定データなどにもJSON形式が使われることがあります。

このページではVS Codeの設定ではなく、JavaScriptの配列・オブジェクトをlocalStorageへ保存するときに使うJSONを学びます。

JSONの基本的な書き方

JSONはJavaScriptのオブジェクトと似ていますが、JSONとしての書き方があります。

{
  "name": "かず",
  "skills": ["HTML", "CSS", "JavaScript"]
}
  • オブジェクト形式は{ }、配列形式は[ ]で囲みます。
  • keyはダブルクォート" "で囲みます。
  • 文字列もダブルクォート" "で囲みます。
  • keyとvalueは:でつなぎます。
  • 複数のデータは,で区切ります。

まずはこの基本的な書き方を覚えれば大丈夫です。

JSON.stringify() - 文字列に変換する

次のskillsは、JavaScriptの配列です。

const skills = ["HTML", "CSS", "JavaScript"];

localStorageはデータを文字列として保存します。そのため、配列やオブジェクトを保存するときは、JSON.stringify()を使って保存できる文字列へ変換します。

const skillsText = JSON.stringify(skills);

skillsの配列をJSON.stringify()へ渡し、変換後のJSON形式の文字列をskillsTextへ入れています。

配列
↓
JSON.stringify()
↓
JSON形式の文字列

JSON.stringify()は、配列・オブジェクトを保存用の文字列へ変換する役割です。

JSON.parse() - 元のデータに戻す

localStorageからgetItem()で読み出した直後のデータは文字列です。

const savedSkills = localStorage.getItem("skills");

const skills = JSON.parse(savedSkills);

savedSkillsには、localStorageから読み出した文字列が入ります。その文字列をJSON.parse()へ渡すと、元のJavaScriptの配列へ戻せます。

localStorageから文字列を読み出す
↓
JSON.parse()
↓
JavaScriptの配列・オブジェクトへ戻す

JSON.stringify()は文字列へ変換し、JSON.parse()は文字列から元のデータへ戻します。2つは逆方向の役割です。

localStorageで配列・オブジェクトを保存する

配列・JSON・localStorageをつなげると、次のように保存と読み出しができます。

const skills = ["HTML", "CSS", "JavaScript"];

const skillsText = JSON.stringify(skills);

localStorage.setItem("skills", skillsText);

const savedSkills = localStorage.getItem("skills");

const restoredSkills = JSON.parse(savedSkills);

skillsは、保存したいJavaScriptの配列です。

skillsTextは、JSON.stringify()で配列を変換した保存用の文字列です。

setItem()は、"skills"というkeyで文字列をlocalStorageへ保存します。

savedSkillsは、getItem()でlocalStorageから読み出した文字列です。

restoredSkillsは、JSON.parse()で文字列から元の配列へ戻したデータです。

配列を作る
↓
JSON.stringify()で文字列へ変換
↓
setItem()で保存
↓
getItem()で読み出す
↓
JSON.parse()で配列へ戻す

このアプリの共通自由メモは、textareaに入力した文字列をそのまま保存しています。そのため、自由メモにはJSON.stringify()とJSON.parse()は必要ありません。
