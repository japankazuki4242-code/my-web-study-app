フォームで使う基本属性

基本属性一覧

フォームの入力欄では、次のような属性をよく使います。

属性 主な役割
type 入力欄の種類を指定する
id その要素を見分ける名前を付ける
name 送信するデータの名前を付ける
value 入力欄の値や選択肢の値を指定する
placeholder 入力前にヒントを表示する
required 入力を必須にする
基本属性を使った例 
<input
  type="email"
  id="user-email"
  name="email"
  placeholder="example@example.com"
  required
>

type="email"
→ メールアドレス用の入力欄にする

id="user-email"
→ このHTML要素を見分ける名前を付ける

name="email"
→ 送信するデータへemailという名前を付ける

placeholder="example@example.com"
→ 入力前にメールアドレスの例を表示する

required
→ 入力を必須にする

idとnameの違い

idとnameは似ていますが、主な役割が違います。

属性 主な役割
id JavaScriptで特定のHTML要素を見つけたり、<label>のfor属性と入力欄を関連付けたりするために使う
name フォームを送信するときのデータ名として使う

id="user-email"
→ HTMLの中から、この入力欄を見分ける

name="email"
→ 送信する値が何のデータなのかを表す

同じ入力欄にidとnameの両方を書くことがありますが、それぞれ別の役割を持っています。

JavaScriptとのつながり

JavaScriptでは、HTMLに付けたidを使って入力欄を見つけられます。

HTML：

<input id="user-email" type="email">

JavaScript：

document.getElementById("user-email");

HTMLのid="user-email"
↓ 同じ値
JavaScriptのgetElementById("user-email")

このように、同じid名を使うことで、JavaScriptから目的の入力欄を見つけられます。
