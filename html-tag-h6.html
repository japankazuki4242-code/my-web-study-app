<h6>

何をするタグ？

<h6>は、HTMLの見出しタグの中で最も下の階層を表すタグです。

<h1>が最も上位で、<h2>から順に階層が下がり、<h6>が最も深い見出しになります。

見出しはページの内容を整理し、読み手や検索エンジンに構造を伝える役割があります。

数字は単なる文字サイズではありません。内容の親子関係に合わせて使い、見た目はCSSで調整します。

小規模なWebページでは使う機会が少ないこともあり、無理に<h6>まで使う必要はありません。

基本の書き方 
<h3>文章タグ</h3>
<h4>見出しタグ</h4>
<h5>h1タグの使い方</h5>
<h6>ページタイトルの例</h6>

<h6>は、この例の「ページタイトルの例」のように、<h5>の内容をさらに細かく分ける見出しです。

ここまで深い階層が必要かを考え、内容の親子関係が自然な場合に使います。

属性名・属性値の例 
<h6 class="example-title">ページタイトルの例</h6>

属性名：class
属性値：example-title

classを付けると、CSSやJavaScriptからこの<h6>を指定できます。

.example-title {
  font-size: 16px;
}

CSSは見た目を調整するために使います。16pxにしたいという理由だけで<h6>を選ばず、見出しの階層で選びます。

よく使う場面

<h6>は、非常に長く複雑な文書で、<h5>より下の見出しが必要なときに使います。

  • 階層が深いマニュアル
  • 細かく分類された教材
  • 複雑な仕様書の最小項目

通常のWebページでは使用頻度が低く、内容がそこまで細かく分かれないなら使わなくても構いません。

実際に使った例

確認したBlack Coffeeとkazuki_HP_practice2では、<h6>はまだ使用していません。

次は、最も深い見出し階層を示すための学習用の例です。

<h4>見出しタグ</h4>
<h5>h1タグの使い方</h5>
<h6>ページタイトルの例</h6>
<p>Web学習アプリというタイトルを表示します。</p>

<h6>は<h5>に含まれる、さらに細かな項目の見出しです。

見た目を小さくする目的ではなく、実際にこの階層が必要な場合にだけ使います。
