<pre>

何をするタグ？

<pre>は、HTMLに書いた改行やスペースを保ったまま表示するためのタグです。

通常のHTMLでは、連続したスペースや改行はそのまま表示されないことがありますが、<pre>の中では、それらを保った形で表示できます。

<pre>
こんにちは
  少し右にずらした文章
    さらに右にずらした文章
</pre>

<pre>はプログラムコード専用のタグではありません。

コードを表示するときによく使われますが、コードそのものを表す役割は<code>が担当します。

基本の書き方 
<pre>
こんにちは
  少し右にずらした文章
    さらに右にずらした文章
</pre>

<pre>は、開始タグ<pre>と終了タグ</pre>の間に、改行やスペースを保ったまま表示したい内容を書きます。

この例では、HTMLに書いた改行と先頭のスペースが、ブラウザでもその形を保って表示されます。

<pre>の中では、スペースや改行そのものが表示に影響するため、インデントにも意味があります。

属性名・属性値の例 
<pre class="code-block">
ここに整形した文章を書きます。
</pre>

属性名：class
属性値：code-block

classを付けると、CSSやJavaScriptからこの<pre>を指定できます。

CSS例：

.code-block {
  background-color: #121212;
}

HTML：

class="code-block"

CSS：

.code-block

CSSでclassを指定するときは、class名の前に.（ドット）を付けます。

code-blockは学習用のclass名の例です。

よく使う場面

<pre>は、改行やスペースをそのまま見せたい内容に使います。

  • プログラムコードを複数行で表示するとき
  • 整形した文章をそのまま見せたいとき
  • インデントや改行に意味がある内容を表示するとき
  • ASCIIアートのように、文字の位置関係を保ちたいとき

<pre>と<code>はよく一緒に使いますが、必ずセットで使うわけではありません。

複数行のプログラムコードを表示する
→ <pre>＋<code>

文章の途中に短いコードを表示する
→ <code>だけ

コードではなく、改行やスペースを保って表示する
→ <pre>だけ

複数行コードの例：

<pre><code>
const message = "Hello";
console.log(message);
</code></pre>

文章中の短いコードの例：

<p>JavaScriptでは <code>console.log()</code> を使います。</p>
実際に使った例

このWeb学習アプリでは、HTMLやCSSなどのコード例を複数行で見やすく表示するために、<pre>と<code>を組み合わせて使っています。

<pre><code>
<details>
  <summary>詳しく見る</summary>
  <p>ここに詳しい内容を書きます。</p>
</details>
</code></pre>

<pre>
→ 改行やインデントを保ったまま表示する

<code>
→ 中の内容がプログラムコードであることを表す

このWeb学習アプリでは、複数行のコード例を見やすく表示するために、<pre>と<code>を組み合わせています。

ただし、<pre>と<code>は必ずセットで使うものではありません。
