要素とインデックス

配列の要素を確認する

配列の中にある1つ1つの値を「要素」と呼びます。

const fruits = ["りんご", "みかん", "バナナ"];

この配列には、「りんご」「みかん」「バナナ」という3つの要素が順番に入っています。

インデックスとは？

インデックスは、配列の中にある要素の位置を表す番号です。

"りんご"
→ 1番目の要素
→ index 0

"みかん"
→ 2番目の要素
→ index 1

"バナナ"
→ 3番目の要素
→ index 2

インデックスは、配列の左にある要素から順番に付きます。

人間は1番目、indexは0から

人間が順番を数えるときは、最初のものを「1番目」と呼ぶことが多いです。

JavaScriptの配列では、最初の要素のインデックスは0です。

人間が数える順番
1番目 → 2番目 → 3番目

JavaScriptのindex
0 → 1 → 2

人間が数える順番より、インデックスは1つ小さくなります。

fruits[0]を分けて読む

1番目の要素を指定するときは、次のように書きます。

fruits[0]
書き方 意味
fruits 配列が入っている変数
[ index指定の始まり
0 指定するindex番号
] index指定の終わり

fruits[0]は、「fruitsのindex 0にある要素」と読みます。

3つの要素をindexで指定する 
fruits[0]
fruits[1]
fruits[2]

fruits[0]
→ index 0
→ 1番目の「りんご」

fruits[1]
→ index 1
→ 2番目の「みかん」

fruits[2]
→ index 2
→ 3番目の「バナナ」

配列名の後ろに角括弧を書き、その中へ指定したい要素のインデックスを入れます。

間違えやすいポイント

fruits[1]は1番目の要素ではありません。index 1なので、人間が数えると2番目の「みかん」です。

最初の要素を指定したいときは、fruits[0]と書きます。
