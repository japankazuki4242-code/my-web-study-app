テンプレートリテラル

テンプレートリテラルとは？

テンプレートリテラルは、文章の中へ変数の値などを埋め込みやすくする文字列の書き方です。

シングルクォート'ではなく、バッククォート`で文字列全体を囲みます。

バッククォートを使う 
const message = `こんにちは`;

文字列の最初と最後にある`がバッククォートです。

見た目がシングルクォート'と似ていますが、別の記号です。

${ }で変数を埋め込む 
const userName = "かず";
const message = `こんにちは、${userName}さん`;

console.log(message);

実行結果は次のとおりです。

こんにちは、かずさん

${userName}の部分が、userNameに保存されている「かず」へ置き換わります。

コードを分けて読む 
const message = `こんにちは、${userName}さん`;

const message
→ messageという定数を宣言する

=
→ 右側の値を代入する

`
→ テンプレートリテラルの始まりと終わり

${userName}
→ userNameの値を文章へ埋め込む

+で文字列をつなぐ場合との違い

+でつなぐ

const message = "こんにちは、" + userName + "さん";

テンプレートリテラル

const message = `こんにちは、${userName}さん`;

どちらも同じ文章を作れます。テンプレートリテラルでは、文章を+で何度も区切らずに変数を埋め込めます。

クォートとの違い 
const message1 = 'こんにちは';
const message2 = "こんにちは";
const message3 = `こんにちは、${userName}さん`;

シングルクォート'やダブルクォート"は、通常の文字列を作るときに使えます。

バッククォート`で囲むと、${ }を使って変数や計算結果を文章へ埋め込めます。

シングルクォートやダブルクォートで囲んだ文字列の中では、${userName}は変数の値へ置き換わりません。

${ }の中で計算する

${ }の中には、変数だけでなく計算式も書けます。

const price = 500;
const quantity = 3;
const message = `合計は${price * quantity}円です`;

console.log(message);

実行結果は次のとおりです。

合計は1500円です

先にprice * quantityが計算され、その結果が文章へ埋め込まれます。

確認問題 
const itemName = "ノート";
const price = 200;

テンプレートリテラルを使い、「ノートは200円です」という文章をmessageへ保存してください。

確認問題の答え 
const message = `${itemName}は${price}円です`;

${itemName}には「ノート」、${price}には200が入ります。

今回の学習ポイント

テンプレートリテラルは、バッククォート`で囲みます。

${ }を使うと、変数の値や計算結果を文章へ埋め込めます。

文字列と変数を+で何度もつなぐより、文章の形を読み取りやすく書けます。
