for文で配列を順番に処理する

for文でできること

for文を使うと、配列の要素を先頭から順番に処理できます。

このページでは、3つの果物を1つずつコンソールへ表示します。

基本コード 
const fruits = ["りんご", "みかん", "バナナ"];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

変数iを使ってindexを0から順番に変え、現在のindexにある要素を表示しています。

for文の条件を分けて読む
書き方 意味
let i = 0 index 0から始める
i < fruits.length iが要素数より小さい間だけ繰り返す
i++ 1回ごとにiを1増やし、次のindexへ進む

丸括弧の中は、「どこから始めるか」「いつまで続けるか」「1回ごとにどう進めるか」の順番で読みます。

なぜlet iを使う？

for文では、繰り返すたびにiの値を0、1、2と変更します。

あとから値を変更するため、const iではなくlet iと書きます。

fruits[i]とは？ 
console.log(fruits[i]);

fruits[i]は、現在のiと同じindexの要素を指定します。

iが0ならfruits[0]、iが1ならfruits[1]として動きます。

実行の流れ

i = 0
→ fruits[0]
→ りんご

i = 1
→ fruits[1]
→ みかん

i = 2
→ fruits[2]
→ バナナ

次にiが3になると、i < fruits.lengthは成り立たなくなるため、繰り返しを終了します。

実行結果 
りんご
みかん
バナナ

配列のindex 0からindex 2までが、順番に1回ずつ処理されています。

今回の学習ポイント

fruits.lengthは要素数の3です。i < fruits.lengthと書くことで、存在するindex 0・1・2だけを順番に処理できます。

for文の条件を間違えた場合の動きは、次の「配列で間違えやすいポイント」で確認します。
