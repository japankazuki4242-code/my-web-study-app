return・戻り値

returnとは？

returnは、関数の中で作った値を、関数を呼び出した場所へ返すときに使います。

function add(number1, number2) {
  return number1 + number2;
}

この関数は、受け取った2つの数値を足し、その計算結果を返します。

戻り値とは？

関数から呼び出し元へ返された値を、戻り値と呼びます。

add(3, 5)

add関数のreturn number1 + number2;によって、呼び出した場所へ8が返ります。

この例では、add(3, 5)を戻り値の8として使えます。

戻り値を変数へ保存する 
function add(number1, number2) {
  return number1 + number2;
}

const total = add(3, 5);

add(3, 5)の戻り値は8です。

返ってきた8が、totalへ保存されます。

console.log(total);

このコードを実行すると、8と表示されます。

console.log()との違い

console.log()とreturnは役割が違います。

console.log(number1 + number2);

console.log()
→ 値をコンソールへ表示する

return number1 + number2;

return
→ 値を関数の呼び出し元へ返す

「表示すること」と「後の処理で使える値を返すこと」は同じではありません。

表示する関数と値を返す関数

表示する関数

function showTotal(number1, number2) {
  console.log(number1 + number2);
}

計算結果をコンソールへ表示しますが、その結果を呼び出し元へ返してはいません。

値を返す関数

function getTotal(number1, number2) {
  return number1 + number2;
}

計算結果を戻り値として返すため、変数へ保存したり、別の計算で使ったりできます。

returnの後ろの処理 
function getMessage() {
  return "完了";
  console.log("この行は実行されない");
}

同じ実行の流れでは、returnが実行されると、値を返して、その関数の処理はそこで終了します。

そのため、この例ではreturnが実行された後にあるconsole.log()は実行されません。

初心者のうちは、実行したい処理をreturnより前に書く、と覚えておきましょう。

コードを上から順番に読む 
function double(number) {
  const answer = number * 2;
  return answer;
}

const result = double(4);
console.log(result);

① function double(number) { ... }
→ double関数を定義する
→ この時点では関数内の処理はまだ実行しない

② double(4)を呼び出す
→ 引数4を渡す

③ 仮引数numberが4を受け取る

④ const answer = number * 2;
→ 4 * 2の結果である8をanswerへ保存する

⑤ return answer;
→ 8を呼び出し元へ返す

⑥ 戻り値の8がresultへ保存される

⑦ console.log(result);
→ 8を表示する

確認問題 
function multiply(number1, number2) {
  return number1 * number2;
}

const result = multiply(3, 4);
console.log(result);

① multiply(3, 4)の戻り値は何ですか？

② 戻り値を保存する変数名は何ですか？

③ コンソールには何と表示されますか？

確認問題の答え

① 12

② result

③ 12

returnで返された値がresultへ保存され、その後で表示されます。

今回の学習ポイント

returnは、関数の中で作った値を呼び出し元へ返します。

返された値を戻り値と呼び、変数へ保存して後の処理で使えます。

console.log()は表示、returnは値を返す処理です。また、returnが実行されると、その関数の処理はそこで終わります。
