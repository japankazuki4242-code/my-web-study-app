JavaScriptの基本

JavaScriptとは？

JavaScriptは、Webページに「動き」や「処理」を加えるためのプログラミング言語です。

たとえば、次のようなことができます。

  • ボタンを押したときに処理する
  • 入力した文字を取得する
  • 入力した内容を保存する
  • 条件によって処理を変える

HTMLとCSSだけでもWebページは作れます。

そこへJavaScriptを加えると、ボタンを押すなどのユーザーの操作に反応するWebページを作れます。

HTML・CSS・JavaScriptの役割

HTML
→ ページの内容・構造を作る

CSS
→ 色・大きさ・配置など、見た目を整える

JavaScript
→ 動き・判断・処理を加える

例：このアプリの自由メモ

HTML
→ メモの入力欄と保存ボタンを置く

CSS
→ 入力欄や保存ボタンの見た目を整える

JavaScript
→ 保存ボタンが押されたら、入力された文章を保存する

3つは役割が違いますが、組み合わせることで1つのWeb機能になります。

JavaScriptでできること

ボタンを押したら処理する
→ 保存ボタンを押したときに、メモを保存する

文字を書き換える
→ 保存が終わったら、画面へ「保存しました」と表示する

入力した内容を取得する
→ 入力欄に書かれたメモの文章を受け取る

表示／非表示を切り替える
→ 必要な説明だけを画面に表示する

条件によって処理を変える
→ 保存されたメモがあるときだけ、入力欄へ表示する

データを保存する
→ 入力したメモをブラウザへ保存する

保存したデータを読み込む
→ ページを開いたときに、前に保存したメモを表示する

JavaScriptは「画面を動かす」だけではありません。

値を受け取り、条件を判断し、データを保存し、画面の表示を変えるなど、Webページの処理を担当します。

JavaScriptはどうやって動く？

Webページでの基本的な流れ

HTMLの要素を見つける
↓
ユーザーの操作を待つ
↓
値を取得する
↓
JavaScriptで処理する
↓
画面を変更する／データを保存する

このアプリの自由メモの場合

<textarea>と保存ボタンを見つける
↓
保存ボタンが押されるのを待つ
↓
<textarea>に入力された文字を取得する
↓
JavaScriptで処理する
↓
localStorageへ保存する
↓
「保存しました」と表示する

ここでは、JavaScriptの処理が上から順番につながっていることをイメージできれば十分です。

getElementById()など、1つ1つの詳しい書き方は、この先の学習ページで確認します。

このアプリで使っているJavaScript

1. BACKボタン

BACKボタンを押したときに、ブラウザの履歴を使って1つ前のページへ戻ります。

実際のコードを見る 
// HTMLからBACKボタンを取得します。
const backButton = document.getElementById("back-button");

// BACKボタンがクリックされたときの処理です。
backButton.addEventListener("click", function () {
  // ブラウザの履歴を使って前のページへ戻ります。
  history.back();
});

2. Destyleのコピー機能

「コードをコピー」ボタンを押すと、Destyleの読み込みコードをクリップボードへコピーします。

コピーできたかどうかに合わせて、画面へ結果を表示します。

実際のコードを見る 
// コピーに使うボタン・コード・結果表示をHTMLから取得します。
const copyDestyleButton = document.getElementById("copy-destyle-button");
const destyleCdnCode = document.getElementById("destyle-cdn-code");
const copyStatus = document.getElementById("copy-status");

// 必要な3つの要素があるページでだけ処理します。
if (copyDestyleButton && destyleCdnCode && copyStatus) {
  copyDestyleButton.addEventListener("click", function () {
    // コピー機能が使えないブラウザでは、メッセージを表示します。
    if (!navigator.clipboard) {
      copyStatus.textContent = "このブラウザではコピーできませんでした";
      return;
    }

    // Destyleの読み込みコードをクリップボードへコピーします。
    navigator.clipboard.writeText(destyleCdnCode.textContent)
      .then(function () {
        copyStatus.textContent = "コピーしました";
      })
      .catch(function () {
        copyStatus.textContent = "コピーできませんでした";
      });
  });
}

3. 自由メモ（localStorage）

自由メモに入力した文章を取得し、アプリ全体で共通のメモとしてlocalStorageへ保存します。

ページを開いたときは、同じ保存キーからメモを読み込みます。

自由メモ
↓
JavaScriptで入力内容を取得
↓
localStorageへ保存
↓
同じ共通メモとして読み込む

実際のコードを見る 
// アプリ全体の自由メモで共通して使用する保存キーです。
const freeMemoStorageKey = "my-web-study-app:free-memo";

// 自由メモの入力欄・保存ボタン・結果表示をHTMLから取得します。
const freeMemoInput = document.getElementById("free-memo-input");
const saveFreeMemoButton = document.getElementById("save-free-memo-button");
const freeMemoStatus = document.getElementById("free-memo-status");

// 必要な3つの要素があるページでだけ処理します。
if (freeMemoInput && saveFreeMemoButton && freeMemoStatus) {
  // 保存済みのメモをlocalStorageから読み込みます。
  const savedFreeMemo = localStorage.getItem(freeMemoStorageKey);

  // 保存済みのメモがある場合は、入力欄へ表示します。
  if (savedFreeMemo !== null) {
    freeMemoInput.value = savedFreeMemo;
  }

  // 保存ボタンがクリックされたときの処理です。
  saveFreeMemoButton.addEventListener("click", function () {
    // 入力欄に書かれた文章を取得します。
    const freeMemoText = freeMemoInput.value;

    // 入力された文章を共通の保存キーで保存します。
    localStorage.setItem(freeMemoStorageKey, freeMemoText);
    // 保存できたことを画面へ表示します。
    freeMemoStatus.textContent = "保存しました";
  });
}
これから学ぶこと

HTMLを操作する
→ JavaScriptからHTMLの要素を見つけて、内容を読み取ったり変更したりする

イベント
→ クリックなどをきっかけに処理を動かす

フォーム・入力
→ <input>や<textarea>に入力された値を取得して扱う

localStorage
→ データをブラウザに保存し、あとから読み込む

配列・オブジェクト
→ 複数のデータをまとめて整理して扱う

関数・コールバック
→ 処理をまとめたり、他の処理へ関数を渡したりする

実践
→ 学んだ内容を組み合わせて、実際のWeb機能を作る

ここからはJavaScriptを単独で覚えるだけではなく、HTMLとどのようにつながって動くのかを意識しながら学んでいきます。
