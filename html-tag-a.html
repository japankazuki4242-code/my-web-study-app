<a>

何をするタグ？

<a>は、別のページやページ内の場所へ移動するリンクを作るためのタグです。

<a>がリンク全体を表し、href属性が移動先を指定します。

外部ページだけでなく、同じサイト内の別ページや、同じページ内の場所にも移動できます。

文字だけでなく、画像などを<a>で囲んでリンクにすることもできます。

基本の書き方 
<a href="about.html">ABOUTを見る</a>

開始タグ<a>と終了タグ</a>の間に、リンクとして表示する文字を書きます。

href="about.html"は、同じフォルダにあるabout.htmlへ移動する指定です。

ページ内リンクの例：

<a href="#contact">CONTACTへ</a>

#contactは、同じページ内にあるid="contact"の要素へ移動する指定です。

属性名・属性値の例 
<a href="about.html" class="link-button">ABOUTを見る</a>

属性名：href
属性値：about.html

hrefはリンク先を指定します。

属性名：class
属性値：link-button

classは、CSSやJavaScriptから指定しやすくするために使います。

HTMLはリンクの意味と移動先を表し、CSSは色や形などの見た目を調整します。

よく使う場面

<a>は、クリックやタップで別の場所へ移動できるようにするときに使います。

  • ナビゲーションから別ページへ移動する
  • 詳しい内容のページへ移動する
  • 外部のWebサイトへ移動する
  • 同じページ内の特定の場所へ移動する
  • 画像をクリックできるリンクにする

リンク先がない操作ボタンには、目的に応じて<button>を使います。

実際に使った例

実際に作成したBlack Coffeeでは、ナビゲーションと予約ボタンに<a>を使っています。

<nav>
  <ul>
    <li><a href="">Home</a></li>
    <li><a href="">Menu</a></li>
  </ul>
</nav>

<a href="" class="btn">予約はこちら</a>

kazuki_HP_practice2でも、ロゴ・ナビゲーション・Read Moreボタンに<a>を使っています。

<h1 class="header-logo">
  <a href="#">LOGO</a>
</h1>

<a href="#" class="cta-btn">Read More</a>

どちらも移動できる文字やボタン部分を作るために使われています。
