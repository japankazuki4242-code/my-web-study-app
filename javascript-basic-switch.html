switch文

switch文とは？

switch文は、1つの値を複数の候補と比べ、同じ値のcaseに書かれた処理を実行するときに使います。

曜日や選択されたメニューなど、1つの値ごとに処理を分けたい場合に使えます。

基本コード 
const signal = "青";

switch (signal) {
  case "赤":
    console.log("止まる");
    break;
  case "青":
    console.log("進む");
    break;
  default:
    console.log("信号を確認する");
}

signalの値は「青」なので、case "青"の処理が実行され、「進む」と表示されます。

switch・case・break・default

switch (signal)
→ どの値を比べるか指定する

case "赤":
→ 値が「赤」と同じ場合の処理

break
→ switch文の処理をここで終了する

default
→ どのcaseにも当てはまらなかった場合の処理

コードを上から順に読む

signalが「青」の場合を、上から順番に確認します。

① switch (signal)
→ signalの値「青」を確認する

② case "赤":
→ 「青」と「赤」は同じではないため進む

③ case "青":
→ 値が同じなので「進む」と表示する

④ break
→ switch文を終了する

case "青"が見つかったため、defaultは実行されません。

defaultはどんなときに使う？

defaultは、どのcaseとも値が同じではなかったときに実行されます。

const signal = "点滅";

この値はcase "赤"にもcase "青"にも当てはまらないため、defaultの「信号を確認する」が表示されます。

breakを書かなかった場合

一致したcaseの処理が終わった後も、breakがなければ次のcase以降の処理が続けて実行されます。

const signal = "赤";

switch (signal) {
  case "赤":
    console.log("止まる");
  case "青":
    console.log("進む");
    break;
}

「赤」に一致した後にbreakがないため、「止まる」に続いて「進む」も表示されます。

そこで処理を終えたいcaseには、breakを書き忘れないようにします。

if文との簡単な違い

switch文
→ 1つの値を複数の候補と比べたいときに読みやすい

if文
→ 「80以上」や「2つの条件が両方成り立つ」など、さまざまな条件式を使える

1つの値と候補を比べるならswitch文、範囲や複数の条件を確認するならif文と考えると、使い分けやすくなります。

確認問題 
const fruit = "みかん";

switch (fruit) {
  case "りんご":
    console.log("赤い果物");
    break;
  case "みかん":
    console.log("オレンジ色の果物");
    break;
  default:
    console.log("ほかの果物");
}

① どのcaseが実行されますか？

② 何と表示されますか？

確認問題の答え

① case "みかん":

② 「オレンジ色の果物」と表示されます。

その後にbreakがあるため、switch文を終了します。

今回の学習ポイント

switch文は、1つの値を複数の候補と比べるときに使えます。

caseで候補、breakで終了、defaultでどの候補にも当てはまらなかった場合の処理を書きます。

コードはswitchから下へ、値が同じcaseを探すように読みましょう。
