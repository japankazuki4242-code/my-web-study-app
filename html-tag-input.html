<input>

何をするタグ？

<input>は、type属性によってさまざまな入力欄や操作を作るタグです。

<input>はvoid要素で終了タグを持たないため、</input>とは書きません。

type="text"は基本的に1行の入力、複数行の文章には<textarea>を使います。

基本の書き方 
<label for="name">お名前：</label>
<input type="text" id="name" name="user_name" required>

type="text"は1行テキスト、id="name"はlabelとの関連付けなどに使います。

name="user_name"は送信時のデータ名、requiredは入力必須をブラウザに伝えるboolean属性です。

value属性を使うと、初期値や送信される値を指定できます。

属性名・属性値の例

代表的なtype：

  • type="text"：1行テキスト
  • type="email"：メールアドレス
  • type="password"：パスワード入力
  • type="checkbox"：チェックボックス
  • type="radio"：ラジオボタン
  • type="submit"：送信ボタンとして使えるinput
<input type="radio" name="plan" value="basic">

nameは送信データ名、valueはその選択肢が選ばれたときに送信される値です。

よく使う場面

<input>は、名前・メールアドレス・パスワード・選択項目など、短い入力や選択に使います。

<input type="text">
→ 基本的に1行のテキスト入力。終了タグなし。

<textarea></textarea>
→ 複数行の文章入力。開始タグと終了タグあり。

お問い合わせ本文や長いコメントには<textarea>が向いています。
