CSSの基本

CSSは何をするもの？

HTMLは、見出し・文章・画像など、ページの構造や内容の意味を表します。

CSSは、色・大きさ・余白・配置など、HTMLで作ったページの見た目を整えます。

HTMLとCSSは役割を分けながら、組み合わせてWebページを作ります。

CSSの基本の書き方 
h1 {
  color: blue;
}

このCSSは、h1を選び、文字色を青にします。

基本は「どこに・何を・どうする」を順番に読むと理解しやすくなります。

セレクタ・プロパティ・値 
h1 {
  color: blue;
}

h1
→ セレクタ。どのHTML要素に指定するかを選ぶ

color
→ プロパティ。何を変更するかを指定する

blue
→ 値。どのように変更するかを指定する

記号の意味

{ }
→ そのセレクタに対するCSSを書く範囲

:
→ プロパティと値を区切る

;
→ 1つの指定の終わり

セレクタ {
  プロパティ: 値;
}
HTMLとCSSのつながり

HTML：

<h1>タイトル</h1>

CSS：

h1 {
  color: blue;
}
HTMLのh1
↓
CSSのh1が選ぶ
↓
color: blue; が適用される

CSSファイルは、HTMLの<link>から読み込むことでページへつながります。

実際に使った例

Black Coffeeでは、ヘッダーへ背景色・内側の余白・文字の位置を指定しています。

header {
  background-color: white;
  padding: 30px;
  text-align: center;
}

header
→ HTMLの<header>を選ぶ

background-color: white;
→ 背景色を白にする

padding: 30px;
→ 内側に30pxの余白を作る

text-align: center;
→ 中の文字などを中央に揃える
