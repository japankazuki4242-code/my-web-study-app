filter() - 条件に合うもの

filter()とは？

filter()は、条件に合う要素をすべて集める配列メソッドです。

条件に合った要素を入れた、新しい配列を結果として作ります。

条件を確認する処理は、コールバック関数としてfilter()へ渡します。

基本コード 
const numbers = [10, 20, 30, 40];

const filtered = numbers.filter(function (number) {
  return number >= 30;
});

console.log(filtered);

30以上の要素をすべて集め、新しい配列をfilteredへ保存しています。

実行結果は[30, 40]です。

コードを分けて読む

numbers
→ 条件を確認する元の配列

filter
→ 条件に合う要素をすべて集める配列メソッド

function (number) { ... }
→ 各要素の条件を確認するコールバック関数

number
→ 配列から1つずつ渡される要素を受け取る仮引数

filtered
→ filter()が作った新しい配列を保存する変数

trueとfalseで選ぶ 
return number >= 30;

条件がtrueになった要素は、新しい配列へ入ります。

条件がfalseになった要素は、新しい配列へ入りません。

returnは、現在の要素が条件に合うかどうかをfilter()へ返しています。

実行順を追う

10 → 10 >= 30はfalse → 新しい配列へ入れない

20 → 20 >= 30はfalse → 新しい配列へ入れない

30 → 30 >= 30はtrue → 新しい配列へ入れる

40 → 40 >= 30はtrue → 新しい配列へ入れる

すべての要素を確認した結果、新しい配列は[30, 40]になります。

元の配列は変更しない 
console.log(numbers);
console.log(filtered);

numbers
→ [10, 20, 30, 40]

filtered
→ [30, 40]

filter()自体は元のnumbers配列を変更せず、条件に合う要素を入れた別の新しい配列を作ります。

find()との違い

find()
→ 条件に合う最初の1つを結果にする

filter()
→ 条件に合うものをすべて集め、新しい配列を結果にする

同じnumber >= 30という条件でも、find()の結果は30、filter()の結果は[30, 40]です。

コードを上から順番に読む

① numbers配列を作る

② numbers.filter(...)を実行する

③ 各要素を仮引数numberへ1つずつ渡す

④ コールバック関数が条件の結果を返す

⑤ trueになった30と40を新しい配列へ入れる

⑥ 新しい配列をfilteredへ保存する

確認問題 
const scores = [40, 80, 90];

const passed = scores.filter(function (score) {
  return score >= 70;
});

① 新しい配列へ入る要素は何ですか？

② passedはどのような配列になりますか？

③ 元のscores配列は変わりますか？

確認問題の答え

① 80と90です。

② [80, 90]になります。

③ 変わりません。scoresは[40, 80, 90]のままです。

今回の学習ポイント

filter()は、条件に合う要素をすべて集めます。

条件がtrueになった要素から、新しい配列を作ります。

filter()自体は、元の配列を変更せず、条件に合う要素を入れた新しい配列を作ります。
