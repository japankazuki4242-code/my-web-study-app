radio：1つだけ選ぶ

radioは、複数の選択肢から1つだけ選んでもらうときに使います。

<label>
  <input
    type="radio"
    id="contact-email"
    name="contact-method"
    value="email"
  >
  メール
</label>

<label>
  <input
    type="radio"
    id="contact-phone"
    name="contact-method"
    value="phone"
  >
  電話
</label>

同じname="contact-method"を付けたラジオボタンは、同じグループになります。同じグループの中では、1つだけ選べます。

.checkedで、そのラジオボタンが選ばれているかを確認できます。

.valueで、そのラジオボタンに設定されているvalueの値を取得できます。

const emailRadio =
  document.getElementById("contact-email");

console.log(emailRadio.checked);
console.log(emailRadio.value);
checkbox：チェック状態を確認する

checkboxは、複数の項目を選んでもらう場合や、同意を確認する場合に使います。

<label>
  <input id="agree" type="checkbox">
  利用規約に同意する
</label>
const agreeCheckbox =
  document.getElementById("agree");

const isAgreed =
  agreeCheckbox.checked;

true
→ チェックされている

false
→ チェックされていない

.checkedは、チェック状態をtrueまたはfalseで表します。

select：選ばれた値を取得する

selectは、プルダウンの選択肢から1つを選んでもらうときに使います。

<select id="prefecture">
  <option value="aichi">愛知県</option>
  <option value="gifu">岐阜県</option>
  <option value="mie">三重県</option>
</select>
const prefectureSelect =
  document.getElementById("prefecture");

const prefecture =
  prefectureSelect.value;

.valueで、現在選ばれている<option>のvalueを取得できます。

valueとcheckedの違い
プロパティ 確認できること
.value 入力欄や選択肢が持つ値
.checked radioやcheckboxが選ばれているか

ラジオボタンでは、.checkedで選ばれているかを確認し、.valueでその選択肢の値を取得します。

チェックボックスでは、まず.checkedでチェック状態を確認します。

セレクトボックスでは、.valueで現在選ばれている値を取得します。
