<table>

何をするタグ？

<table>は、行と列を使って関連するデータを整理する表全体の親となるタグです。

<table>単体だけでは通常、表の中身は完成しません。<tr>・<th>・<td>などを組み合わせます。

必要に応じて<caption>・<thead>・<tbody>・<tfoot>も使います。

ページ全体の配置を作るレイアウト目的では使いません。HTMLはデータの構造を表し、枠線や配置などの見た目はCSSで調整します。

基本の書き方

表全体の親子構造：

<table>
├─ <caption>  表が何についての表なのかを示す
├─ <thead>    表の見出し部分
│   └─ <tr>   1行
│       ├─ <th> 見出しセル
│       └─ <th>
├─ <tbody>    主なデータ部分
│   ├─ <tr>
│   │   ├─ <td> データセル
│   │   └─ <td>
│   └─ <tr>
│       ├─ <td>
│       └─ <td>
└─ <tfoot>    表のまとめ部分
    └─ <tr>
        ├─ <th> 見出しとして使うこともある
        └─ <td> データ

完成形の例：

<table>
  <caption>営業時間</caption>
  <thead>
    <tr>
      <th>曜日</th>
      <th>時間</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>月曜日</td>
      <td>10:00〜18:00</td>
    </tr>
    <tr>
      <td>火曜日</td>
      <td>10:00〜18:00</td>
    </tr>
  </tbody>
</table>

<table>の中に表題や各部分があり、その中の<tr>が1行、さらにその中の<th>と<td>がセルになります。

属性名・属性値の例 
<table class="price-table">
  <tr>
    <td>コーヒー</td>
    <td>500円</td>
  </tr>
</table>

属性名：class
属性値：price-table

classを付けると、CSSやJavaScriptからこの表を指定できます。

HTMLは表の意味と構造を表し、枠線・幅・色などの見た目はCSSで指定します。

よく使う場面

<table>は、行と列の関係があるデータを整理して見せたいときに使います。

  • 商品と価格の一覧
  • 営業時間や予定表
  • 成績や集計結果
  • 仕様の比較

<thead>は見出し部分、<tbody>は主なデータ部分、<tfoot>はまとめ・集計部分です。

これらをすべての表に必ず書くという意味ではなく、表の構造を分かりやすく整理する必要に応じて使います。

実際に使った例

実際に作成したBlack Coffeeでは、メニュー名と価格を並べる表に<table>を使っています。

<table>
  <tr>
    <td>サンプルメニュー</td>
    <td>400円</td>
  </tr>
</table>

実作品では<tr>と<td>を使ったシンプルな構造で、<caption>・<thead>・<tbody>・<th>・<tfoot>は使用していません。

kazuki_HP_practice2では、今回の表関連タグを使用していません。
