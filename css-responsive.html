レスポンシブ

レスポンシブとは？

レスポンシブ対応は、PC・タブレット・スマートフォンなどの画面幅に合わせて、レイアウトやサイズを調整する考え方です。

すべての端末へ別々のHTMLを作るのではなく、同じ内容をCSSで見やすく調整できます。

メディアクエリの基本 
@media screen and (max-width: 871px) {
  .feature-box {
    flex-direction: column;
  }
}

@media
→ 条件付きでCSSを適用する

max-width: 871px
→ 画面幅が871px以下の場合

max-width の読み方

メディアクエリ内のmax-widthは、画面幅などの条件を表します。

@media screen and (max-width: 871px) {
}

これは、要素自体へmax-width: 871px;を指定するCSSとは役割が異なります。

ブレークポイントとは？

ブレークポイントは、レイアウトやサイズを切り替える境目となる画面幅です。

すべてのサイトで使う絶対的な数字はありません。内容が見づらくなる幅を確認し、そのサイトに合う値を決めます。

横並び → 縦並び 
.feature-box {
  display: flex;
  justify-content: space-between;
}

@media screen and (max-width: 871px) {
  .feature-box {
    flex-direction: column;
    text-align: center;
  }
}

広い画面では横並び、狭い画面では縦並びへ切り替える例です。

画像・文字サイズの調整 
@media screen and (max-width: 520px) {
  .fv {
    height: 380px;
  }

  .img-area figure {
    width: 100%;
    height: auto;
  }

  .header-menu-list a {
    font-size: 16px;
  }
}

狭い画面に合わせて、背景領域の高さ・画像幅・文字サイズを調整しています。

小さくしすぎず、読みやすさや押しやすさを確認することも大切です。

実際に使った例

kazuki_HP_practice2では、871pxで横並びを縦並びへ変更し、520pxで画像や文字サイズを調整しています。

Progate模写では、1000px以下で4列を2列へ、670px以下で1列へ変更しています。

@media all and (max-width: 1000px) {
  .lesson {
    width: 50%;
  }
}

@media all and (max-width: 670px) {
  .lesson {
    width: 100%;
  }
}

670px以下では、通常メニューを隠してメニューアイコンを表示する切り替えもあります。

.header-right {
  display: none;
}

.menu-icon {
  display: block;
}
