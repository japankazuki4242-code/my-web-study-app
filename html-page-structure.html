ページ構造から探す

ホームページ全体の基本構造

ホームページ全体は、次のような親子関係で作ることがあります。

body
├─ header
├─ main
│  ├─ section
│  ├─ section
│  └─ section
├─ aside（必要な場合）
└─ footer

ただし、すべてのホームページが必ずこの構造になるわけではありません。内容や制作した時期、教材の方針などによって構造は変わります。

実際に模写したBlack Coffeeは、次のような大きな構造です。

body
├─ header
├─ main
│  ├─ section.hero
│  ├─ section.about
│  └─ section.menu
├─ aside
└─ footer

kazuki_HP_practice2では、<main>の中にファーストビューとFeature部分があります。

body
├─ header
├─ main
│  ├─ div.fv
│  └─ section.feature
└─ footer

Progate教材を模写したkazu_practice_progate_html_cssは、<main>や<section>ではなく、<div>とclass名を中心に構成されています。

body
├─ header
├─ div.top-wrapper
├─ div.lesson-wrapper
├─ div.message-wrapper
└─ footer

教材によって構造や書き方は異なります。新しい書き方と違うから間違いということではなく、それぞれのコードを親子関係で見ることが大切です。

ヘッダー・ナビゲーション

Black Coffeeのヘッダーは、見出しとナビゲーションを直接まとめています。

header
├─ h1
└─ nav
   └─ ul
      └─ li
         └─ a

<nav>の中にリストがあり、それぞれの<li>の中に移動用の<a>があります。

kazuki_HP_practice2では、ヘッダーの内側に<div class="header-inner">を作っています。

header
└─ div.header-inner
   ├─ div.logo-box
   └─ nav.header-menu
      └─ ul
         └─ li
            └─ a

header-innerでロゴ側とメニュー側をまとめ、CSSで配置を整えています。

ヘッダーの中が必ずこの形になるわけではありません。ページの内容やデザインによって、必要な要素や親子関係は変わります。

ファーストビュー

Black Coffeeでは、<section>の中に画像を置いています。

<section class="hero">
  <figure>
    <img src="images/top.jpg" alt="カフェの店内">
  </figure>
</section>

kazuki_HP_practice2では、空の<div>を作り、CSSのbackground-imageで画像を表示しています。

<div class="fv"></div>

Progate教材では、<div class="top-wrapper">の中に<div class="container">を置いています。

<div class="top-wrapper">
  <div class="container">
    <h1>LEARN TO CODE.</h1>
    <p>Progateはオンラインプログラミング学習サービスです。</p>
  </div>
</div>

hero・fv・top-wrapperはHTMLタグではなく、制作者が付けたclass名です。ファーストビュー専用のHTMLタグがあるわけではありません。

HTMLで内容の親子関係を作り、CSSで背景画像・大きさ・配置などの見た目を整えます。同じような見た目でも、HTML構造は1種類とは限りません。

メインコンテンツ・section

<main>は、そのページの中心となる内容をまとめるために使います。

<section>は、関連する内容を章やテーマごとのまとまりとして整理するときに使います。

<main>
  <section>
    <h2>ABOUT</h2>
  </section>

  <section>
    <h2>SERVICE</h2>
  </section>

  <section>
    <h2>CONTACT</h2>
  </section>
</main>

この例では、ABOUT・SERVICE・CONTACTをそれぞれ内容のまとまりとして分けています。

ただし、ABOUTだから必ず<section>、CONTACTだから必ず<section>というルールではありません。名前だけで決めず、見出しを付けられるような意味のあるまとまりかを考えます。

container / inner の考え方

Black CoffeeとProgate教材ではcontainer、kazuki_HP_practice2ではheader-innerやfeature-innerというclass名が使われています。

<section>
  <div class="container">
    <h2>見出し</h2>
    <p>文章</p>
  </div>
</section>

このHTMLを親子関係で見ると、次のようになります。

section
└─ div.container
   ├─ h2
   └─ p

container・inner・wrapperはHTMLタグではなく、制作者が付けたclass名です。

中身の横幅・余白・配置をCSSで整えるための内側の箱として使われることがあります。

ただし、containerという名前を必ず使う決まりはなく、innerというclassに決まった機能があるわけでもありません。実際の役割はHTMLの構造とCSSの指定によって変わります。

aside・footer

Black Coffeeでは、メインコンテンツの後に補足情報とフッターが続いています。

main
↓
aside
↓
footer

<aside>は、本文やページ内容に関連する補足情報を表します。「画面の右側に置くタグ」ではなく、表示する位置はCSSによって変わります。

<footer>は、ページやセクションの締めくくりとなる情報を表します。コピーライトや関連情報などを入れることがあります。

<footer>も「画面の一番下に置くためだけのタグ」ではありません。画面上の位置だけではなく、内容が持つ意味や役割を考えてHTMLタグを選びます。
