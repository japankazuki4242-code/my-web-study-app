while文とfor文の違い

while文とは？

while文は、指定した条件がtrueの間、同じ処理を繰り返します。

繰り返す回数よりも、「この条件が成り立っている間は続ける」と考えたい処理に向いています。

while文の基本コード 
let count = 1;

while (count <= 3) {
  console.log(count);
  count++;
}

countが3以下の間、現在の値を表示し、1ずつ増やします。

実行結果は1、2、3です。

while文を分けて読む

let count = 1
→ 最初の値を1にする

while (count <= 3)
→ countが3以下の間、繰り返す

console.log(count)
→ 現在のcountを表示する

count++
→ countを1増やす

実行の流れ

① count = 1
→ 条件はtrue
→ 1を表示
→ countを2にする

② count = 2
→ 条件はtrue
→ 2を表示
→ countを3にする

③ count = 3
→ 条件はtrue
→ 3を表示
→ countを4にする

④ count = 4
→ count <= 3はfalse
→ 繰り返しを終了する

更新処理を忘れるとどうなる？

このように数値を使って繰り返すwhile文では、条件がいつかfalseになるように、値を更新する処理が必要です。

let count = 1;

while (count <= 3) {
  console.log(count);
}

この例ではcountが変わらないため、count <= 3がずっとtrueのままです。

このコードでは条件がずっとtrueのままなので、無限ループになります。

for文との違い

while文
→ 条件が満たされている間、繰り返す

for文
→ 回数や範囲が分かっている繰り返しに向いている

for文は、最初の値・繰り返す条件・更新処理を丸括弧の中へまとめて書けます。

for (let i = 1; i <= 3; i++) {
  console.log(i);
}

for文の詳しい読み方は、既存の「for文で配列を順番に処理する」で学習済みです。このページでは使い分けを中心に確認します。

while文とfor文の比較
while文 for文
条件がtrueの間、繰り返す 回数や範囲が分かっている繰り返しに向く
条件と更新処理を別の場所に書く 最初の値・条件・更新処理をまとめて書ける
いつ終わるかを条件で考える どこからどこまで繰り返すかを考える
どちらを使う？

「入力が正しくなるまで続ける」のように、条件を中心に考える場合はwhile文が向いています。

「配列の要素を先頭から最後まで処理する」のように、範囲が分かっている場合はfor文が向いています。

どちらでも書ける場合はありますが、何を基準に繰り返すのかが読みやすい方を選びます。

確認問題

① while文は、どのような間、処理を繰り返しますか？

② while文で更新処理を忘れると、どのような問題が起こる可能性がありますか？

③ 1回目から10回目まで処理するなど、回数が分かっている場合は、while文とfor文のどちらが向いていますか？

確認問題の答え

① 条件がtrueの間

② 条件がずっとtrueになり、無限ループになる可能性がある

③ for文

今回の学習ポイント

while文は、条件がtrueの間、処理を繰り返します。

while文では、条件がいつかfalseになるように更新処理を確認します。

条件を中心に考えるならwhile文、回数や範囲が分かっているならfor文と整理しましょう。
