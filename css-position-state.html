Position・状態変化

positionとは？

positionは、要素の配置方法を指定します。

Version 1ではrelative・absolute・fixedと、位置を指定するプロパティを扱います。

position: relative 
.lesson-icon {
  position: relative;
}

relativeは、元の位置を基準に移動するときや、内側のabsolute要素が位置を決める基準を作るときに使います。

position: absolute 
.lesson-icon {
  position: relative;
}

.lesson-icon p {
  position: absolute;
  top: 44%;
  width: 100%;
}
親 .lesson-icon
└─ position: relative
   ↓ 位置の基準
   子 p
   └─ position: absolute

Progate模写では、親を基準にして画像の上へ文字を重ねています。

position: fixed 
header {
  position: fixed;
  top: 0;
}

fixedは、要素を画面の決まった位置へ固定します。この例では、スクロールしてもヘッダーを画面上部へ固定します。

top / right / bottom / left 
.box {
  position: fixed;
  right: 16px;
  bottom: 16px;
}

top・right・bottom・leftは、positionで配置した要素の位置を指定します。

z-index 
header {
  position: fixed;
  z-index: 10;
}

z-indexは、重なった要素の前後関係を調整します。

単純な例では数字が大きい要素が手前になりますが、どのような場合でも大きい数字なら必ず最前面になるわけではありません。詳しい重なりの仕組みはVersion 1では扱いません。

:hover / :active

Progate模写の「さっそく開発する」ボタンを例に、マウスを乗せた状態と押している状態を確認します。

<a href="#" class="btn message">さっそく開発する</a>

:hoverは、マウスポインターを要素の上に乗せている状態です。

.btn {
  opacity: 0.8;
}

.btn:hover {
  opacity: 1;
}

通常の.btnはopacity: 0.8;で少し透明です。マウスポインターを乗せるとopacity: 1;になり、はっきり表示されます。

:activeは、ボタンなどを押している間の状態です。

「さっそく開発する」ボタンの通常状態には、下側へ7pxの影があります。

.message {
  padding: 15px 40px;
  background-color: #5dca88;
  box-shadow: 0 7px #1a7940;
}

box-shadow: 0 7px #1a7940;の2つ目の数値7pxによって、ボタンの下側に影が見えます。

ボタンを押している間は、次のCSSが適用されます。

.message:active {
  position: relative;
  top: 7px;
  box-shadow: none;
}

position: relative;
→ 要素の元の位置を基準にして、位置を少し動かせる状態にする

top: 7px;
→ 元の位置を基準にして、ボタン本体を7px下へ動かす

これは「画面の一番上から7px」という意味ではなく、「ボタンの元の位置から7px下」という意味です。

box-shadow: none;
→ 通常時にボタンの下にあった影を消す

ボタン本体が7px下へ動く
＋
下にあった7pxの影が消える
↓
ボタンが影の部分へ沈み込んだように見える

position: relativeで動く方向

top: 7px;
→ 元の位置から下へ7px

right: 7px;
→ 元の位置から左へ7px

bottom: 7px;
→ 元の位置から上へ7px

left: 7px;
→ 元の位置から右へ7px

右下へ7pxずつ動かす場合は、topとleftを組み合わせます。

.box {
  position: relative;
  top: 7px;
  left: 7px;
}
:hover
→ マウスを乗せた状態

:active
→ 押している状態

position: relative
→ 元の位置を基準にできる

top: 7px
→ 元の位置から7px下へ動く

box-shadow: none
→ 影が消える

その結果
→ ボタンが押し込まれたように見える
実際に使った例

Progate模写のヘッダーは画面上部へ固定されています。

header {
  position: fixed;
  top: 0;
  z-index: 10;
}

メッセージボタンを押している間は、位置と影を変えて押し込まれたように見せています。

.message:active {
  position: relative;
  top: 7px;
  box-shadow: none;
}

Black Coffeeでは、予約ボタンのhover時に背景色を変えています。

aside .btn:hover {
  background-color: red;
}
