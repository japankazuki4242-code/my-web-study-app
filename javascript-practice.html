実践

実践とは？

実践は、これまで学習したJavaScriptを、1つの機能の中で少しずつ組み合わせていくページです。

完成コードを暗記するのではなく、次の処理がどのようにつながっているかを読むことを目的にします。

  • どのHTML要素を取得するか
  • どのイベントを待つか
  • どの値を読み取るか
  • どこへ表示するか

STEP 1

入力した文字を画面に表示する

PR1-1

STEP 1で作るもの

PR1-1では「学習項目リスト」の最初の段階を作りました。

学習したい内容を入力
↓
追加ボタンを押す
↓
入力した内容を画面へ表示

たとえば、入力欄へ「JavaScriptのJSONを復習する」と入力します。

入力欄：
JavaScriptのJSONを復習する
↓
追加
↓
表示：
JavaScriptのJSONを復習する

PR1-1ではまだ配列へ追加せず、入力した1つの内容をそのまま画面へ表示しました。

使うHTML要素を確認する

PR1-1では、入力欄・追加ボタン・表示場所の3つのHTML要素を使いました。

<input
  type="text"
  id="study-item-input"
>

<button
  type="button"
  id="add-study-item-button"
>追加</button>

<p id="study-item-result"></p>

<input>は、学習したい内容を入力する場所です。id="study-item-input"を使い、JavaScriptのstudyItemInputにつなげます。

<button>は、入力内容を表示するきっかけになる追加ボタンです。id="add-study-item-button"を使い、JavaScriptのaddStudyItemButtonにつなげます。

<p>は、入力内容を画面へ表示する場所です。id="study-item-result"を使い、JavaScriptのstudyItemResultにつなげます。

JavaScriptでHTML要素を見つける

PR1-1ではdocument.getElementById()を使い、HTMLに付けたidから3つの要素を見つけました。

const studyItemInput =
  document.getElementById("study-item-input");

const addStudyItemButton =
  document.getElementById("add-study-item-button");

const studyItemResult =
  document.getElementById("study-item-result");

studyItemInputは入力欄、addStudyItemButtonは追加ボタン、studyItemResultは表示場所のHTML要素を表しています。

HTMLのidとgetElementById()の文字列が同じ名前になることで、それぞれのコードがつながります。

クリックを受け取る

addEventListener()を使い、追加ボタンがクリックされるのを待ちます。

addStudyItemButton.addEventListener("click", function () {
  // クリックされた後の処理
});

"click"は待つイベントの種類です。追加ボタンがクリックされると、コールバック関数のfunction () { ... }の中が実行されます。

今回はfunction () { ... }という無名関数を、addEventListener()のコールバック関数として直接渡しています。名前付き関数を使う場合は、関数名だけを書くと関数そのものを渡し、関数名に()を付けるとその場で関数を実行します。

入力した値を取得して表示する

PR1-1では、入力欄に現在入力されている値をstudyItemInput.valueで取得しました。

const studyItemText = studyItemInput.value;

studyItemResult.textContent = studyItemText;

取得した値を、最初にstudyItemTextという変数へ入れます。

次に、studyItemResult.textContentへstudyItemTextを入れ、表示場所へ文字を表示しました。

STEP 2

複数の学習項目を一覧に表示する

PR1-2

配列に複数の学習項目を入れる

複数の学習項目をまとめて持つために、最初に空の配列を作ります。

const studyItems = [];

studyItemsは、追加した学習項目をためていく配列です。最初は何も入っていないため、[ ]の中は空です。

この配列は、ページを開いている間だけJavaScriptの中で使います。今回はまだlocalStorageへ保存しないため、ページを再読み込みすると空の配列へ戻ります。

push()で新しい項目を追加する

入力欄の値を.valueで取得し、studyItemTextへ入れます。

const studyItemText = studyItemInput.value;

studyItems.push(studyItemText);

studyItems.push(studyItemText)は、取得した学習項目をstudyItems配列の末尾へ追加します。

追加ボタンを押すたびに同じ処理が実行されるため、配列の中へ学習項目が順番に増えていきます。

renderStudyItems()で一覧表示を始める

renderStudyItems()は、配列の現在の内容を画面へ一覧表示する名前付き関数です。

function renderStudyItems() {
  studyItemList.textContent = "";

  studyItems.forEach(function (studyItem) {
    const listItem = document.createElement("li");

    listItem.textContent = studyItem;
    studyItemList.appendChild(listItem);
  });
}

最初にstudyItemList.textContent = ""で前回表示した一覧を空にします。

次にforEach()で配列を1件ずつ処理し、li要素を作ってul要素へ追加します。

追加ボタンを押したあとにrenderStudyItems()を実行すると、配列へ追加した最新状態が画面へ表示されます。

studyItems.push(studyItemText);

renderStudyItems();
配列から1件ずつ取り出す

forEach()を使い、studyItems配列の中身を1件ずつ処理します。

studyItems.forEach(function (studyItem) {
  // 1件ずつ表示する処理
});

studyItemには、配列から学習項目が1件ずつ順番に渡されます。

配列に3件入っていればコールバック関数が3回実行され、それぞれの学習項目を使って表示処理を行います。

liを作って画面へ追加する

HTMLには、学習項目一覧を表示するための<ul>を用意します。

<ul id="study-item-list"></ul>

JavaScriptでは、学習項目1件につき1つの<li>を作ります。

const listItem = document.createElement("li");

listItem.textContent = studyItem;

studyItemList.appendChild(listItem);

document.createElement("li")でli要素を作り、listItem.textContentで学習項目の文字を入れます。

最後にappendChild()を使い、作ったli要素をstudyItemListのul要素へ追加します。ここが、JavaScriptでHTML要素を作って画面へ追加するDOM操作です。

STEP 3

学習内容と完了状態をセットで持つ

PR1-3

なぜ文字列だけでは足りないのか

PR1-2では、1件の学習項目を文字列として配列へ追加していました。

"HTMLを復習する"

この文字列が持っているのは、学習内容という1つの情報だけです。

今後、1件の学習項目に「学習内容」と「完了したかどうか」のような複数の情報を持たせるには、それらを1つにまとめる必要があります。

そこでPR1-3では、複数のプロパティをまとめて持てるオブジェクトを使います。

学習項目をオブジェクトにする

入力欄から取得した文字列を使い、1件分の学習項目を表すオブジェクトを作ります。

const studyItem = {
  text: studyItemText,
  done: false
};

studyItemは、学習項目1件を入れる変数です。

text と done に役割を分ける

textは学習内容を保存するプロパティで、値にはinputから取得した文字列のstudyItemTextを入れます。

doneは完了状態を保存するプロパティです。falseは、まだ完了していない状態を表します。

今回はdone: falseとして情報を持たせるだけで、完了状態を変更したり画面へ表示したりする処理はまだ作りません。

オブジェクトを配列へ追加する

push()の役割はPR1-2と同じで、値を配列の末尾へ追加することです。

studyItems.push(studyItem);

PR1-2では、文字列が入っているstudyItemTextを追加していました。

studyItems.push(studyItemText);

PR1-3では、学習内容と完了状態をまとめたstudyItemオブジェクトを追加します。

文字列を追加する
↓
オブジェクトを追加する

この点が変わり、studyItemsは文字列の配列からオブジェクトの配列になります。

配列から学習項目を1件ずつ取り出す

学習項目を2件追加すると、studyItems配列の中は次のようになります。

[
  {
    text: "HTMLを復習する",
    done: false
  },
  {
    text: "CSSのflexboxを復習する",
    done: false
  }
]

外側の[ ]が配列で、その中に{ }で表した学習項目オブジェクトが複数入っています。

それぞれのオブジェクトは、textとdoneという同じ2つのプロパティを持っています。

forEach()を使うと、配列から学習項目オブジェクトを1件ずつ取り出せます。

studyItems.forEach(function (studyItem) {
  // studyItemは学習項目オブジェクト1件
});

studyItemには、textとdoneを持つオブジェクトが順番に入ります。

studyItem.text から文字を取り出して表示する

forEach()で配列を処理すると、studyItemには学習項目オブジェクトが1件ずつ入ります。

studyItems.forEach(function (studyItem) {
  const listItem = document.createElement("li");

  listItem.textContent = studyItem.text;
  studyItemList.appendChild(listItem);
});

studyItemは、次のようなオブジェクト1件を表します。

{
  text: "HTMLを復習する",
  done: false
}

画面へ表示したいのは学習内容なので、studyItem.textと書いてtextプロパティの値だけを取り出します。

studyItem.text
↓
"HTMLを復習する"
↓
listItem.textContentでli要素へ表示

STEP 4

チェックボックスと完了状態を連動する

PR1-4

done で完了状態を管理する

PR1-3では、1件の学習項目をtextとdoneを持つオブジェクトにしました。

{
  text: "HTMLを復習する",
  done: false
}

textは学習内容、doneは完了したかどうかを表します。

PR1-3ではdoneを作るだけでしたが、PR1-4ではチェックボックスとつなげ、初めて画面の操作に使います。

true と false の意味を確認する

doneプロパティには、trueまたはfalseを入れて完了状態を表します。

done: false
↓
未完了

done: true
↓
完了

新しい学習項目はdone: falseで作るため、最初は未完了です。チェックボックスを操作すると、この値がtrueまたはfalseへ変わります。

チェックボックスをJavaScriptで作る

学習項目1件につき1つのチェックボックスを、JavaScriptで作ります。

const checkbox = document.createElement("input");

checkbox.type = "checkbox";

document.createElement("input")でinput要素を作り、checkbox.type = "checkbox"でチェックボックスにします。

チェックボックスはHTMLへ最初から書いているのではありません。forEach()の中で、学習項目オブジェクト1件ごとにJavaScriptが作ります。

done をチェックボックスへ反映する

作ったチェックボックスへ、学習項目オブジェクトの完了状態を反映します。

checkbox.checked = studyItem.done;

studyItem.doneがfalseならチェックなし、trueならチェックありになります。

studyItem.done
↓
checkbox.checked
↓
画面のチェック状態

これは、JavaScriptのデータを画面へ反映する処理です。

新しい項目を追加してrenderStudyItems()が再実行されても、配列内のdoneがtrueなら、チェックありの状態で作り直されます。

チェック変更を受け取る

チェックボックスの状態が変わったことは、changeイベントで受け取ります。

checkbox.addEventListener("change", function () {
  studyItem.done = checkbox.checked;
});

changeイベントは、ユーザーがチェックを付けたり外したりして、チェック状態が変わったときに発生します。

状態が変わるとコールバック関数の中が実行され、画面の新しいチェック状態を学習項目オブジェクトへ戻します。

チェック状態を done へ戻す

checkbox.checkedは、チェックボックスの現在の状態を表します。

チェックあり
↓
true

チェックなし
↓
false

studyItem.done = checkbox.checked;

この代入によって、チェックがあればtrue、チェックがなければfalseがstudyItem.doneへ入ります。

画面でチェックを変更
↓
checkbox.checked
↓
studyItem.done

これは、画面の操作をJavaScriptのデータへ戻す処理です。

text と done をそれぞれ画面で使う

forEach()で受け取るstudyItemは、学習項目オブジェクト1件です。

{
  text: "HTMLを復習する",
  done: false
}

同じオブジェクトの2つのプロパティを、それぞれ別の画面要素へつなげます。

studyItem.text
↓
spanの文字

studyItem.done
↓
checkboxのチェック状態

itemText.textContent = studyItem.text;

checkbox.checked = studyItem.done;
STEP 4の処理を上から読む

PR1-4のjavascript-practice.js全体は、次のコードです。

const studyItemInput =
  document.getElementById("study-item-input");

const addStudyItemButton =
  document.getElementById("add-study-item-button");

const studyItemList =
  document.getElementById("study-item-list");

const studyItems = [];

function renderStudyItems() {
  studyItemList.textContent = "";

  studyItems.forEach(function (studyItem) {
    const listItem = document.createElement("li");

    const checkbox = document.createElement("input");
    checkbox.type = "checkbox";
    checkbox.checked = studyItem.done;

    const itemText = document.createElement("span");
    itemText.textContent = studyItem.text;

    checkbox.addEventListener("change", function () {
      studyItem.done = checkbox.checked;
    });

    listItem.appendChild(checkbox);
    listItem.appendChild(itemText);

    studyItemList.appendChild(listItem);
  });
}

addStudyItemButton.addEventListener("click", function () {
  const studyItemText = studyItemInput.value;

  const studyItem = {
    text: studyItemText,
    done: false
  };

  studyItems.push(studyItem);

  renderStudyItems();
});

document.createElement()を使って、li・checkbox・spanを学習項目ごとに作っています。

checkbox.checked = studyItem.doneが、オブジェクトの完了状態を画面へ反映する場所です。

checkbox.addEventListener("change", ...)がチェック変更を受け取り、studyItem.done = checkbox.checkedが画面の状態をオブジェクトへ戻す場所です。

一覧を作る流れは次のとおりです。

studyItems
↓
forEach()
↓
studyItemを1件取得
↓
liを作る
↓
checkboxを作る
↓
studyItem.doneをcheckbox.checkedへ反映
↓
spanを作る
↓
studyItem.textを表示
↓
checkboxとspanをliへ追加
↓
liをulへ追加

ユーザー操作からデータへ戻す流れは次のとおりです。

↓

↓

↓

STEP 5

学習項目をブラウザに保存する

PR1-5

なぜJSON.stringify()が必要なのか

studyItemsは、学習内容と完了状態を持つオブジェクトの配列です。

[
  {
    text: "HTMLを復習する",
    done: true
  },
  {
    text: "CSSを復習する",
    done: false
  }
]

localStorageは値を文字列として保存します。配列やオブジェクトをそのまま渡すと、元の構造を正しく保てません。そのため、JSON.stringify()でJSON文字列へ変換して保存します。

const studyItemsJson = JSON.stringify(studyItems);

JSON.stringify()を使うと、配列とその中のオブジェクトを、同じ情報を持つJSON文字列へ変換できます。

studyItemsの配列・オブジェクト
↓
JSON.stringify()
↓
JSON文字列

読み込むときは反対に、JSON文字列をJSON.parse()で配列・オブジェクトへ戻します。

学習項目をlocalStorageへ保存する

学習項目リストでは、自由メモやJSON練習とは別の保存キーを使います。

const studyItemsStorageKey =
  "my-web-study-app:study-items";

保存処理は、何度でも同じ処理を使えるようにsaveStudyItems()という名前付き関数へまとめます。

function saveStudyItems() {
  const studyItemsJson = JSON.stringify(studyItems);

  localStorage.setItem(
    studyItemsStorageKey,
    studyItemsJson
  );
}

最初にJSON.stringify()の結果をstudyItemsJsonへ入れます。次に、そのJSON文字列をlocalStorage.setItem()で保存します。

studyItems
↓
JSON.stringify()
↓
studyItemsJson
↓
localStorage.setItem()

追加したあとに保存する

追加ボタンを押したときは、新しい学習項目を配列へ追加したあとで保存します。

studyItems.push(studyItem);

saveStudyItems();
renderStudyItems();

push()より先に保存すると、新しい項目がまだ配列へ入っていません。そのため、追加してから最新のstudyItemsを保存します。

新しい学習項目を作る
↓
push()で配列へ追加
↓
saveStudyItems()で保存
↓
renderStudyItems()で表示

チェック変更後に保存する

チェックボックスを操作したときは、最初に現在のチェック状態をdoneへ戻します。

checkbox.addEventListener("change", function () {
  studyItem.done = checkbox.checked;

  saveStudyItems();
});

studyItem.doneを変更したあとにsaveStudyItems()を実行するため、最新の完了状態が保存されます。

checkbox.checked
↓
studyItem.done
↓
saveStudyItems()

保存したデータを読み込む

保存した学習項目は、loadStudyItems()という名前付き関数で読み込みます。

function loadStudyItems() {
  const savedStudyItems =
    localStorage.getItem(studyItemsStorageKey);

  if (savedStudyItems !== null) {
    // 保存データがある場合の処理
  }
}

localStorage.getItem()の結果をsavedStudyItemsへ入れます。保存データがない場合はnullになるため、nullではない場合だけ復元処理へ進みます。

localStorage.getItem()
↓
保存データを取得
↓
保存データがない場合はnull
↓
nullではない場合だけ、このあとの復元処理へ進む

JSON.parse()で元の配列へ戻す

localStorage.getItem()で読み込んだ値はJSON文字列です。配列やオブジェクトとして使うために、JSON.parse()で元の形へ戻します。

const restoredStudyItems =
  JSON.parse(savedStudyItems);

復元した配列は、分かりやすいようにrestoredStudyItemsという変数へ入れます。

保存するときは、配列・オブジェクトからJSON文字列へ変換しました。読み込むときは、その逆向きです。

JSON文字列
↓
JSON.parse()
↓
配列・オブジェクト

constの配列へデータを戻す

学習項目を保持するstudyItemsは、PR1-2から使っているconstの配列です。

const studyItems = [];

constの変数へ別の配列を直接代入することはできませんが、配列の中身はpush()で変更できます。

restoredStudyItems.forEach(function (studyItem) {
  studyItems.push(studyItem);
});

forEach()で復元した配列から学習項目を1件ずつ取り出し、既存のstudyItemsへpush()します。

restoredStudyItems
↓
forEach()
↓
studyItemを1件取得
↓
studyItems.push(studyItem)

renderStudyItems()で画面へ復元する

STEP 6

学習項目を1件削除する

PR1-6

なぜ削除機能が必要なのか

間違えて追加した項目や、不要になった項目を1件ずつ取り除けるようにします。残したい項目や完了状態はそのまま保ちます。

削除ボタンを押すと確認画面が開き、OKを押した場合だけ削除します。キャンセルした場合は、配列も保存データも変更しません。

削除ボタンをJavaScriptで作る

forEach()の中で、各学習項目に対応するbutton要素を作ります。学習項目が3件なら、削除ボタンも3個作られます。

const deleteButton = document.createElement("button");
deleteButton.type = "button";
deleteButton.textContent = "削除";
deleteButton.className = "study-item-delete-button";

type = "button"で通常のボタンにし、textContentで「削除」と表示します。classNameは削除ボタン用のCSSにつなげます。

クリック時の処理を登録した後、appendChild()でチェックボックス、学習内容、削除ボタンの順にliへ入れます。

listItem.appendChild(checkbox);
listItem.appendChild(itemText);
listItem.appendChild(deleteButton);
li
├─ checkbox
├─ span（学習内容）
└─ button（削除）
削除したい学習項目を特定する 
studyItems.forEach(function (studyItem, index) {
  // 学習項目と、その位置を使って処理します。
});

studyItemは今処理している学習項目オブジェクト、indexはその項目が配列の何番目にあるかを表す番号です。

indexは0から始まります。1件目は0、2件目は1、3件目は2です。各削除ボタンのクリック処理で、このindexを使って対象を指定します。

削除後は一覧を作り直すので、残った項目の新しい位置に対応するindexで、ボタンの処理も登録し直されます。

削除前に表示する確認文 
const shouldDelete = confirm(
  "「" + studyItem.text + "」を削除しますか？"
);

if (shouldDelete === false) {
  return;
}

studyItem.textを文字列とつなげると、「CSSを復習する」を削除しますか？のように、対象の学習項目名を確認画面へ表示できます。

confirm()は、OKならtrue、キャンセルならfalseを返します。この結果をshouldDeleteへ入れます。

falseならreturn;でクリック時の処理を終了します。削除や保存より前に確認するため、キャンセルした場合は何も変更されません。

splice()で配列から1件削除する

配列から削除する基本形は、splice(開始位置, 削除する個数)です。

studyItems.splice(index, 1);

indexは削除を開始する位置、1は削除する個数です。たとえばindexが1なら、2件目の学習項目を1件だけ削除します。

push()は配列の末尾へ追加します。今回のsplice()は、配列の指定した位置から要素を削除します。

const studyItems = [];の配列自体を別の配列に置き換えず、その中身を変更します。

削除後に保存して画面を更新する 
studyItems.splice(index, 1);
saveStudyItems();
renderStudyItems();

配列から削除しただけでは、localStorageに削除前のデータが残っています。saveStudyItems()で削除後の配列を保存すると、再読み込みしても削除した項目は戻りません。

その後、renderStudyItems()で一覧を作り直し、残った項目を表示します。

↓
保存する
↓
画面を更新する

保存キーとJSONの形式はこれまでと同じです。removeItem()やclear()は使いません。

STEP 6の処理を上から読む

PR1-6のJavaScript全体は次のコードです。追加時の前後の空白除去・空入力防止・入力欄クリア・フォーカスと、チェック状態の保存も含みます。

// 実践エリアで使用するHTML要素を取得します。
const studyItemInput = document.getElementById("study-item-input");
const addStudyItemButton = document.getElementById("add-study-item-button");
const studyItemList = document.getElementById("study-item-list");

// 学習項目リストだけで使用するlocalStorageの保存キーです。
const studyItemsStorageKey = "my-web-study-app:study-items";

// ページ内で使用する学習項目を保持する配列です。
// 保存済みの学習項目はloadStudyItems()でこの配列へ戻します。
const studyItems = [];

// 学習項目の配列をJSON文字列にしてlocalStorageへ保存します。
function saveStudyItems() {
  const studyItemsJson = JSON.stringify(studyItems);

  localStorage.setItem(studyItemsStorageKey, studyItemsJson);
}

// 配列に入っている学習項目を画面へ一覧表示します。
function renderStudyItems() {
  // 前回表示した一覧を一度空にします。
  studyItemList.textContent = "";

  // 配列の学習項目オブジェクトを1件ずつli要素にして追加します。
  studyItems.forEach(function (studyItem, index) {
    const listItem = document.createElement("li");

    // チェックボックスを作り、オブジェクトの完了状態を反映します。
    const checkbox = document.createElement("input");
    checkbox.type = "checkbox";
    checkbox.checked = studyItem.done;

    // 学習内容を表示するspan要素を作ります。
    const itemText = document.createElement("span");
    itemText.textContent = studyItem.text;

    // チェック状態が変わったら、オブジェクトの完了状態へ戻します。
    checkbox.addEventListener("change", function () {
      studyItem.done = checkbox.checked;

      saveStudyItems();
    });

    // 学習項目ごとに削除ボタンを作ります。
    const deleteButton = document.createElement("button");
    deleteButton.type = "button";
    deleteButton.textContent = "削除";
    deleteButton.className = "study-item-delete-button";

    // 削除する学習内容を確認してから、配列の対象項目を1件削除します。
    deleteButton.addEventListener("click", function () {
      const shouldDelete = confirm(
        "「" + studyItem.text + "」を削除しますか？"
      );

      // キャンセルの場合は、削除や保存をせずに処理を終了します。
      if (shouldDelete === false) {
        return;
      }

      // indexの位置から1件削除し、保存してから一覧を作り直します。
      studyItems.splice(index, 1);
      saveStudyItems();
      renderStudyItems();
    });

    listItem.appendChild(checkbox);
    listItem.appendChild(itemText);
    listItem.appendChild(deleteButton);

    studyItemList.appendChild(listItem);
  });
}

// localStorageに保存した学習項目を配列へ戻して画面に表示します。
function loadStudyItems() {
  const savedStudyItems = localStorage.getItem(studyItemsStorageKey);

  if (savedStudyItems !== null) {
    const restoredStudyItems = JSON.parse(savedStudyItems);

    restoredStudyItems.forEach(function (studyItem) {
      studyItems.push(studyItem);
    });
  }

  renderStudyItems();
}

// 追加ボタンを押したとき、学習項目オブジェクトを配列へ追加します。
addStudyItemButton.addEventListener("click", function () {
  // inputから前後の空白を取り除いて学習内容の文字列を取得します。
  const studyItemText = studyItemInput.value.trim();

  // 空文字の場合はここで処理を終了します。
  if (studyItemText === "") {
    return;
  }

  // 1件分の学習項目を表すオブジェクトを作ります。
  const studyItem = {
    // textにはinputから取得した学習内容を保存します。
    text: studyItemText,
    // doneには完了したかどうかを保存します。最初は未完了です。
    done: false
  };

  // 学習項目オブジェクトを配列の末尾へ追加します。
  studyItems.push(studyItem);

  saveStudyItems();
  renderStudyItems();

  // 正常に追加できたら入力欄を空にします。
  studyItemInput.value = "";
  // 続けて入力できるようにフォーカスを戻します。
  studyItemInput.focus();
});

// ページを開いたとき、保存済みの学習項目を読み込みます。
loadStudyItems();
