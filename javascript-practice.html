実践

実践とは？

実践は、これまで学習したJavaScriptを、1つの機能の中で少しずつ組み合わせていくページです。

完成コードを暗記するのではなく、次の処理がどのようにつながっているかを読むことを目的にします。

  • どのHTML要素を取得するか
  • どのイベントを待つか
  • どの値を読み取るか
  • どこへ表示するか
今回作るもの

今回は「学習項目リスト」の最初の段階を作ります。

学習したい内容を入力
↓
追加ボタンを押す
↓
入力した内容を画面へ表示

たとえば、入力欄へ「JavaScriptのJSONを復習する」と入力します。

入力欄：
JavaScriptのJSONを復習する
↓
追加
↓
表示：
JavaScriptのJSONを復習する

今回はまだ配列へ追加しません。入力した1つの内容を、そのまま画面へ表示するだけです。

使うHTML要素

今回は、入力欄・追加ボタン・表示場所の3つのHTML要素を使います。

<input
  type="text"
  id="study-item-input"
>

<button
  type="button"
  id="add-study-item-button"
>追加</button>

<p id="study-item-result"></p>

<input>は、学習したい内容を入力する場所です。id="study-item-input"を使い、JavaScriptのstudyItemInputにつなげます。

<button>は、入力内容を表示するきっかけになる追加ボタンです。id="add-study-item-button"を使い、JavaScriptのaddStudyItemButtonにつなげます。

<p>は、入力内容を画面へ表示する場所です。id="study-item-result"を使い、JavaScriptのstudyItemResultにつなげます。

JavaScriptでHTML要素を見つける

document.getElementById()を使い、HTMLに付けたidから3つの要素を見つけます。

const studyItemInput =
  document.getElementById("study-item-input");

const addStudyItemButton =
  document.getElementById("add-study-item-button");

const studyItemResult =
  document.getElementById("study-item-result");

studyItemInputは入力欄、addStudyItemButtonは追加ボタン、studyItemResultは表示場所のHTML要素を表しています。

HTMLのidとgetElementById()の文字列が同じ名前になることで、それぞれのコードがつながります。

clickイベントを受け取る

addEventListener()を使い、追加ボタンがクリックされるのを待ちます。

addStudyItemButton.addEventListener("click", function () {
  // クリックされた後の処理
});

"click"は待つイベントの種類です。追加ボタンがクリックされると、コールバック関数のfunction () { ... }の中が実行されます。

今回はfunction () { ... }という無名関数を、addEventListener()のコールバック関数として直接渡しています。名前付き関数を使う場合は、関数名だけを書くと関数そのものを渡し、関数名に()を付けるとその場で関数を実行します。

入力した値を読み取って表示する

入力欄に現在入力されている値は、studyItemInput.valueで取得します。

const studyItemText = studyItemInput.value;

studyItemResult.textContent = studyItemText;

取得した値を、最初にstudyItemTextという変数へ入れます。

次に、studyItemResult.textContentへstudyItemTextを入れ、表示場所へ文字を表示します。

処理の流れを上から読む

今回のJavaScript全体は、次のコードです。

const studyItemInput =
  document.getElementById("study-item-input");

const addStudyItemButton =
  document.getElementById("add-study-item-button");

const studyItemResult =
  document.getElementById("study-item-result");

addStudyItemButton.addEventListener("click", function () {
  const studyItemText = studyItemInput.value;

  studyItemResult.textContent = studyItemText;
});

① getElementById()でHTML要素を取得する
↓
② addEventListener()でclickを待つ
↓
③ studyItemInput.valueで入力値を取得する
↓
④ 入力値をstudyItemTextへ保存する
↓
⑤ textContentで画面へ表示する

studyItemInputから値を読み取り、その値をstudyItemResultへ渡すことで、入力欄と表示場所がJavaScriptの処理でつながります。
