<header>

何をするタグ？

ページやセクションの先頭部分をまとめるためのタグです。
見出し・ロゴ・ナビゲーションなどを中に入れることがあります。

基本の書き方 
<header>
  <h1>サイトタイトル</h1>
</header>

画像やロゴ、ナビゲーションなどを中に入れることもあります。

属性名・属性値の例 
<header class="site-header">

属性名：class
属性値：site-header

class は、CSSやJavaScriptからその要素を指定するときに使います。

よく使う場面

ページの上部に、
サイトタイトル・ロゴ画像・ナビゲーションをまとめたり、
背景画像を大きく表示したいときに使います。

実際に使った例 
<header class="site-header">
  <div class="header-inner">
    <h1 class="site-logo">
      <a href="#">LOGO</a>
    </h1>

    <nav class="global-nav">
      <ul>
        <li><a href="#">Home</a></li>
        <li><a href="#">About</a></li>
        <li><a href="#">Contact</a></li>
      </ul>
    </nav>
  </div>
</header>

この例は、次の親子構造になっています。

<header>
└─ .header-inner
   ├─ ロゴ側
   └─ ナビゲーション側

将来的にCSS側では、次のようにロゴとナビゲーションを左右に振り分ける例とつなげて学習できるようにします。

.header-inner {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

今回はこのCSSを実際のstyles.cssには追加せず、学習用の補足として扱います。

背景画像の詳しい指定についても、後でCSS側のbackground-imageなどで扱います。
