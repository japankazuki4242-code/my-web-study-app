Flexbox

Flexboxとは？

Flexboxは、複数の要素を横や縦へ並べ、間隔や位置を調整するためのレイアウト方法です。

ナビゲーション・カード・画像と文章の横並びなどでよく使います。

親要素と子要素 
<div class="box">
  <div class="item">A</div>
  <div class="item">B</div>
</div>
div.box
├─ div.item
└─ div.item

並べたい.itemではなく、その親要素である.boxへdisplay: flex;を書きます。

display: flex 
.box {
  display: flex;
}

親要素をFlexboxにすると、その直接の子要素が並びます。初期状態では基本的に横方向です。

justify-content

justify-contentは、主軸方向の並び方を指定します。

flex-start
→ 主軸の先頭へ寄せる

center
→ 主軸方向の中央へ寄せる

space-between
→ 最初と最後を両端へ置き、間を均等に空ける

.box {
  display: flex;
  justify-content: space-between;
}
align-items

align-itemsは、交差軸方向の揃え方を指定します。

.box {
  display: flex;
  align-items: center;
}

justify-contentは主軸、align-itemsは交差軸を調整します。

gap 
.box {
  display: flex;
  gap: 20px;
}

gapは、Flexbox内の子要素同士の間隔を指定します。

flex-direction / flex-wrap 
.box {
  display: flex;
  flex-direction: column;
  flex-wrap: wrap;
}

flex-direction: row;
→ 基本的に横方向

flex-direction: column;
→ 縦方向

flex-wrap: wrap;
→ 子要素が入りきらない場合に折り返す

flex-directionが変わると主軸の方向も変わります。

実際に使った例

kazuki_HP_practice2では、画像側と文章側を横並びにしています。

.feature-box {
  display: flex;
  justify-content: space-between;
}

画面が狭い場合は、縦並びへ切り替えています。

.feature-box {
  flex-direction: column;
  text-align: center;
}

ヘッダーでは、ロゴとメニューを左右に分け、縦方向の中央を揃えています。

.header-inner {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
