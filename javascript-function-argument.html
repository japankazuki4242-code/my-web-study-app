引数・仮引数

関数へ値を渡す仕組み

関数は、呼び出すときに外から値を受け取り、その値を使って処理できます。

function introduce(name) {
  console.log(name);
}

introduce("かず");

この例では、呼び出すときに渡した"かず"を、関数の中で表示しています。

引数とは？

引数は、関数を呼び出すときに関数へ渡す値です。

introduce("かず");

このコードでは、"かず"が引数です。

引数は、呼び出す関数名の後ろにある()の中へ書きます。

仮引数とは？

仮引数は、関数が受け取る値に付ける名前です。

function introduce(name) {
  console.log(name);
}

このコードでは、関数を定義するときのnameが仮引数です。

受け取った値は、関数の中でnameという名前を使って読み出せます。

値がどこからどこへ渡る？ 
function introduce(name) {
  console.log(name);
}

introduce("かず");

① introduce("かず");
→ 引数として"かず"を渡す

② function introduce(name)
→ 仮引数nameが"かず"を受け取る

③ console.log(name);
→ nameに入った"かず"を表示する

引数の値が、同じ位置にある仮引数へ渡されると考えましょう。

呼び出す値を変えてみる 
introduce("かず");
introduce("あき");

1回目はnameへ"かず"が渡されます。

2回目はnameへ"あき"が渡されます。

同じ関数でも、呼び出すときの引数を変えることで、違う値を使って処理できます。

複数の引数を渡す 
function add(number1, number2) {
  console.log(number1 + number2);
}

add(3, 5);

3
→ 1番目の仮引数number1へ渡る

5
→ 2番目の仮引数number2へ渡る

number1 + number2は3 + 5になるため、8と表示されます。

複数の引数と仮引数は、どちらもカンマ,で区切ります。

コードを1行ずつ読む 
function add(number1, number2) {
  const total = number1 + number2;
  console.log(total);
}

add(3, 5);

① function add(number1, number2) { ... }
→ add関数を定義する
→ この時点では関数内の処理はまだ実行しない

② add(3, 5);
→ 関数を呼び出し、3と5を渡す

③ 3がnumber1、5がnumber2へ渡る

④ const total = number1 + number2;
→ 3 + 5を計算して、totalへ保存する

⑤ console.log(total);
→ 8を表示する

確認問題 
function showScore(name, score) {
  console.log(name);
  console.log(score);
}

showScore("かず", 80);

① 仮引数は何ですか？

② 引数は何ですか？

③ nameへ渡る値は何ですか？

④ scoreへ渡る値は何ですか？

確認問題の答え

① nameとscore

② "かず"と80

③ "かず"

④ 80

1番目の引数は1番目の仮引数へ、2番目の引数は2番目の仮引数へ渡ります。

今回の学習ポイント

引数
→ 関数を呼び出すときに渡す値

仮引数
→ 関数が受け取る値に付ける名前

複数ある場合は、引数と仮引数の位置を順番に対応させて読みましょう。
