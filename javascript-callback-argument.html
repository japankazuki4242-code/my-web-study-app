コールバック関数へ値を渡す

コールバック関数にも値を渡せる

通常の関数と同じように、コールバック関数を実行するときにも引数を渡せます。

callback("かず");

callbackに入っている関数を実行し、その関数へ"かず"を引数として渡しています。

callbackにどの関数が入っているかを確認すると、値の行き先を追いやすくなります。

小さなコード例 
function call(callback) {
  callback("かず");
}

function introduce(name) {
  console.log(name);
}

call(introduce);

introduce関数そのものをcall関数へ渡しています。

call関数の中でcallback("かず");を実行すると、実際にはintroduce("かず");が実行されます。

2つの仮引数を区別する 
function call(callback) {
  callback("かず");
}

function introduce(name) {
  console.log(name);
}

call関数の仮引数callback
→ コールバック関数そのものを受け取る

introduce関数の仮引数name
→ introduce関数が実行されたときに文字列を受け取る

外側のcall関数と、コールバックになるintroduce関数には、それぞれ別の仮引数があります。

関数が渡る流れ

call(introduce);を実行する

introduce
↓
callbackに入る

この時点では、introduce関数そのものがcallbackへ渡されたと考えます。

introduceには()を付けていないため、渡す前には実行しません。

値が渡る流れ

callback("かず")
↓
実際にはintroduce("かず")が実行される

"かず"
↓
introduceの仮引数nameへ渡る

console.log(name);
↓
nameに入った「かず」を表示する

通常の引数・仮引数と同じく、呼び出すときの値が、実行される関数の仮引数へ渡ります。

実行順を1つずつ追う

① call関数を定義する
→ 中の処理はまだ実行しない

② introduce関数を定義する
→ 中の処理はまだ実行しない

③ call(introduce);で、introduce関数そのものを渡す

④ introduceがcallbackへ入る

⑤ callback("かず");を実行する
→ 実際にはintroduce("かず");を実行する

⑥ "かず"が仮引数nameへ渡る

⑦ console.log(name);で「かず」を表示する

確認問題 
function run(callback) {
  callback("完了");
}

function showMessage(message) {
  console.log(message);
}

run(showMessage);

① run関数が受け取るコールバック関数は何ですか？

② "完了"は、どの仮引数へ渡りますか？

③ コンソールには何と表示されますか？

確認問題の答え

① showMessage関数です。

② showMessage関数の仮引数messageへ渡ります。

③ 完了と表示されます。

callback("完了")は、実際にはshowMessage("完了")として実行されます。

今回の学習ポイント

コールバック関数を実行するときも、通常の関数と同じように引数を渡せます。

外側の関数が関数そのものを受け取る仮引数と、コールバック関数が値を受け取る仮引数を区別しましょう。

callback("かず")を見たら、callbackに入っている実際の関数名へ置き換えて考えると読みやすくなります。
