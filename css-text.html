文字

font-size 
h1 {
  font-size: 28px;
}

font-sizeは文字サイズを指定します。

font-weight 
.normal {
  font-weight: normal;
}

.bold {
  font-weight: bold;
}

.weight-400 {
  font-weight: 400;
}

.weight-700 {
  font-weight: 700;
}

font-weightは文字の太さを指定します。Version 1ではnormal・bold・400・700を基本として扱います。

font-family 
body {
  font-family: Arial, "Helvetica Neue",
    "Hiragino Kaku Gothic ProN",
    "Hiragino Sans",
    Meiryo,
    sans-serif;
}

ブラウザは左から順番に、端末で利用できるフォントを探します。

ArialやMeiryoは1単語の具体的なフォント名なので、基本的に引用符なしで書けます。

"Helvetica Neue"や"Hiragino Sans"はスペースを含む具体的なフォント名です。複数単語でも引用符なしで書ける場合がありますが、初心者向けには引用符で囲む書き方が安全で分かりやすいです。

sans-serifは特定のフォント名ではなく、CSSの総称フォントを表すキーワードなので引用符を付けません。

"sans-serif"と書くと、総称フォントではなく「sans-serif」という名前のフォントを探す意味になります。

line-height 
p {
  font-size: 16px;
  line-height: 1.7;
}

font-sizeは文字そのものの大きさ、line-heightは1行分の高さを指定します。

text-align 
h1 {
  text-align: center;
}

text-alignは、要素内の文字やインライン要素の横方向の揃え方を指定します。centerは中央揃えです。

text-decoration / letter-spacing 
a {
  text-decoration: none;
}

h1 {
  letter-spacing: 5px;
}

text-decorationは下線などの文字装飾を指定します。noneは装飾を表示しません。

letter-spacingは文字と文字の間隔を指定します。

line-heightは行と行、letter-spacingは文字と文字の間隔です。

実際に使った例

Black Coffee・kazuki_HP_practice2・Progate模写では、同じシステムフォントの候補を使用しています。

body {
  font-family: Arial, "Helvetica Neue",
    "Hiragino Kaku Gothic ProN",
    "Hiragino Sans",
    Meiryo,
    sans-serif;
}

kazuki_HP_practice2では、説明文に文字サイズ・文字色・行の高さ・下余白を指定しています。

.text-area-desc {
  font-size: 16px;
  color: #555;
  line-height: 1.5;
  margin-bottom: 30px;
}

Progate模写では、トップの見出しに文字間隔を指定しています。

.top-wrapper h1 {
  letter-spacing: 5px;
}
