名前付き関数と無名関数

名前付き関数とは？

名前付き関数は、関数に名前を付けて定義する書き方です。

function printMessage() {
  console.log("こんにちは");
}

この関数の名前はprintMessageです。

名前があるため、printMessage()と書いて実行したり、printMessageと書いて関数そのものを渡したりできます。

名前付き関数をコールバックにする 
function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

call(printMessage);では、名前付き関数のprintMessageをコールバック関数として渡しています。

()を付けていないため、この場所では実行せず、関数そのものを渡します。

無名関数とは？

無名関数は、関数名を付けずに書く関数です。匿名関数と呼ばれることもあります。

コールバックとして渡している無名関数の部分だけを抜き出すと、次の形です。

function () {
  console.log("こんにちは");
}

これは無名関数の部分を確認するために抜き出した形で、このコードだけをそのまま実行する例ではありません。

functionの後ろに関数名がありません。

無名関数は、別の関数へ渡す場所で、そのまま書くことができます。

無名関数をコールバックにする 
call(function () {
  console.log("こんにちは");
});

call()の()の中へ、名前を付けていない関数を直接書いています。

このfunction () { ... }全体が、call関数へ渡されるコールバック関数です。

定義した場所で今すぐ中の処理を実行するのではなく、call関数の中から呼び出されたときに実行します。

function () { }を1つずつ読む

ここでも、コールバックとして渡している無名関数の部分だけを取り出して読みます。

function () {
  console.log("こんにちは");
}

function
→ 関数を作るときに使うキーワード

()
→ 仮引数を書く場所。この例では値を受け取らないため空

{ }
→ 関数が実行されたときの処理を書く場所

console.log("こんにちは");
→ 関数が実行されたときに行う処理

functionと()の間に名前がないため、無名関数です。

2つの書き方を比べる

名前付き関数

function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

無名関数

call(function () {
  console.log("こんにちは");
});

書き方は違いますが、どちらもcall関数へコールバック関数を渡しています。

名前付き関数は先に名前を付けて定義し、無名関数は渡す場所でそのまま定義しています。

今はアロー関数の書き方へ広げず、functionを使った2つの形を読めれば大丈夫です。

無名関数を使った実行順 
function call(callback) {
  callback();
}

call(function () {
  console.log("こんにちは");
});

① call関数を定義する
→ この時点では中の処理を実行しない

② function () { ... }で無名関数を作る
→ ここでも中の処理はまだ実行しない

③ 無名関数そのものをcall関数へ渡す

④ 無名関数が仮引数callbackへ入る

⑤ callback();で無名関数を実行する

⑥ コンソールに「こんにちは」と表示する

確認問題 
function run(callback) {
  callback();
}

run(function () {
  console.log("開始");
});

① このコールバック関数には名前がありますか？

② この無名関数はどの仮引数へ渡り、どのコードで実行されますか？

③ 関数が実行されると、何と表示されますか？

確認問題の答え

① 名前はありません。無名関数です。

② 仮引数callbackへ渡り、callback();で実行されます。

③ 開始と表示されます。

run関数へ渡された無名関数がcallbackに入り、callback();によって実行されます。

今回の学習ポイント

名前付き関数と無名関数は、どちらもコールバック関数として使えます。

名前付き関数は、call(printMessage);のように関数名を使って渡します。

無名関数は、call(function () { ... });のように渡す場所でそのまま書けます。
