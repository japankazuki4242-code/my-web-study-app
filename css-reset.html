リセットCSS

リセットCSSとは？

ブラウザには、h1・p・ulなどへ最初から標準のCSSが設定されています。

リセットCSSは、ブラウザ標準の余白や見た目などを整え、自分でCSSを書きやすくするためのCSSです。

なぜリセットするの？

ブラウザ標準の見た目が残っていると、自分では指定していない余白などが表示されることがあります。

最初に基準となる状態を整えると、その後のサイズや余白を自分で指定しやすくなります。

リセット方法は1つだけではなく、制作物に合わせて選びます。

基本のリセットCSS 
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

*
→ すべての要素を選ぶ

margin: 0
→ 外側の標準余白を0にする

padding: 0
→ 内側の標準余白を0にする

box-sizing: border-box
→ widthやheightの内側にpaddingとborderを含め、サイズを計算しやすくする

Destyleを使う方法

Destyleは、ブラウザ標準の見た目を整えるためのリセットCSSの1つです。

掲載コード：Destyle v4.0.1
取得元：公式GitHub
ライセンス：MIT License

※最新版は公式GitHubも確認してください。

公式GitHubで最新版を見る

CDNで読み込む

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css@4.0.1/destyle.min.css">

この1行をHTMLの<head>内に書くと、jsDelivr経由でDestyle v4.0.1のCSSを読み込みます。

CDNの<link>は、それ自体がリセット処理をするコードではありません。Destyle本体のCSSファイルを読み込むための指定です。

HTML
↓
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css@4.0.1/destyle.min.css">
↓
jsDelivrからDestyle v4.0.1を読み込む
↓
多数のリセット指定がブラウザへ適用される

Destyle全文は、1つの巨大な特別な命令ではありません。

body・h1〜h6・ul・ol・buttonなど、HTML要素や状態ごとにCSSセレクタを指定し、標準の余白・文字の見た目・リスト記号・サイズ計算などを1つずつ整えるCSSの集まりです。

HTML要素
↓
Destyle内のセレクタで指定
↓
ブラウザ標準の見た目を整える

全部を覚える必要はありません。普段は上にあるCDNコード1行を<head>内へ書けば、Destyle全文を自分で貼り付けなくても利用できます。

代表的なリセット指定

body {
  margin: 0;
}

ブラウザがbodyへ最初から付ける余白を0にします。

h1,
h2,
h3,
h4,
h5,
h6 {
  font-size: inherit;
  font-weight: inherit;
  margin: 0;
}

見出しにブラウザが標準で付ける文字サイズ・太さ・余白などを整えます。

ul,
ol {
  margin: 0;
  padding: 0;
  list-style: none;
}

リストの標準余白を0にし、標準の箇条書き記号を表示しない状態にします。

*,
::before,
::after {
  box-sizing: border-box;
  border-style: solid;
  border-width: 0;
  min-width: 0;
}

多くの要素と、その前後に作られる要素について、サイズ計算や境界線などの基本状態を整えます。

読み込み順に注意 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css@4.0.1/destyle.min.css">
<link rel="stylesheet" href="style.css">

1. Destyleを先に読み込む
→ ブラウザ標準の見た目を整える

2. style.css
→ 自分のデザインを指定する

Destyleでブラウザ標準の見た目を整えたあと、自分のCSSでデザインを指定します。

実際に使った例

Black Coffeeでは、すべての要素のmarginとpaddingを0にしています。

* {
  padding: 0;
  margin: 0;
}

Progate模写では、余白のリセットに加えてbox-sizingも指定しています。

* {
  padding: 0;
  margin: 0;
}

* {
  box-sizing: border-box;
}

kazuki_HP_practice2では、HTMLからDestyle v4.0.0のCDNを自作CSSより先に読み込んでいます。

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css@4.0.0/destyle.min.css">
<link rel="stylesheet" href="./style.css">

このように、簡単なリセットを自分で書く方法と、Destyleなどを読み込む方法があります。

注意点

完成済みのサイトへ途中からリセットCSSを追加すると、これまで表示されていた余白・文字サイズ・リスト記号などが変化する場合があります。

追加後は一部分だけでなく、ページ全体を確認します。

このWeb学習アプリには、表示を壊さないため、今回Destyleを実際の共通CSSとして追加していません。
