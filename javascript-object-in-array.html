配列の中にオブジェクト

配列の要素にオブジェクトを入れる

配列の1つ1つの要素として、オブジェクトを入れることができます。

複数のユーザー情報を1つの配列へまとめるときは、次のように書けます。

基本コード 
const users = [
  { name: "かず", age: 50 },
  { name: "太郎", age: 30 }
];

usersは配列です。その配列の中に、2つのオブジェクトが要素として入っています。

usersの階層を確認する

users
→ 配列

users[0]
→ 配列のindex 0の要素

{ name: "かず", age: 50 }
→ users[0]に入っているオブジェクト

name・age
→ そのオブジェクトのプロパティ名

"かず"・50
→ それぞれのプロパティの値

1つのオブジェクトであり、1つの要素 
{ name: "かず", age: 50 }

オブジェクトとして見る
→ nameとageを持つ1つのオブジェクト

users配列から見る
→ index 0に入っている1つの要素（値）

同じデータでも、どのまとまりから見ているかによって「オブジェクト」と「配列の要素」という2つの見方ができます。

最初のユーザー名を取り出す 
console.log(users[0].name);

実行結果は次のとおりです。

かず

users[0].nameを一度に覚えるのではなく、左から1段ずつたどります。

左から1段ずつたどる

users
↓ 配列

users[0]
↓ index 0の要素を指定

{ name: "かず", age: 50 }
↓ その要素はオブジェクト

users[0].name
↓ nameプロパティを見る

"かず"
→ 最後に取り出される値

users[0].nameを分けて読む

users
→ 配列

[0]
→ index 0の要素を指定

index 0の要素
→ オブジェクト

.name
→ nameプロパティを見る

結果
→ "かず"

2番目のユーザー名を取り出す 
console.log(users[1].name);

users[1]は、index 1にある2番目のオブジェクトです。

そのオブジェクトのnameプロパティを見るため、結果は次のようになります。

太郎
今回の学習ポイント

配列の要素には、オブジェクトを入れることができます。

値を取り出すときは、「配列を選ぶ → indexで要素を選ぶ → そのオブジェクトのプロパティを見る」と左から順番にたどりましょう。
