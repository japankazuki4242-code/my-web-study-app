callback()では何が実行される？

callbackは仮引数 
function call(callback) {
  callback();
}

callbackは、call関数が値を受け取るための仮引数です。

callbackという名前の特別な関数が、JavaScriptに最初から用意されているわけではありません。

仮引数の名前は自分で決められますが、受け取る値がコールバック関数だと分かりやすいため、ここではcallbackとしています。

呼び出し時に渡された関数が入る 
function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

call(printMessage);を実行すると、printMessage関数そのものが仮引数callbackへ渡ります。

この呼び出しの間、callbackにはprintMessage関数が入っていると考えられます。

printMessageへ()を付けていないので、渡す前には実行しません。

callback()で入っている関数を実行する 
callback();

callbackの後ろに()があるため、callbackに入っている関数をその時点で実行します。

今回の例ではcallbackにprintMessageが入っているため、callback()は実際にはprintMessage()を実行することになります。

その結果、コンソールに「こんにちは」と表示されます。

値が渡って実行される流れ 
function call(callback) {
  callback();
}

function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

printMessage
↓
callbackに渡る

callback()
↓
callbackに入っている関数を実行する

printMessageが実行される
↓
「こんにちは」と表示される

コードを1行ずつ読む

① function call(callback) {
→ 仮引数callbackで値を受け取るcall関数を定義する

② callback();
→ 受け取った関数を実行する処理を書く

③ function printMessage() {
→ printMessage関数を定義する

④ console.log("こんにちは");
→ printMessageが実行されたときの処理を書く

⑤ call(printMessage);
→ printMessage関数そのものをcall関数へ渡す

関数を定義した行では、その関数の中の処理はまだ実行されません。

実行順を追う

① call関数とprintMessage関数を定義する

② call(printMessage);でcall関数を呼び出す

③ printMessage関数そのものがcallbackへ入る

④ call関数の中にあるcallback();へ進む

⑤ callbackに入っているprintMessage関数を実行する

⑥ 「こんにちは」と表示する

確認問題 
function run(task) {
  task();
}

function showMessage() {
  console.log("完了");
}

run(showMessage);

① この例で、コールバック関数を受け取る仮引数は何ですか？

② task()では、実際にどの関数が実行されますか？

③ taskはJavaScriptに最初からある特別な関数ですか？

確認問題の答え

① taskです。

② showMessage関数です。

③ 特別な関数ではありません。run関数の仮引数として自分で付けた名前です。

run(showMessage);によってshowMessageがtaskへ入り、task()で実行されます。

今回の学習ポイント

callbackは、関数を受け取るために付けた仮引数の名前です。

呼び出し時に渡された関数がcallbackへ入ります。

callback()は、その時点でcallbackに入っている関数を実行します。
