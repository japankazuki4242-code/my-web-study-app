JavaScriptでできること

画面を操作する

ボタンを押したら処理する
→ 保存ボタンを押したときに、メモを保存する

文字を書き換える
→ 保存が終わったら、画面へ「保存しました」と表示する

表示／非表示を切り替える
→ 必要な説明だけを画面に表示する

入力と条件を扱う

入力した内容を取得する
→ 入力欄に書かれたメモの文章を受け取る

条件によって処理を変える
→ 保存されたメモがあるときだけ、入力欄へ表示する

データを保存・読み込む

データを保存する
→ 入力したメモをブラウザへ保存する

保存したデータを読み込む
→ ページを開いたときに、前に保存したメモを表示する

JavaScriptが担当すること

JavaScriptは「画面を動かす」だけではありません。

値を受け取り、条件を判断し、データを保存し、画面の表示を変えるなど、Webページの処理を担当します。
