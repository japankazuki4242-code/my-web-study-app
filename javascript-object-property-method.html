プロパティとメソッドの読み方

プロパティとメソッドを整理する

プロパティ
→ オブジェクトなどが持っている情報や値

メソッド
→ オブジェクトが持っている処理や機能

どちらも.を使ってアクセスします。コードを読むときは、.の右側に何があるのかを確認します。

プロパティの例 
fruits.length
user.name

fruits.length
→ fruitsが持っている要素数を見る
→ lengthプロパティ

user.name
→ userが持っている名前の値を見る
→ nameプロパティ

どちらも、.の右側に情報や値を表すプロパティがあります。

user.nameを分けて読む 
user.name

user
→ オブジェクト

.
→ 持っているものへアクセスする

name
→ プロパティ

()は付いていません。このコードでは処理を実行するのではなく、nameプロパティの値を見ています。

メソッドの例 
console.log()
console.table()

console.log()
→ logメソッド

console.table()
→ tableメソッド

どちらも、consoleオブジェクトが持っている処理や機能を()で実行しています。

console.log()を分けて読む 
console.log()

console
→ オブジェクト

.
→ 持っているものへアクセスする

log
→ メソッド

()
→ メソッドを実行する

localStorageのメソッドを読む 
localStorage.setItem("key", "value");
localStorage.getItem("key");
localStorage.removeItem("key");

localStorage.setItem()
→ setItemメソッド

localStorage.getItem()
→ getItemメソッド

localStorage.removeItem()
→ removeItemメソッド

localStorageという同じオブジェクトでも、.の右側に書くメソッドによって実行する処理が変わります。

プロパティとメソッドを並べる

fruits.length
→ lengthプロパティ

user.name
→ nameプロパティ

console.log()
→ logメソッド

console.table()
→ tableメソッド

localStorage.setItem()
→ setItemメソッド

プロパティかメソッドかを考えるときは、.の右側が情報・値なのか、実行する処理・機能なのかを確認します。

初心者向けの覚え方

.プロパティ
→ 情報や値を見る

.メソッド()
→ 処理を実行する

まずはこの違いを使ってコードを読み分けましょう。
