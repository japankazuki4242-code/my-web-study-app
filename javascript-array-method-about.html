配列メソッドとは？

メソッドの復習

メソッドは、オブジェクトが持っている関数です。

「どの値が持つ機能なのか」を左側で確認し、ドット.の右側にあるメソッド名を読みます。

値.メソッド名()

()が付いているため、そのメソッドを実行する形です。

配列メソッドとは？

配列には、要素を追加したり、1つずつ処理したりする便利なメソッドがあります。

配列が持っているこれらの処理を、配列メソッドとして使えます。

const fruits = ["りんご", "みかん"];

fruits.push("バナナ");

この例では、配列fruitsが持つpush()メソッドを使っています。

array.method()の形 
array.method()

array
→ メソッドを使う配列

.
→ 配列と、その配列が持つメソッドをつなぐ

method
→ 実行したいメソッドの名前

()
→ メソッドを実行する

実際のコードを分けて読む 
fruits.push("バナナ");

fruits
→ 配列名

.
→ fruitsが持つ機能へアクセスする

push
→ 配列の末尾へ追加するメソッド名

("バナナ")
→ pushメソッドを実行し、追加する値を渡す

これから学ぶ5つのメソッド

push()
→ 配列の末尾へ要素を追加する

forEach()
→ 配列の要素を1つずつ処理する

find()
→ 条件に合う最初の1つを探す

filter()
→ 条件に合う要素をすべて集める

map()
→ 各要素から新しい値を作る

今は役割の違いを大まかに確認し、次のページから1つずつ学びます。

コードの実行順を上から読む 
const numbers = [10, 20];

numbers.push(30);

console.log(numbers);

① numbersという配列を作る

② numbers.push(30);で、配列の末尾へ30を追加する

③ console.log(numbers);で、追加後の配列を表示する

実行結果は[10, 20, 30]です。

確認問題 
const colors = ["赤", "緑"];

colors.push("青");

① 配列名は何ですか？

② メソッド名は何ですか？

③ .は何をつないでいますか？

④ ()の中に渡している値は何ですか？

確認問題の答え

① colorsです。

② pushです。

③ 配列colorsと、その配列が持つpushメソッドをつないでいます。

④ "青"です。

今回の学習ポイント

配列メソッドは、配列が持っている便利な処理です。

基本の形は配列名.メソッド名()です。

コードを読むときは、配列名・ドット・メソッド名・丸括弧に分けて確認しましょう。
