メソッドとは？

メソッドは、オブジェクトが持っている処理や機能です。

オブジェクトが持っているメソッドを使うときは、「オブジェクト名.メソッド名()」という形で書きます。

console.log()を確認する 
console.log("こんにちは");

このコードを実行すると、コンソールに「こんにちは」と表示されます。

これまで使ってきたconsole.log()も、オブジェクトが持っているメソッドを実行する書き方です。

console.log()を分けて読む
書き方 意味
console オブジェクト
. consoleが持っているものへアクセスする
log メソッド
() メソッドを実行する

console.log()は、「consoleオブジェクトが持っているlogメソッドを実行する」と読みます。

console.log()とconsole.table() 
console.log(data);
console.table(data);

console
→ どちらも同じオブジェクト

log()
→ consoleが持っているlogメソッド

table()
→ consoleが持っているtableメソッド

.の右側を変えることで、同じconsoleオブジェクトが持つ別のメソッドを実行できます。

ここでは、表示方法の細かな違いではなく、呼び出すメソッドが違うことを確認しましょう。

localStorageが持っているメソッド 
localStorage.setItem("key", "value");
localStorage.getItem("key");
localStorage.removeItem("key");

localStorage
→ オブジェクト

setItem()
→ データを保存するメソッド

getItem()
→ データを読み出すメソッド

removeItem()
→ データを削除するメソッド

3つとも、localStorageオブジェクトが持っているメソッドです。

共通する形を見つける 
オブジェクト.メソッド()

console.log()やlocalStorage.setItem()は別の機能ですが、どちらも「オブジェクト.メソッド()」という共通した形です。

今まで決まった書き方として使ってきたコードも、「どのオブジェクトが持つ、どのメソッドを実行するのか」と分けると読みやすくなります。

今回の学習ポイント

メソッドは、オブジェクトが持っている処理や機能です。

オブジェクト
→ どのオブジェクトが持つ機能か

メソッド
→ どの処理や機能を使うか

()
→ メソッドを実行する
