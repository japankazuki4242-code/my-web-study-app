<code>

何をするタグ？

<code>は、プログラムのコードであることを意味として表すタグです。

文章の途中に短いコードを表示するときは、<code>を単独で使えます。

<p>JavaScriptでは <code>console.log()</code> を使います。</p>

複数行のコードでは、<pre>と<code>を組み合わせて使うことがよくあります。

基本の書き方

文章の途中に短いコードを書く例：

<p>JavaScriptでは <code>console.log()</code> を使います。</p>

開始タグ<code>と終了タグ</code>の間に、コードとして示したい内容を書きます。

複数行のコードを書く例：

<pre><code>
const message = "Hello";
console.log(message);
</code></pre>

<pre>は改行や空白を保つ役割、<code>は「これはコードです」という意味を持たせる役割があります。

2つはよく一緒に使いますが、必ずセットで使うタグではありません。

属性名・属性値の例 
<code class="inline-code">console.log()</code>

属性名：class
属性値：inline-code

classを付けると、CSSやJavaScriptからこの<code>を指定できます。

HTML：

class="inline-code"

CSS：

.inline-code

CSSでclassを指定するときは、class名の前に.（ドット）を付けます。

inline-codeは学習用のclass名の例です。

よく使う場面

<code>は、HTML・CSS・JavaScriptなどのコードを文章やページ内に表示するときに使います。

  • 文章の途中にタグ名や命令を書くとき
  • 関数名や変数名をコードとして示すとき
  • 複数行のコード例を表示するとき

短いコードは<code>だけで表示できます。

複数行のコードでは、改行や空白を保つ<pre>の中に<code>を書く方法がよく使われます。

実際に使った例

このWeb学習アプリでは、HTMLやCSSのコード例をコードとして示すために<code>を使っています。

<pre><code>
<details>
  <summary>詳しく見る</summary>
</details>
</code></pre>

<pre>
→ 改行やインデントを保ったまま表示する

<code>
→ 中の内容がプログラムコードであることを表す

文章中の短いタグ名を示す場合は、<code>だけを使っています。
