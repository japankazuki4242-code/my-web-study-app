localStorageの書き方を読む

コード全体を確認する

次のコードは、localStorageへデータを保存する基本的な書き方です。

localStorage.setItem("userName", "かず");

"userName"というkeyと、"かず"というvalueをセットにして保存しています。

localStorage.setItemを読む
書き方 意味
localStorage ブラウザの保存機能
. localStorageとsetItemをつなぐ
setItem データを保存するメソッド

.の左側にあるlocalStorageが持っている、setItemという機能を使う、と読みます。

丸括弧の中を読む
記号・値 意味
( 引数の開始
"userName" 保存する場所の名前であるkey
, 引数の区切り
"かず" 保存する中身であるvalue
) 引数の終了
; 1つの処理の終了

メソッドへ渡す値を引数といいます。setItem()では、keyとvalueの2つを引数として渡します。

変数と文字列の違い
書き方 表しているもの
freeMemoStorageKey 値を入れておく変数
"freeMemoStorageKey" 引用符で囲まれた文字列そのもの

引用符がないfreeMemoStorageKeyを書くと、変数の中に入っている値が使われます。

引用符で囲んだ"freeMemoStorageKey"を書くと、「freeMemoStorageKey」という文字そのものが使われます。

改行しても同じ処理

このアプリでは、読みやすくするために引数ごとに改行しています。

localStorage.setItem(
  freeMemoStorageKey,
  freeMemoText
);

次のように1行で書くこともできます。

localStorage.setItem(freeMemoStorageKey, freeMemoText);

2つのコードは改行の仕方が違うだけで、基本的には同じ処理です。どちらも、freeMemoStorageKeyをkey、freeMemoTextをvalueとして保存します。
