色・背景

color と background-color 
.box {
  color: white;
  background-color: black;
}

colorは文字色、background-colorは背景色を指定します。

色の指定方法 
.sample-1 {
  color: black;
}

.sample-2 {
  color: #EFA358;
}

.sample-3 {
  color: rgb(239, 163, 88);
}

.sample-4 {
  color: rgba(0, 0, 0, 0.5);
}

色名・16進数・RGB・RGBAなどの方法で色を指定できます。

rgba(R, G, B, A)の順番です。

R → Red / 赤
G → Green / 緑
B → Blue / 青
A → Alpha / 透明度

RGBは基本的に0〜255で指定します。

rgba(255, 0, 0, 1)
→ 赤255・緑0・青0・透明度1なので、不透明な赤

rgba(0, 0, 0, 0.5)
→ RGBがすべて0なので黒、Alphaが0.5なので半透明の黒

Alphaは、0が完全に透明、0.5が半透明、1が不透明です。

background-image 
.hero {
  background-image: url("images/top.jpg");
}

background-imageは、要素の背景に画像を表示します。url()の中に画像ファイルの場所を書きます。

background-size: cover 
.hero {
  background-size: cover;
}

coverは、画像の縦横比を保ちながら背景の領域全体を埋めます。

領域全体を埋めるため、画像の上下または左右が一部切れる場合があります。

background-position 
.hero {
  background-position: center;
}

background-positionは、背景画像を領域内のどこへ合わせるか指定します。centerは中央へ合わせます。

opacity と rgba() 
.box {
  opacity: 0.5;
}

.overlay {
  background-color: rgba(0, 0, 0, 0.5);
}

opacity: 0.5;
→ 要素全体が半透明になり、中の文字や画像にも影響する

rgba(...)
→ 背景色など、指定した色だけの透明度を変更できる

rgba()のカッコ内は、rgba(R, G, B, A)の順番です。

rgba( 0, 0, 0, 0.5 )
      R  G  B    A
      赤 緑 青   Alpha

R → Red / 赤
G → Green / 緑
B → Blue / 青
A → Alpha / 透明・不透明の度合い

RGBは基本的に0〜255の数値で指定します。

rgba(0, 0, 0, 0.5)では、R・G・Bがすべて0なので色は黒です。Aが0.5なので半透明になります。

つまり、rgba(0, 0, 0, 0.5)は「半透明の黒」という意味です。

Alphaは、0が完全に透明、0.5が半透明、1が不透明です。

実際に使った例

kazuki_HP_practice2では、ファーストビューを背景画像で表示しています。

.fv {
  height: 603px;
  background-image: url("./img/fv 1.jpg");
  background-size: cover;
  background-position: center;
}

Progate模写でも、ファーストビューに背景画像・cover・centerを使っています。

.top-wrapper {
  background-image: url(https://prog-8.com/images/html/advanced/top.png);
  background-size: cover;
  background-position: center;
}

Progate模写の固定ヘッダーには、少し透けた背景色が使われています。

header {
  background-color: rgba(34, 49, 52, 0.9);
}
