保存したデータを読む getItem()

getItem()とは？

getItem()は、localStorageに保存されているデータを読み出すメソッドです。

const userName =
  localStorage.getItem("userName");

"userName"というkeyに保存されているvalueを読み出し、userNameという変数へ入れています。

書き方を分けて読む
書き方 意味
localStorage ブラウザの保存機能
getItem() 保存されているデータを読み出すメソッド
"userName" 読み出したいデータのkey
userName 読み出したvalueを入れる変数
読み出しの流れ

getItem()は、指定されたkeyを手がかりにして保存済みのvalueを読み出します。

"userName"というkeyを探す
↓
保存されているvalueを読み出す
↓
userNameという変数へ入れる

保存時と同じkeyを指定することが大切です。

setItem()との違い
メソッド 役割 基本形
setItem() 保存 setItem(key, value)
getItem() 読み出し getItem(key)

setItem()はkeyとvalueを指定します。getItem()は、読み出したいデータのkeyだけを指定します。

保存データがない場合

指定したkeyに保存データが存在しない場合、getItem()はnullを返します。

nullは、ここでは「そのkeyに読み出せるデータがない」ことを表します。

データがない場合も考えて、読み出した結果がnullではないかを確認してから使うことがあります。

このアプリの実際の書き方

このアプリの自由メモでは、次のコードで保存済みのメモを読み出しています。

const savedFreeMemo =
  localStorage.getItem(freeMemoStorageKey);

freeMemoStorageKeyを使って自由メモの保存場所を探し、読み出したvalueをsavedFreeMemoという変数へ入れています。

読み出したメモを入力欄へ表示する

保存済みのメモを読み出した後は、次のコードへつながります。

if (savedFreeMemo !== null) {
  freeMemoInput.value = savedFreeMemo;
}

!==は、「厳密に等しくない」という比較演算子です。

savedFreeMemo !== nullは、「savedFreeMemoがnullではない」という意味です。

保存済みのメモがある場合だけ、その内容をfreeMemoInput.valueへ入れて入力欄に表示します。
