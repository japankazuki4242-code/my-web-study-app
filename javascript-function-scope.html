スコープ

スコープとは？

スコープは、変数や定数を使える範囲のことです。

変数を宣言した場所によって、その変数を使える場所が変わります。

まずは、「関数の外で宣言したか、関数の中で宣言したか」に注目しましょう。

関数の外で宣言した変数 
const userName = "かず";

function greet() {
  console.log(userName);
}

greet();

userNameは関数の外で宣言されています。

この例では、関数の外にあるuserNameを、greet関数の中から使えます。

greet()を呼び出すと、「かず」と表示されます。

関数の中で宣言した変数 
function greet() {
  const message = "こんにちは";
  console.log(message);
}

greet();

messageは、greet関数の中で宣言されています。

同じ関数の{ }の中にあるconsole.log(message);では、messageを使えます。

関数内の変数は外から使えない 
function greet() {
  const message = "こんにちは";
}

console.log(message);

messageを使えるのは、宣言したgreet関数の中だけです。

関数の外にあるconsole.log(message);からは使えないため、実行するとエラーになります。

このページではまず、関数の{ }の内側で宣言したか、外側で宣言したかを目印にして考えます。

グローバルスコープとローカルスコープ

グローバルスコープ
→ 関数の外など、広い範囲で使える場所

ローカルスコープ
→ 関数の中など、限られた範囲だけで使える場所

関数の外で宣言したuserNameは広い範囲で使えます。

関数の中で宣言したmessageは、その関数の中だけで使えます。

まずは用語を暗記するより、「どこで宣言され、どこから使っているか」を確認しましょう。

同じ名前でも別の変数になる場合 
const message = "関数の外";

function showMessage() {
  const message = "関数の中";
  console.log(message);
}

showMessage();
console.log(message);

showMessage()の中
→ 関数の中で宣言したmessageを使うため、「関数の中」と表示する

最後のconsole.log(message);
→ 関数の外で宣言したmessageを使うため、「関数の外」と表示する

名前は同じでも、宣言した範囲が違うため別の変数です。

コードを上から順番に読む 
const appName = "学習アプリ";

function showTitle() {
  const pageName = "関数";
  console.log(appName);
  console.log(pageName);
}

showTitle();

① 関数の外でappNameを宣言する

② showTitle関数を定義する。この時点では中の処理を実行しない

③ showTitle()を呼び出す

④ 関数の中でpageNameを宣言する

⑤ 関数の中から、外側のappNameと内側のpageNameを表示する

確認問題 
const outsideText = "外";

function showText() {
  const insideText = "中";
  console.log(outsideText);
  console.log(insideText);
}

showText();

① 関数の外で宣言されている定数はどれですか？

② 関数の中だけで使える定数はどれですか？

③ showText関数の中からoutsideTextを使えますか？

④ 関数の外からinsideTextを使えますか？

確認問題の答え

① outsideText

② insideText

③ 使えます

④ 使えません

insideTextのスコープは、showText関数の中だけです。

今回の学習ポイント

スコープは、変数や定数を使える範囲です。

関数の外で宣言した変数は関数の中から使えますが、関数の中で宣言した変数は関数の外から使えません。

同じ名前でもスコープが違えば、別の変数になる場合があります。まずは、どこで宣言された変数なのかを確認して読みましょう。
