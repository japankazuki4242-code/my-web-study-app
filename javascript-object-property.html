プロパティとは？

プロパティは、オブジェクトが持っている情報やデータです。

オブジェクトでは、プロパティ名とプロパティの値を組み合わせてデータを管理します。

今回使うオブジェクト 
const user = {
  name: "かず",
  age: 50
};

このuserオブジェクトは、nameとageという2つのプロパティを持っています。

nameプロパティを分けて読む 
name: "かず"

name
→ プロパティ名（key）

:
→ プロパティ名と値の区切り

"かず"
→ プロパティの値（value）

name: "かず"は、「nameというプロパティの値は『かず』」と読みます。

ageプロパティを分けて読む 
age: 50

age
→ プロパティ名（key）

:
→ プロパティ名と値の区切り

50
→ プロパティの値（value）

age: 50は、「ageというプロパティの値は50」と読みます。

keyとvalueの組み合わせ

オブジェクトのプロパティは、keyとvalueの組み合わせで考えられます。

nameというkey
＋
"かず"というvalue

ageというkey
＋
50というvalue

何についてのデータかをkeyで表し、そのデータの中身をvalueとして書きます。

localStorageのkeyとの違い

localStorageでもkeyとvalueを使いますが、オブジェクトのkeyとは使われる場所と役割が違います。

keyの種類 役割
localStorageのkey localStorageに保存したデータを見分ける名前
オブジェクトのプロパティ名（key） オブジェクトの中にある情報を見分ける項目名

同じ「key」という言葉でも、localStorageのkeyなのか、オブジェクトのkeyなのかを区別しましょう。

今回の学習ポイント

プロパティは、オブジェクトが持っている情報やデータです。

プロパティ名（key）
→ 何についてのデータかを表す

プロパティの値（value）
→ そのデータの中身を表す
