関数名と関数名()の違い

introduceとintroduce()を比べる 
introduce
introduce()

この2つは、()があるかどうかで意味が変わります。

introduce
→ 関数そのものを表す

introduce()
→ 関数の中にある処理を実行する

関数名だけを書く場合

関数名だけを書くと、定義した関数そのものを表します。

function introduce() {
  console.log("かずです");
}

const savedFunction = introduce;

introduceに()がないため、この行では関数の処理を実行していません。

savedFunctionには、「かずです」と表示した結果ではなく、introduce関数そのものが入ります。

()を付ける場合

関数名の後ろに()を付けると、その関数を呼び出して処理を実行します。

introduce();

introduce関数の中にあるconsole.log("かずです");が実行されます。

コンソールに「かずです」と表示されるのは、この呼び出しを行ったときです。

同じ関数を別の名前から実行する 
const savedFunction = introduce;

savedFunction();

1行目では、introduce関数そのものをsavedFunctionへ入れています。

3行目では、savedFunctionに()を付けて、入っている関数を実行しています。

そのため、introduce()を呼び出したときと同じように「かずです」と表示されます。

1行ずつ分けて読む 
function introduce() {
  console.log("かずです");
}

const savedFunction = introduce;
savedFunction();

① function introduce() {
→ introduce関数を定義する

② console.log("かずです");
→ 呼び出されたときの処理を決める

③ const savedFunction = introduce;
→ 関数を実行せず、関数そのものを別の名前へ入れる

④ savedFunction();
→ 入っている関数を実行する

「関数そのもの」と「関数を実行する」の違い

関数そのものを使うとき
→ introduceのように、()を付けずに書く

関数そのものは、const savedFunction = introduce;のように別の変数へ入れることができます。

関数を実行するとき
→ introduce()のように、()を付ける

この違いは、後で別の処理へ関数そのものを渡すコードを読むときの基礎になります。

このページではコールバック関数の詳しい説明には進まず、まず()の有無を見分けられれば大丈夫です。

確認問題 
function showMessage() {
  console.log("お知らせ");
}

const task = showMessage;
task();

① 関数を実行せず、関数そのものを値として使っているshowMessageは、どの行にありますか？

② 関数を実行しているのは、どの行ですか？

③ コンソールには何と表示されますか？

確認問題の答え

① const task = showMessage;のshowMessage

② task();

③ お知らせ

showMessageでは関数を実行せず、task()でその関数を実行しています。

今回の学習ポイント

関数名
→ 関数そのものを表す

関数名()
→ 関数を呼び出して実行する

コードを読むときは、関数名の後ろに()が付いているかを確認しましょう。
