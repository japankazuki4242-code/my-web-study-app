<script>

何をするタグ？

<script>は、HTMLからJavaScriptファイルを読み込んだり、HTML内にJavaScriptを書いたりするためのタグです。

Version 1では、外部のscript.jsを読み込む使い方を中心に学びます。

<script>は<meta>や<link>とは異なり、終了タグ</script>が必要です。

基本の書き方 
<script src="script.js"></script>

src="script.js"は、読み込むJavaScriptファイルの場所を指定します。

この指定によって、HTMLと外部JavaScriptファイルがつながります。

外部ファイルを読み込む場合も、終了タグ</script>を書きます。

属性名・属性値の例 
<script src="script.js"></script>

属性名：src
属性値：script.js

srcは、読み込むJavaScriptファイルの場所を指定します。

同じフォルダにあるscript.jsを読み込む、シンプルな相対パスの例です。

よく使う場面

<script>は、クリック時の処理や画面の内容を変える処理など、JavaScriptによる動作をHTMLへつなげるときに使います。

  • ボタンをクリックしたときの処理
  • 入力内容の保存や読み込み
  • 画面表示の切り替え

今回はJavaScriptの高度な内容には広げず、外部ファイルを読み込む基本を扱います。

実際に使った例

現在のmy-web-study-appでは、下部ナビゲーションのBACKボタンを動かすためにscript.jsを読み込んでいます。

<button type="button" id="back-button" class="nav-button">BACK</button>

<script src="script.js"></script>

script.jsでは、id="back-button"のボタンを取得し、クリック時にhistory.back()を実行しています。

const backButton = document.getElementById("back-button");

backButton.addEventListener("click", function () {
  history.back();
});

HTMLがボタンの構造を作り、JavaScriptがBACKの動作を追加しています。
