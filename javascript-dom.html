HTMLを操作する

HTMLを操作するとは？

JavaScriptでは、HTMLに書かれている要素を見つけて、内容を読み取ったり変更したりできます。

たとえば、次のようなことができます。

  • ボタンを見つける
  • 入力欄に書かれた文章を取得する
  • HTML上の文字を変更する

基本の流れ

HTMLに要素がある
↓
JavaScriptがその要素を見つける
↓
内容や値を読み取る
↓
必要なら変更する

自由メモの簡単な例

<textarea id="free-memo-input"></textarea>

HTMLにid="free-memo-input"の入力欄がある
↓
JavaScriptが同じidの要素を見つける
↓
<textarea>に入力された文章を取得する

ここではまず、HTMLとJavaScriptが同じid名でつながることをイメージできれば十分です。

DOMとは？

DOMは、HTMLの内容をJavaScriptから扱えるようにする仕組みです。

HTMLを書く
↓
ブラウザが読み込む
↓
DOMとして扱える形になる
↓
JavaScriptから操作できる

HTMLには、要素が中に入る親子関係があります。

<body>
  <main>
    <h1>Web学習アプリ</h1>
    <button>保存</button>
  </main>
</body>
body
└─ main
   ├─ h1
   └─ button

JavaScriptは、HTMLファイルに書かれた文字そのものを直接書き換えるのではありません。

ブラウザが作ったDOMを通して、HTML要素を読み取ったり変更したりします。

この段階では、DOMは「HTMLとJavaScriptをつなぐ仕組み」と考えると分かりやすいです。

HTML要素を見つける

idを使ってHTML要素を見つけるときは、document.getElementById()を使います。

HTML：

<textarea id="free-memo-input"></textarea>

JavaScript：

document.getElementById("free-memo-input")

document
→ 今ブラウザで開いているHTMLページを扱うもの

.
→ 左側のものが持っている機能や値へつなぐ記号

getElementById()
→ idを使ってHTML要素を探すメソッド

"free-memo-input"
→ 探したいid名

日本語では「このHTMLページから、free-memo-inputというidを持つ要素を探す」という意味です。

documentはオブジェクト、getElementById()はそのオブジェクトが持つメソッドとして読むこともできます。

idとclass、1つと複数の違い

idは同じページ内で重複させず、1つの要素を特定するために使います。

document.getElementById("free-memo-input")

getElementByIdのElementは単数形です。idから1つの要素を探します。

getElementsById()というメソッドは存在しません。

classは、複数の要素に同じ名前を付けられます。

<button class="menu-button">HTML</button>
<button class="menu-button">CSS</button>
<button class="menu-button">JavaScript</button>
document.getElementsByClassName("menu-button")

getElementsByClassNameのElementsは複数形なので、sが付きます。

querySelectorを使う方法

document.querySelector(".menu-button")

CSSセレクタを使って、最初に一致した1つを取得します。

document.querySelectorAll(".menu-button")

CSSセレクタを使って、一致するものをすべて取得します。

getElementById()
→ idから1つ

getElementsByClassName()
→ classから複数

querySelector()
→ CSSセレクタで最初の1つ

querySelectorAll()
→ CSSセレクタで一致するもの全部

このページでは、現在のアプリでも使っているgetElementById()を中心に確認します。

取得した要素を変数へ入れる

const freeMemoInput =
  document.getElementById("free-memo-input");

HTML要素を探す
↓
見つける
↓
freeMemoInputという変数へ入れておく
↓
あとでその要素を使う

HTMLの文字を読み取る・変更する

HTML要素が持つ文字は、textContentで読み取ったり変更したりできます。

HTML：

<p id="message">保存前です</p>

JavaScriptで要素を見つける：

const message =
  document.getElementById("message");

文字を読む：

console.log(message.textContent);

文字を変更する：

message.textContent = "保存しました";

画面上の文字は「保存前です」から「保存しました」へ変わります。

message
→ 取得しておいたHTML要素

.
→ 要素が持つ値へつなぐ記号

textContent
→ その要素が持っている文字

textContentはプロパティです。

message.textContentは「オブジェクト名.プロパティ名」という形なので、()は付きません。

現在のアプリで使っている例：

freeMemoStatus.textContent = "保存しました";

自由メモを保存できたときに、結果表示の文字を変更しています。

このページでは、HTML文字列を直接扱うinnerHTMLなどには広げません。

input・textareaの値を取得する

<input>や<textarea>に入力された値は、valueで取得できます。

HTML：

<textarea id="free-memo-input"></textarea>

JavaScriptで要素を見つける：

const freeMemoInput =
  document.getElementById("free-memo-input");

入力された値を取得する：

const freeMemoText = freeMemoInput.value;

<textarea>へ文章を入力
↓
freeMemoInput.value
↓
入力された文章を取得
↓
freeMemoTextへ入れる

freeMemoInput
→ 取得した<textarea>要素

value
→ 現在入力されている値

valueもプロパティなので、()は付きません。

textContentとvalueの比較

扱うもの 使うプロパティ
<p>や<span>などの文字 textContent
<input>や<textarea>の入力値 value 
const freeMemoText = freeMemoInput.value;

freeMemoStatus.textContent = "保存しました";

入力された値
→ value

画面に表示する文字
→ textContent

このアプリで使っているHTML操作

1. BACKボタンを見つける

HTMLのBACKボタンとJavaScriptは、同じback-buttonというid名でつながっています。

HTMLのid="back-button"
↓ 同じ名前でつながる
JavaScriptのgetElementById("back-button")

実際のコードを見る

HTML：

<button type="button" id="back-button" class="nav-button">BACK</button>

JavaScript：

// HTMLからBACKボタンを取得します。
const backButton = document.getElementById("back-button");

// BACKボタンがクリックされたときの処理です。
backButton.addEventListener("click", function () {
  history.back();
});

2. 自由メモの入力欄を見つけて値を読む

HTMLのfree-memo-inputというidを使って入力欄を見つけ、freeMemoInputという変数へ入れます。

HTMLのid="free-memo-input"
↓
getElementById("free-memo-input")
↓
freeMemoInput
↓ .value
入力された文章

実際のコードを見る

HTML：

<textarea id="free-memo-input" class="free-memo-input" aria-label="自由メモ"></textarea>

JavaScript：

// HTMLから自由メモの入力欄を取得します。
const freeMemoInput = document.getElementById("free-memo-input");

// 入力欄に書かれた文章を取得します。
const freeMemoText = freeMemoInput.value;

3. 「保存しました」の文字を変更する

HTMLの空の<p>をidで見つけ、textContentを使って「保存しました」という文字を表示します。

HTMLのid="free-memo-status"
↓
getElementById("free-memo-status")
↓
freeMemoStatus.textContent
↓
「保存しました」と表示

実際のコードを見る

HTML：

<p id="free-memo-status" class="free-memo-status" aria-live="polite"></p>

JavaScript：

// HTMLから保存結果を表示する要素を取得します。
const freeMemoStatus = document.getElementById("free-memo-status");

// 空だった要素へ「保存しました」という文字を入れます。
freeMemoStatus.textContent = "保存しました";

結果：

<p
  id="free-memo-status"
  class="free-memo-status"
  aria-live="polite"
></p>

↓ textContentで文字を変更

<p
  id="free-memo-status"
  class="free-memo-status"
  aria-live="polite"
>保存しました</p>

textContentはHTML要素そのものを作り直すのではなく、その要素が持つ文字内容を変更します。

これから学ぶこと

HTML要素を見つける
→ getElementById()などを使う

文字を扱う
→ textContentを使う

入力値を扱う
→ valueを使う

複数のHTML要素を扱う
→ classやquerySelectorAll()などを使う

イベント
→ クリックなどをきっかけに処理を動かす

JavaScriptでHTMLを操作するときは、「まず要素を見つける → その要素の文字や値を扱う」という流れを意識すると、コードを読みやすくなります。
