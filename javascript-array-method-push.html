push() - 末尾へ追加

push()とは？

push()は、配列の末尾へ新しい要素を追加するメソッドです。

配列名.push(追加する値);

()の中へ、配列に追加したい値を書きます。

1つの要素を追加する 
const fruits = ["りんご", "みかん"];

fruits.push("バナナ");

console.log(fruits);

fruits.push("バナナ");によって、末尾へ「バナナ」が追加されます。

実行結果は["りんご", "みかん", "バナナ"]です。

実行前と実行後を比べる

push()を実行する前

["りんご", "みかん"]

push()を実行した後

["りんご", "みかん", "バナナ"]

push()は、元のfruits配列そのものへ要素を追加します。

別の新しい配列を作るのではなく、元の配列そのものが変わることが大切です。

複数の要素を追加する 
const colors = ["赤"];

colors.push("青", "黄");

console.log(colors);

()の中をカンマ,で区切ると、複数の要素をまとめて末尾へ追加できます。

実行結果は["赤", "青", "黄"]です。

lengthとのつながり 
const colors = ["赤"];

console.log(colors.length);

colors.push("青", "黄");

console.log(colors.length);

実行前の要素数は1です。

2つ追加した後の要素数は3です。

push()で要素が増えると、配列のlengthも増えます。

このページでは、push()の戻り値の詳しい説明には進みません。

コードを分けて読む 
fruits.push("バナナ");

fruits
→ 要素を追加する元の配列

.
→ fruitsが持つメソッドへアクセスする

push
→ 末尾へ追加するメソッド

("バナナ")
→ pushを実行し、追加する値を渡す

コードの実行順を上から読む

① const fruits = ["りんご", "みかん"];
→ 2つの要素が入った配列を作る

② fruits.push("バナナ");
→ 元の配列の末尾へ「バナナ」を追加する

③ console.log(fruits);
→ 追加後の配列を表示する

「りんご」「みかん」の後ろに「バナナ」が加わります。

確認問題 
const numbers = [1, 2];

numbers.push(3, 4);

console.log(numbers);
console.log(numbers.length);

① numbers配列は、実行後にどうなりますか？

② 実行後のnumbers.lengthはいくつですか？

③ 元のnumbers配列そのものは変わりますか？

確認問題の答え

① [1, 2, 3, 4]になります。

② 4です。

③ 変わります。push()は元の配列の末尾へ要素を追加します。

今回の学習ポイント

push()は、配列の末尾へ1つ以上の要素を追加します。

push()を実行すると、元の配列そのものが変わります。

要素を追加すると、配列のlengthも増えます。
