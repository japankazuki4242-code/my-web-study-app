<hr>

何をするタグ？

<hr>は、文章や内容の中で、話題・内容が切り替わる区切りを表すHTMLタグです。

ブラウザでは通常、横線のように表示されます。

見た目として横線を表示するだけではなく、HTML上で内容の区切りという意味を表します。

基本の書き方 
<p>前半の内容です。</p>

<hr>

<p>後半の内容です。</p>

内容が切り替わる場所に<hr>を書きます。

<hr>は終了タグを書かず、1つのタグだけで使います。

○ <hr>

属性名・属性値の例 
<hr class="section-divider">

属性名：class
属性値：section-divider

classを付けると、CSSからこの<hr>を指定できます。

<hr>は内容の区切りを表すタグで、基本的に専用の属性を付けなくても使用できます。

よく使う場面

<hr>は、HTMLとして内容の区切りを表したい場所で使います。

  • 話題が切り替わる場所
  • 文章の内容を区切りたい場所
  • 前半と後半の内容を分ける場所

単なる装飾として線を付けたい場合と、HTMLで内容の区切りを表したい場合では役割が違います。

CSSのborderとの違い

<hr>
→ HTML
→ 内容・話題の区切りを表す

border
→ CSS
→ 要素に枠線・線という見た目を付ける

.box {
  border: 1px solid black;
}

上側だけに線を付ける場合は、border-topを使います。

.box {
  border-top: 1px solid black;
}

横線に近い見た目になる場合があっても、HTMLの<hr>とCSSのborderでは役割が違います。
