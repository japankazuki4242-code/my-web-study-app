map() - すべて変換

map()とは？

map()は、配列の各要素を使って新しい値を作る配列メソッドです。

各要素から作った値を順番に入れた、新しい配列が結果になります。

値を作る処理は、コールバック関数としてmap()へ渡します。

基本コード 
const numbers = [1, 2, 3];

const doubled = numbers.map(function (number) {
  return number * 2;
});

console.log(doubled);

各要素を2倍した値から、新しい配列を作っています。

実行結果は[2, 4, 6]です。

コードを分けて読む

numbers
→ 変換に使う元の配列

map
→ 各要素から新しい値を作る配列メソッド

function (number) { ... }
→ 新しい値を作るコールバック関数

number
→ 配列から1つずつ渡される要素を受け取る仮引数

doubled
→ map()が作った新しい配列を保存する変数

returnする値が新しい要素になる 
return number * 2;

現在の要素を2倍し、その計算結果をreturnしています。

returnした値が、map()の作る新しい配列へ入ります。

条件のtrue・falseを返すのではなく、新しく作った値を返すことがポイントです。

1を変換する流れ

1
↓
仮引数numberへ渡る

number * 2
↓
1 * 2を計算する

2をreturnする
↓
新しい配列へ2が入る

2と3も順番に変換する

2
→ numberへ渡る
→ 2 * 2
→ 4をreturn
→ 新しい配列へ入る

3
→ numberへ渡る
→ 3 * 2
→ 6をreturn
→ 新しい配列へ入る

すべての変換が終わると、新しい配列は[2, 4, 6]になります。

元の配列は変更しない 
console.log(numbers);
console.log(doubled);

numbers
→ [1, 2, 3]

doubled
→ [2, 4, 6]

map()自体は元の配列を変更せず、変換した値を入れた別の新しい配列を作ります。

filter()との違い

filter()
→ 元の要素を条件で選び、選ばれた要素から新しい配列を作る

map()
→ すべての要素から新しい値を作り、新しい配列を作る

「条件に合うものを選びたい」のか、「各要素を別の値へ変換したい」のかで使い分けます。

コードの実行順を上から読む

① numbers配列を作る

② numbers.map(...)を実行する

③ 各要素を仮引数numberへ1つずつ渡す

④ コールバック関数で2倍した値をreturnする

⑤ 返された2・4・6から新しい配列を作る

⑥ 新しい配列をdoubledへ保存する

確認問題 
const prices = [100, 200, 300];

const increased = prices.map(function (price) {
  return price + 50;
});

① 仮引数priceには、どの値が順番に渡りますか？

② コールバック関数は、それぞれ何をreturnしますか？

③ increasedはどのような配列になりますか？

④ 元のprices配列は変わりますか？

確認問題の答え

① 100、200、300の順です。

② 150、250、350を順番に返します。

③ [150, 250, 350]になります。

④ 変わりません。pricesは[100, 200, 300]のままです。

今回の学習ポイント

map()は、配列のすべての要素から新しい値を作ります。

コールバック関数がreturnした値が、新しい配列へ順番に入ります。

map()自体は、元の配列を変更せず、変換した値を入れた新しい配列を作ります。
