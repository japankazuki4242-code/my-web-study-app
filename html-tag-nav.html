<nav>

何をするタグ？

ページ内の主要なナビゲーションリンクをまとめるためのタグです。
メニューや、ページ内の別の場所へ移動するリンクなどを中に入れます。

基本の書き方 
<nav>
  <a href="#">Home</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</nav>

<ul>と<li>を使うと、メニュー項目をリストとしてまとめられます。

<nav>
  <ul>
    <li><a href="/">ホーム</a></li>
    <li><a href="/about/">会社概要</a></li>
    <li><a href="/contact/">お問い合わせ</a></li>
  </ul>
</nav>

<nav> → ナビゲーション全体
<ul> → メニュー項目のまとまり
<li> → 1つのメニュー項目
<a> → 実際に移動するリンク

属性名・属性値の例 
<nav class="global-nav">

属性名：class
属性値：global-nav

class は、CSSやJavaScriptからその要素を指定するときに使います。

よく使う場面

ページ上部のメニューや、
ページ内の主要な移動リンクをまとめたいときに使います。

  • Home
  • About
  • Contact
  • ページ内リンク など
実際に使った例 
<nav class="global-nav">
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
</nav>

# はリンク先を仮で指定するときに使うことがあります。

実際にページを作るときは、hrefに移動先のURLやファイル名などを指定します。

例：

<a href="about.html">About</a>

これはabout.htmlに移動するリンクです。
