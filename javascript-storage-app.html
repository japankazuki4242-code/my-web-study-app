このアプリの自由メモで使っているコード

自由メモで使うHTML要素を見つける

最初に、自由メモの入力欄・保存ボタン・状態を表示する場所を、idを使って見つけます。

const freeMemoInput = document.getElementById("free-memo-input");
const saveFreeMemoButton = document.getElementById("save-free-memo-button");
const freeMemoStatus = document.getElementById("free-memo-status");

document.getElementById()でHTML要素を見つけて変数へ入れる部分が、DOMを使った処理です。

ページを開いたときに読み出す

自由メモで使う3つのHTML要素があるページでは、保存済みのメモを読み出します。

const savedFreeMemo = localStorage.getItem(freeMemoStorageKey);

if (savedFreeMemo !== null) {
  freeMemoInput.value = savedFreeMemo;
}

getItem()で保存済みのデータを読み出します。データがあれば、freeMemoInput.valueへ入れてtextareaに表示します。

保存ボタンのclickを受け取る

保存ボタンがクリックされたときに、関数の中の処理が実行されます。

saveFreeMemoButton.addEventListener("click", function () {
  const freeMemoText = freeMemoInput.value;

  localStorage.setItem(freeMemoStorageKey, freeMemoText);
  freeMemoStatus.textContent = "保存しました";
});

addEventListener()がイベントを受け取る部分です。ここでは"click"イベントを指定しています。

入力内容を保存して結果を表示する

クリック後の処理は、次の順番で進みます。

freeMemoInput.valueで入力内容を取得する
↓
取得した内容をfreeMemoTextへ入れる
↓
setItem()でlocalStorageへ保存する
↓
textContentで「保存しました」と表示する

.valueは入力欄の値を扱い、textContentはHTML要素へ文字を表示しています。

5つの学習内容がつながる
学習内容 自由メモでの役割
DOM 入力欄・ボタン・表示場所を見つける
イベント 保存ボタンのclickを受け取る
.value textareaの入力内容を取得したり、保存内容を戻したりする
localStorage メモを保存し、保存済みのメモを読み出す
textContent 「保存しました」と表示する

それぞれは別々の知識ですが、自由メモでは1つの処理として順番につながっています。

↓
