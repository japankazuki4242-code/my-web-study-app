サイズ

width と height 
.box {
  width: 300px;
  height: 200px;
}

widthは横幅、heightは高さを指定します。

max-width と min-height 
.container {
  max-width: 700px;
}

.button {
  min-height: 56px;
}

max-widthは横幅の上限、min-heightは高さの下限を指定します。

内容が増えたときに高さを広げたい場合は、固定のheightよりmin-heightが使いやすいことがあります。

px・%・auto

px
→ 基本的な固定サイズ

%
→ 基準となる親要素などに対する割合

auto
→ ブラウザが状況に合わせて自動計算

.box {
  width: 80%;
  height: auto;
}
width: 100% の意味 
.box {
  width: 100%;
}

width: 100%;は、必ずしも画面全体の100%ではありません。

その要素の幅を決める基準となる親要素や領域に対する100%です。

max-width: 100% と画像 
img {
  max-width: 100%;
  height: auto;
}

width: 100%
→ 基準となる幅いっぱいへ広げる

max-width: 100%
→ 基準幅の100%を上限にする

height: auto
→ 幅に合わせて高さを自動計算する

実際に使った例

Black Coffeeでは、内容を広げすぎず中央に置くため、横幅と上限を組み合わせています。

.container {
  width: 100%;
  max-width: 700px;
  margin: 0 auto;
}

kazuki_HP_practice2のヘッダー内側には、横幅の上限があります。

.header-inner {
  max-width: 1000px;
}

画像部分は、通常時に固定サイズ、狭い画面では幅に合わせたサイズを使用しています。

.img-area figure {
  width: 480px;
  height: 329px;
}

@media screen and (max-width: 520px) {
  .img-area figure {
    width: 100%;
    height: auto;
  }
}
