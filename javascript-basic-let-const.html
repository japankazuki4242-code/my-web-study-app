let・constと値を保存する

値に名前を付けて保存する

変数や定数は、値に名前を付けて保存し、後からその名前で使うための仕組みです。

const userName = "かず";

「userNameという名前の箱へ、『かず』という値を入れる」とイメージすると分かりやすくなります。

後からuserNameと書けば、保存した「かず」という値を使えます。

letは再代入できる

letで宣言した変数には、後から別の値を再代入できます。

let score = 10;

score = 20;

最初に10を保存し、その後で同じscoreへ20を再代入しています。

値が変わる予定のあるものには、letを使います。

constは再代入できない

constで宣言した定数へ、後から別の値を再代入することはできません。

const userName = "かず";

userName = "太郎";

再代入を実行した時点でエラーになります。

一度保存した値を別の値へ入れ替えないときは、constを使います。

基本はconst、必要なときだけlet

宣言するときは、まずconstで書けるかを考えます。

const
→ 後から別の値を再代入しない

let
→ 繰り返しの回数など、後から値を変える必要がある

再代入が必要なときだけletを使うと、意図しない値の変更を減らせます。

camelCaseで名前を付ける

複数の単語を使って変数名や定数名を付けるときは、camelCaseがよく使われます。

const userName = "かず";
const totalPrice = 1500;

最初の単語は小文字で始め、2つ目以降の単語の先頭を大文字にします。

userNameなら、「ユーザーの名前を保存している」と名前から分かります。

+=などで値を更新する

letで宣言した数値は、+=などを使って更新できます。

let score = 10;

score += 5;

console.log(score);

実行結果は15です。

score += 5は、次の書き方と同じ意味です。

score = score + 5;

-=は値を減らすとき、++は値を1増やすときに使えます。

constだから中身が絶対変わらない？

constは、「保存したものの中身が絶対に変わらない」という意味ではありません。

const fruits = ["りんご", "みかん"];

fruits[0] = "バナナ";

fruitsへ別の配列は再代入できませんが、配列の要素は変更できます。

ここでは、「constで宣言した名前には、別の値を再代入できない」と整理しましょう。配列やオブジェクトの詳しい仕組みは、別の教材で学びます。

確認問題 
let points = 10;

points += 5;

① 最後のpointsの値はいくつですか？

② pointsにletを使う理由は何ですか？

③ 後から再代入しない名前には、letとconstのどちらを使いますか？

確認問題の答え

① 15

② pointsの値を後から更新するため

③ const

今回の学習ポイント

変数や定数は、値に名前を付けて保存する仕組みです。

const
→ 再代入できない

let
→ 再代入できる

基本はconstを使い、値の再代入が必要なときだけletを使います。
