配列から値を取り出す・変更する

今回使う配列

このページでは、3つの果物が入った次の配列を使います。

const fruits = ["りんご", "みかん", "バナナ"];

配列名はfruitsです。index 0から順番に、「りんご」「みかん」「バナナ」が入っています。

値を取り出す

「配列名[index]」と書くと、指定した要素を配列から取り出せます。

値を取り出して確認しても、その要素が配列からなくなるわけではありません。

console.log(fruits[0]);
console.log(fruits[1]);
console.log(fruits[2]);

fruits[0]は1番目、fruits[1]は2番目、fruits[2]は3番目の要素を指定しています。

実行結果

先ほどのコードを実行すると、コンソールには次のように表示されます。

りんご
みかん
バナナ

配列の中の値が、指定したインデックスの順番で1つずつ取り出されています。

配列名[index]の読み方 
fruits[1]

fruits
→ 値を取り出す配列

[1]
→ index 1の要素を指定

fruits[1]
→ fruitsのindex 1にある「みかん」

角括弧の中に、人間が数える順番ではなく、0から始まるインデックスを書きます。

値を変更する

指定した要素へ新しい値を代入すると、配列の値を変更できます。

const fruits = ["りんご", "みかん", "バナナ"];

fruits[1] = "ぶどう";

console.log(fruits);

このコードを実行すると、index 1の「みかん」が「ぶどう」へ変わります。

["りんご", "ぶどう", "バナナ"]

指定していない「りんご」と「バナナ」は変わりません。

変更するコードを分けて読む 
fruits[1] = "ぶどう";

fruits
→ 配列

[1]
→ index 1の要素を指定

=
→ 右側の値を左側へ代入

"ぶどう"
→ 新しく代入する値

左から読むと、「fruitsのindex 1に、新しい値の『ぶどう』を代入する」という処理です。

constでも要素は変更できる

const fruits = [...]と宣言していても、fruits[1]のように配列の要素を指定して変更できます。

constでできないのは、fruits自体へ別の配列を再代入することです。

できる

fruits[1] = "ぶどう";

できない

fruits = ["ぶどう", "もも"];

「配列の要素を変更すること」と「変数へ別の配列を再代入すること」を分けて考えましょう。

存在しないindexを指定すると？

この配列にある要素のインデックスは、0・1・2です。

const fruits = ["りんご", "みかん", "バナナ"];

console.log(fruits[3]);

index 3には値が存在しないため、実行結果はundefinedになります。

undefined

undefinedは、ここでは「指定した場所に値がない」と考えると分かりやすいです。

間違えやすいポイント

2番目の要素を取り出したり変更したりするときは、[2]ではなく[1]を使います。インデックスは0から始まるためです。

値を取り出すだけならfruits[1]、新しい値へ変更するならfruits[1] = "ぶどう";のように代入を書きます。
