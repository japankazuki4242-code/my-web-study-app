関数とメソッドの違い

関数とは？

関数は、処理をひとまとまりにして、名前を付けたものです。

function introduce() {
  console.log("かずです");
}

この例では、introduceという名前の関数を定義しています。

introduce()と書くと、関数を呼び出せます。

メソッドとは？

オブジェクトの中にある関数を、メソッドと呼びます。

const user = {
  introduce: function () {
    console.log("かずです");
  }
};

userオブジェクトのintroduceプロパティに、関数が入っています。

このように、オブジェクトが持っている処理や機能として使う関数がメソッドです。

以前学習したオブジェクトとのつながり

オブジェクトは、関係する値や機能を1つにまとめられます。

const user = {
  name: "かず",
  introduce: function () {
    console.log("こんにちは");
  }
};

name
→ 文字列が入っているプロパティ

introduce
→ 関数が入っているプロパティで、呼び出すときはメソッドとして使う

オブジェクトが持つ名前付きの値を、プロパティと呼びます。

そのプロパティの値が関数で、処理として呼び出して使うものをメソッドと呼びます。

見た目の違いを比べる 
introduce();
user.introduce();

introduce()
→ introduceという関数を呼び出す

user.introduce()
→ userオブジェクトが持つintroduceメソッドを呼び出す

メソッドの呼び出しには、オブジェクト名とメソッド名をつなぐ.があります。

コードを分けて読む 
user.introduce();

user
→ オブジェクト

.
→ userが持っているものへアクセスする

introduce
→ メソッド名

()
→ メソッドを実行する

全体で、「userオブジェクトが持つintroduceメソッドを実行する」と読みます。

addEventListener()もメソッド

このアプリのscript.jsでは、次の形のコードを使っています。

backButton.addEventListener("click", function () {
  history.back();
});

backButton
→ 操作する要素を表すオブジェクト

addEventListener
→ backButtonが持つメソッド

()
→ メソッドを実行する

このページでは、backButton.addEventListener()を「オブジェクトが持つメソッド」と読めれば大丈夫です。丸括弧の中にある関数の役割は、次のPhaseで学びます。

確認問題 
showMessage();
console.log("完了");
localStorage.getItem("userName");

① 関数の呼び出しはどれですか？

② メソッドの呼び出しはどれですか？

③ console.log()のオブジェクト名とメソッド名は何ですか？

確認問題の答え

① showMessage();

② console.log("完了");とlocalStorage.getItem("userName");

③ オブジェクト名はconsole、メソッド名はlogです。

オブジェクト.メソッド()という形を目印にしましょう。

今回の学習ポイント

関数
→ 処理をひとまとまりにしたもの

メソッド
→ オブジェクトの中にある関数

functionName()は関数の呼び出し、object.method()はメソッドの呼び出しとして読めます。
