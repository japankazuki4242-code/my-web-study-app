オブジェクトの値を変更する

プロパティの値を変更する

変更したいプロパティを指定し、新しい値を代入すると、プロパティの値を変更できます。

const user = {
  name: "かず",
  age: 50
};

user.age = 51;

console.log(user.age);

このコードでは、ageプロパティの値を50から51へ変更しています。

実行結果 
51

user.age = 51;を実行した後は、user.ageから新しい値の51を取り出せます。

変更するコードを分けて読む 
user.age = 51;
書き方 意味
user オブジェクト
. プロパティへアクセスする
age 変更するプロパティ
= 右側の値を左側へ代入する
51 新しい値

左から読むと、「userのageプロパティへ、新しい値の51を代入する」という処理です。

constでもプロパティは変更できる

const user = { ... };と宣言していても、オブジェクトのプロパティの値は変更できます。

user.age = 51;

このコードは、user自体へ別のオブジェクトを再代入しているのではありません。userが持つageプロパティの値だけを変更しています。

別のオブジェクトは再代入できない

constで宣言したuser自体へ、別のオブジェクトを再代入することはできません。

const user = {
  name: "かず",
  age: 50
};

user = {
  name: "太郎",
  age: 30
};

このコードは、userへ新しいオブジェクトを再代入しようとしているため、再代入した時点でエラーになります。

2つの変更を区別する

プロパティの値を変更する

user.age = 51;

→ constで宣言したオブジェクトでもできる

変数へ別のオブジェクトを再代入する

user = {
  name: "太郎",
  age: 30
};

→ constで宣言したuserにはできない

「中にあるプロパティの値を変更すること」と「user自体へ別のオブジェクトを再代入すること」を混同しないようにしましょう。
