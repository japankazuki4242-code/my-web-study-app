find() - 最初の1件

find()とは？

find()は、条件に合う最初の要素を探す配列メソッドです。

配列の先頭から順番に条件を確認し、最初に条件に合った要素を結果にします。

条件を確認する処理は、コールバック関数としてfind()へ渡します。

基本コード 
const numbers = [10, 20, 30, 40];

const found = numbers.find(function (number) {
  return number >= 30;
});

console.log(found);

30以上という条件に最初に合う要素を探し、結果をfoundへ保存しています。

実行結果は30です。

コードを分けて読む

numbers
→ 探す対象の配列

find
→ 条件に合う最初の要素を探す配列メソッド

function (number) { ... }
→ 条件を確認するコールバック関数

number
→ 配列から1つずつ渡される要素を受け取る仮引数

found
→ find()で見つかった結果を保存する変数

returnで条件の結果を返す 
return number >= 30;

number >= 30は、現在の要素が30以上かを比べます。

条件に合う場合はtrue、合わない場合はfalseになります。

returnによって、そのtrueまたはfalseをfind()へ返します。

実行順を追う

10
→ numberへ渡る
→ 10 >= 30はfalse
→ 次の要素へ進む

20
→ numberへ渡る
→ 20 >= 30はfalse
→ 次の要素へ進む

30
→ numberへ渡る
→ 30 >= 30はtrue
→ 30が結果になる

最初の30が見つかったため、この例では40まで条件を確認する必要はありません。

最初の1つが結果になる 
const numbers = [10, 30, 40];

const found = numbers.find(function (number) {
  return number >= 30;
});

30と40はどちらも条件に合いますが、結果は最初に見つかった30だけです。

find()は、条件に合うすべての要素を集めるメソッドではありません。

見つからない場合はundefined 
const numbers = [10, 20];

const found = numbers.find(function (number) {
  return number >= 30;
});

console.log(found);

どの要素も条件に合わないため、結果はundefinedです。

undefinedは、ここでは「条件に合う要素が見つからなかった」と考えれば大丈夫です。

コードを上から順番に読む

① numbers配列を作る

② numbers.find(...)を実行する

③ 各要素が仮引数numberへ順番に渡る

④ コールバック関数がnumber >= 30の結果を返す

⑤ 最初にtrueになった要素30を、foundへ保存する

⑥ console.log(found);で30を表示する

確認問題 
const scores = [40, 80, 90];

const found = scores.find(function (score) {
  return score >= 70;
});

① 仮引数scoreには、どの値がどの順番で渡りますか？

② 最初にtrueになる値は何ですか？

③ foundへ保存される値は何ですか？

確認問題の答え

① 最初に40、次に80が渡ります。

② 80です。

③ 80です。

80で条件に合う要素が見つかるため、この例では次の90まで確認しません。

今回の学習ポイント

find()は、条件に合う最初の要素を結果にします。

コールバック関数は、条件の結果をtrueまたはfalseとして返します。

条件に合う要素が1つもない場合、結果はundefinedになります。
