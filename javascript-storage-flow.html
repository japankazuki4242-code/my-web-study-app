保存から読み込みまでの流れ

全体の流れ

自由メモは、入力した内容を保存し、次にページを開いたときに入力欄へ戻す仕組みです。

入力
↓
取得
↓
保存
↓
再読み込み
↓
復元

それぞれの処理が順番につながることで、ページを閉じてもメモを残せます。

1〜3：入力内容を保存する

① ユーザーがtextareaへメモを入力する

② .valueで入力内容を取得する

const freeMemoText = freeMemoInput.value;

③ setItem()で入力内容を保存する

localStorage.setItem(freeMemoStorageKey, freeMemoText);

freeMemoStorageKeyをkey、freeMemoTextをvalueとしてlocalStorageへ保存します。

4〜6：保存後にページを開き直す

④ localStorageにデータが残る

⑤ ページを閉じる

⑥ 同じサイトを再び開く

localStorageへ保存したデータは、ページを閉じてもブラウザの中に残ります。同じ端末・ブラウザ・サイトで開き直すと、そのデータを読み出せます。

7〜8：保存内容を復元する

⑦ getItem()で保存データを読み出す

const savedFreeMemo =
  localStorage.getItem(freeMemoStorageKey);

⑧ 保存データがあればtextareaへ内容を戻す

if (savedFreeMemo !== null) {
  freeMemoInput.value = savedFreeMemo;
}

freeMemoInput.valueへ保存内容を入れることで、textareaに前回のメモが表示されます。

8つの手順を続けて確認する
  1. ユーザーが入力する
  2. .valueで入力内容を取得する
  3. setItem()で保存する
  4. localStorageにデータが残る
  5. ページを閉じる
  6. 同じサイトを再び開く
  7. getItem()で保存データを読む
  8. textareaへ内容を戻す

保存するときはtextareaの入力内容をlocalStorageへ保存し、復元するときはlocalStorageから読み出してtextareaへ戻します。

保存と復元で同じkeyを使う

保存するときも読み出すときも、同じfreeMemoStorageKeyを使っています。

localStorage.setItem(freeMemoStorageKey, freeMemoText);

const savedFreeMemo =
  localStorage.getItem(freeMemoStorageKey);

同じkeyを使うことで、保存した場所を見つけて内容を読み出せます。
