関数とは？・定義と呼び出し

関数とは？

関数は、処理をひとまとまりにして、名前を付けたものです。

同じ処理が必要になったときは、その名前を使って何度でも実行できます。

「あいさつする」「合計を計算する」のように、何をする処理なのかが分かる名前を付けると、コードを読みやすくできます。

関数を定義するとは？

関数を定義するとは、まとめたい処理の内容と、その関数の名前を決めることです。

function greet() {
  console.log("こんにちは");
}

function
→ 関数を定義するときに使う言葉

greet
→ 関数名

{ }
→ ひとまとまりにする処理を書く場所

関数を呼び出すとは？

関数を呼び出すとは、定義した関数の処理を実行することです。

greet();

関数名の後ろに()を付けると、greetの中にまとめた処理が実行されます。

この例では、コンソールに「こんにちは」と表示されます。

複数の処理をまとめる

関数の{ }には、複数の処理をまとめて書けます。

function introduce() {
  console.log("かずです");
  console.log("よろしくお願いします");
}

introduce()を呼び出すと、2つのconsole.log()が上から順番に実行されます。

関係する処理を1つの関数にまとめることで、「何をするための処理か」が分かりやすくなります。

定義しただけでは実行されない 
function greet() {
  console.log("こんにちは");
}

このコードはgreet関数を定義しただけです。この時点では、コンソールに何も表示されません。

処理を実行するには、定義とは別に次の呼び出しが必要です。

greet();
コードを上から順番に読む 
function greet() {
  console.log("こんにちは");
}

greet();
console.log("次の処理");

① function greet() {
→ greet関数を定義する

② console.log("こんにちは");
→ 呼び出されたときに実行する処理として覚えておく

③ greet();
→ greet関数を呼び出し、「こんにちは」を表示する

④ console.log("次の処理");
→ 関数の呼び出しが終わった後、「次の処理」を表示する

確認問題 
function sayHello() {
  console.log("Hello");
}

sayHello();

① 関数名は何ですか？

② 関数を定義している部分はどこですか？

③ 関数を呼び出している部分はどこですか？

④ コンソールには何と表示されますか？

確認問題の答え

① sayHello

② function sayHello() {から}まで

③ sayHello();

④ Hello

定義した関数は、sayHello()と呼び出されたときに実行されます。

今回の学習ポイント

このページでは、次の4点を覚えておきましょう。

  • 関数は、処理をひとまとまりにしたもの
  • 定義は、関数の名前と処理の内容を決めること
  • 呼び出しは、定義した関数を実行すること
  • 関数は定義しただけでは実行されない
