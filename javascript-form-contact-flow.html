お問い合わせフォームの基本的な流れ

お問い合わせフォームで行うこと

お問い合わせフォームでは、HTMLで入力欄を作り、JavaScriptでその要素と入力値を扱います。

HTMLでフォームを作る
↓
JavaScriptでフォームと入力欄を見つける
↓
送信されたときに入力値を取得する
↓
取得した値をJavaScriptで処理する

コード全体を見る

HTML：

<form id="contact-form">
  <label for="user-name">名前</label>
  <input
    type="text"
    id="user-name"
    name="userName"
    required
  >

  <label for="email">メールアドレス</label>
  <input
    type="email"
    id="email"
    name="email"
    required
  >

  <label for="message">お問い合わせ内容</label>
  <textarea
    id="message"
    name="message"
    required
  ></textarea>

  <button type="submit">送信</button>
</form>

JavaScript：

const contactForm =
  document.getElementById("contact-form");

const userNameInput =
  document.getElementById("user-name");

const emailInput =
  document.getElementById("email");

const messageInput =
  document.getElementById("message");

contactForm.addEventListener("submit", function (event) {
  event.preventDefault();

  const userName = userNameInput.value;
  const email = emailInput.value;
  const message = messageInput.value;

  console.log(userName);
  console.log(email);
  console.log(message);
});
8段階の流れ

① HTMLでフォームを作る

② <input>・<textarea>へidを付ける

③ JavaScriptで要素を見つける

④ submitイベントを登録する

⑤ ユーザーが送信する

⑥ preventDefault()で標準動作を止める

⑦ .valueで入力値を取得する

⑧ JavaScriptで処理する

HTMLとJavaScriptの対応

HTMLのid属性の値と、getElementById()に指定する文字列を同じにします。

HTML
id="contact-form"
↓ 同じ値
JavaScript
getElementById("contact-form")

HTML
id="user-name"
↓ 同じ値
JavaScript
getElementById("user-name")

HTML
id="email"
↓ 同じ値
JavaScript
getElementById("email")

HTML
id="message"
↓ 同じ値
JavaScript
getElementById("message")

id属性の値とgetElementById()に指定する文字列が一致することで、JavaScriptから目的のフォームや入力欄を見つけられます。

入力値を取得する 
const userName = userNameInput.value;
const email = emailInput.value;
const message = messageInput.value;

userNameInput・emailInput・messageInputは、HTMLから見つけた入力要素です。

それぞれの.valueを使うと、現在入力されている値を取得できます。

取得した値を、userName・email・messageという変数へ入れています。

取得した値を処理する 
console.log(userName);
console.log(email);
console.log(message);

この基本例では、取得した名前・メールアドレス・お問い合わせ内容をconsole.log()でコンソールへ表示しています。

ここまでの流れで、HTMLの入力欄とJavaScriptの処理がどのようにつながるかを確認できます。
