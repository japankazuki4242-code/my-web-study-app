preventDefault()とは？

preventDefault()は、ブラウザ標準の動作を止めるメソッドです。

フォームでは、標準の送信動作を一度止め、JavaScriptで入力値を確認したり処理したりするときに使うことがあります。

基本の書き方 
contactForm.addEventListener("submit", function (event) {
  event.preventDefault();
});

<form>でsubmitイベントが起きたときに、event.preventDefault()を実行しています。

eventとは？

event
→ 今回起きたイベントの情報

function (event) {
  event.preventDefault();
}

イベントが起きると、ブラウザからそのイベントに関する情報を受け取れます。

この例では、受け取った情報をeventという名前で使っています。

コードを1行ずつ読む 
contactForm.addEventListener("submit", function (event) {
  event.preventDefault();
});

contactForm.addEventListener("submit", function (event) {
→ contactFormへsubmitイベントを登録し、送信されたときに関数を実行します。今回起きたイベントの情報をeventで受け取ります。

event.preventDefault();
→ 今回のイベントでブラウザが行う標準の送信動作を止めます。

});
→ 関数とaddEventListener()を閉じます。

フォームで使う場面

フォームをそのまま送信すると、ブラウザの標準動作によってページが移動したり再読み込みされたりすることがあります。

JavaScriptで入力内容を確認する場合は、次のような順番で処理することがあります。

フォームが送信される
↓
submitイベントが起きる
↓
preventDefault()で標準動作を止める
↓
.valueで入力値を取得する
↓
JavaScriptで入力値を確認・処理する

いつでも使うわけではない

preventDefault()は、フォームでいつでも書くものではありません。

ブラウザの標準動作を止める必要がある場合に使います。

フォームを通常どおり送信したい場合は、標準の送信動作を止めないこともあります。何をしたいフォームなのかに合わせて判断します。
