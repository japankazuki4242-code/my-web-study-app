関数を渡す・関数を実行する

2つの書き方を比べる 
call(printMessage);

call(printMessage());

1行目と2行目は、printMessageの後ろに()があるかどうかで動きが変わります。

printMessage
→ 関数そのもの

printMessage()
→ その場で関数を実行し、その戻り値を使う

call(printMessage)は関数を渡す 
call(printMessage);

printMessageに()がないため、この場所では関数を実行しません。

printMessage関数そのものを、call関数の引数として渡しています。

コールバックとして渡したい場合は、基本的にこの形を使います。

call(printMessage())は先に実行する 
call(printMessage());

printMessage()には()があるため、まずその場でprintMessage関数を実行します。

そのあと、printMessage()の戻り値がcall関数へ渡されます。

console.log()でコンソールに表示された内容と、関数から返される戻り値は別のものです。

これは「printMessage関数そのものをコールバックとして渡す」書き方ではありません。

今回は戻り値の詳しい応用には進まず、()を付けると先に実行されることを覚えましょう。

正しい例の実行順 
function call(callback) {
  console.log("開始");
  callback();
}

function printMessage() {
  console.log("こんにちは");
}

call(printMessage);

① call関数を定義する
→ この時点では中の処理はまだ実行しない

② printMessage関数を定義する
→ この時点でも中の処理はまだ実行しない

③ call(printMessage);を呼び出す

④ printMessage関数そのものが仮引数callbackへ渡る

⑤ console.log("開始");を実行し、「開始」と表示する

⑥ callback();を実行する
→ callbackに入っているprintMessage関数が実行される

⑦ console.log("こんにちは");によって、「こんにちは」と表示する

実行結果は「開始」「こんにちは」の順です。

よくある間違いの実行順 
call(printMessage());

① call(printMessage());を実行しようとする

② 引数に書かれたprintMessage()を先に実行する

③ 「こんにちは」と表示される

④ printMessage()にはreturnがないため、戻り値はundefinedになる

⑤ call(undefined);の形でcall関数が実行される

⑥ console.log("開始");によって、「開始」と表示される

⑦ callback();を実行しようとする

⑧ callbackには関数ではなくundefinedが入っているため、エラーになる

undefinedは、ここでは「戻り値として使える値が返されていない状態」くらいに考えれば大丈夫です。

call(printMessage());は、printMessage関数そのものをコールバックとして渡していない点が間違いです。

関数名と関数名()につなげる

以前学習した違いを、そのままコールバックにも当てはめられます。

printMessage
→ 関数そのものを使う
→ 別の関数へ渡せる

printMessage()
→ 関数の処理を今すぐ実行する

コードを見たら、関数名の後ろに()が付いているかを最初に確認しましょう。

確認問題 
function run(callback) {
  callback();
}

function sayHello() {
  console.log("こんにちは");
}

① sayHello関数そのものをrun関数へ渡すのは、次のどちらですか？

A：run(sayHello);

B：run(sayHello());

② Bでは、sayHello関数はいつ実行されますか？

確認問題の答え

① Aのrun(sayHello);です。

② run関数へ値を渡す前に、その場で実行されます。

コールバックとして関数そのものを渡すときは、sayHelloに()を付けません。

今回の学習ポイント

call(printMessage);
→ printMessage関数そのものを渡す

call(printMessage());
→ printMessage関数をその場で先に実行し、その戻り値を渡す

コールバックとして渡したい場合は、基本的に関数名へ()を付けません。
