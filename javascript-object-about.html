オブジェクトとは？・オブジェクトを作る

オブジェクトとは？

オブジェクトは、関連するデータを、項目名と値の組み合わせでまとめて管理する仕組みです。

たとえば、名前と年齢を「1人のユーザーの情報」として1つにまとめられます。

オブジェクトを作る基本コード 
const user = {
  name: "かず",
  age: 50
};

userという定数へ、名前と年齢をまとめたオブジェクトを代入しています。

nameとageが項目名、その右側にある"かず"と50がそれぞれの値です。

書き方を分けて読む
書き方 意味
const user = 右側のオブジェクトをuserへ代入する
{ オブジェクトの始まり
name: "かず" nameという項目名と、その値
, 項目と項目の区切り
age: 50 ageという項目名と、その値
} オブジェクトの終わり

項目名と値の間は、コロン:で区切ります。複数の項目は、カンマ,で区切ります。

配列とオブジェクトの軽い比較

配列

const userArray = ["かず", 50];

配列は、値を順番で管理します。「かず」は1番目、50は2番目の要素です。

オブジェクト

const user = {
  name: "かず",
  age: 50
};

オブジェクトは、nameやageのような意味のある項目名で管理します。

項目名があると分かりやすい

配列の50は、順番だけを見ると何を表す値か分かりにくいことがあります。

オブジェクトではage: 50と書くため、50が年齢を表していると分かります。

関連するデータを意味のある項目名と一緒にまとめられることが、オブジェクトの基本です。
