配列メソッドと
コールバックのつながり

これまでの学習がつながる

配列メソッドのコードには、これまで学んだ内容が一緒に登場します。

配列・メソッド・関数・引数・仮引数・return・コールバック関数の役割を分けて読むと、長く見えるコードも追いやすくなります。

このページでは、map()の例を使って、それぞれのつながりを整理します。

今回読むコード 
const numbers = [1, 2, 3];

const doubled = numbers.map(function (number) {
  return number * 2;
});

numbers配列の各要素を2倍し、新しい配列をdoubledへ保存するコードです。

実行後のdoubledは[2, 4, 6]になります。

numbers・ドット・map・()を読む

numbers
→ [1, 2, 3]が入っている配列

.
→ numbers配列が持つ機能へアクセスする

map
→ 各要素から新しい値を作る配列メソッド

()
→ mapメソッドを実行し、必要な値を渡す場所

function (number) { ... }を読む 
function (number) {
  return number * 2;
}

これは、map()へ渡しているコールバック関数の部分だけを抜き出した形です。

function (number) { ... }
→ 各要素から新しい値を作るコールバック関数

number
→ 配列から1つずつ渡される値を受け取る仮引数

return number * 2を読む 
return number * 2;

現在numberに入っている値を2倍します。

returnした計算結果が、map()の作る新しい配列へ入ります。

1なら2、2なら4、3なら6を返します。

doubledを読む 
const doubled = numbers.map(...);

numbers.map(...)の結果として、新しい配列ができます。

doubledは、その新しい配列を保存する変数です。

元のnumbersは[1, 2, 3]のまま、doubledには[2, 4, 6]が入ります。

コードを1行ずつ読む

① const numbers = [1, 2, 3];
→ 元になる配列を作る

② function (number) { ... }
→ コールバック関数としてmap()の引数へ渡す

③ numbers.map(function (number) { ... })
→ そのコールバック関数を引数として受け取り、numbers配列のmap()メソッドを実行する

④ return number * 2;
→ 各要素を2倍した値を返す

⑤ const doubled =
→ map()が作った新しい配列をdoubledへ保存する

→ 2を返す

確認問題 
const prices = [100, 200];

const increased = prices.map(function (price) {
  return price + 50;
});

① 配列名は何ですか？

② 配列メソッド名は何ですか？

③ コールバック関数はどの部分ですか？

④ 仮引数は何ですか？

⑤ returnした値は、何に使われますか？

⑥ increasedには、どの配列が入りますか？

確認問題の答え

① pricesです。

② mapです。

③ function (price) { return price + 50; }の部分です。

④ priceです。

⑤ map()が作る新しい配列の要素になります。

⑥ [150, 250]が入ります。

今回の学習ポイント

配列メソッドのコードは、配列・メソッド・コールバック関数・仮引数・returnがつながって動きます。

numbers.map(function (number) { ... });は、「numbersの各要素をnumberで受け取り、コールバック関数で変換する」と読めます。

returnした値から新しい配列が作られ、その結果を変数へ保存できます。
