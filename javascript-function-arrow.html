functionとアロー関数

functionを使った関数

functionを使うと、次のように関数を定義できます。

function greet() {
  console.log("こんにちは");
}

functionの後ろに関数名のgreetを書き、{ }の中に実行したい処理を書いています。

greet()と呼び出すと、「こんにちは」と表示されます。

アロー関数とは？

アロー関数は、functionを使う関数とは別の書き方です。

const greet = () => {
  console.log("こんにちは");
};

=>が矢印のように見えるため、「アロー関数」と呼びます。

この例では、アロー関数をgreetという名前へ入れています。

アロー関数の基本形 
() => {
  処理
}

()
→ 関数が受け取る値（仮引数）を書く場所。この例では何も受け取らないため空

=>
→ アロー関数で使う記号

{ }
→ 関数を呼び出したときに実行する処理を書く場所

まずは、この3つが並ぶ基本の形を覚えましょう。

同じ処理を2つの書き方で比べる

functionを使った関数

function greet() {
  console.log("こんにちは");
}

アロー関数

const greet = () => {
  console.log("こんにちは");
};

書き方は違いますが、どちらもgreet()と呼び出すと「こんにちは」と表示します。

書き方を1つずつ読む 
const greet = () => {
  console.log("こんにちは");
};

greet();

① const greet =
→ greetという名前へ、右側の関数を入れる

② () => {
→ アロー関数の開始

③ console.log("こんにちは");
→ 呼び出されたときに実行する処理

④ greet();
→ greetに入っているアロー関数を実行する

まずは両方の形を読めればよい

JavaScriptのコードでは、functionを使った関数とアロー関数の両方を見かけます。

function greet() { }
→ functionを使った関数

const greet = () => { };
→ アロー関数

今は、どちらも処理をひとまとまりにする関数だと読めれば大丈夫です。

アロー関数には処理が1行のときの省略記法などもありますが、このページでは基本形だけを使います。

確認問題 
const showMessage = () => {
  console.log("完了");
};

showMessage();

① この関数は、functionを使った関数とアロー関数のどちらですか？

② 関数名は何ですか？

③ 関数を呼び出している行はどこですか？

④ コンソールには何と表示されますか？

確認問題の答え

① アロー関数

② showMessage

③ showMessage();

④ 完了

=>が、アロー関数を見分ける目印です。

今回の学習ポイント

関数には、functionを使う書き方とアロー関数の書き方があります。

アロー関数の基本形は() => { }です。

まずは省略しない基本形で、それぞれの記号と処理のつながりを読みましょう。
