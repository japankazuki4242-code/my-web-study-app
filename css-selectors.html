セレクタ

セレクタとは？

セレクタは、CSSを適用するHTML要素を選ぶ部分です。

h1 {
  color: #333;
}

この例では、h1がセレクタです。

要素セレクタ 
h1 {
  font-size: 28px;
}

HTMLのタグ名をそのまま書き、同じ種類の要素を選びます。この例ではページ内の<h1>が対象になります。

classセレクタ

HTML：

<p class="message">こんにちは</p>

CSS：

.message {
  color: red;
}

HTMLではclass="message"、CSSではclass名の前に.を付けて.messageと書きます。

classは複数の要素で再利用できます。

複数のclassを付ける例：

<a class="btn signup">新規登録</a>
.btn {
  padding: 8px 24px;
}

.signup {
  background-color: #239b76;
}

共通の見た目を.btn、個別の見た目を.signupへ分けられます。

IDセレクタ

HTML：

<div id="page"></div>

CSS：

#page {
  width: 100%;
}

覚え方は、classが.、IDが#です。

同じid値は、同一ページ内で重複させません。

親要素の中から指定する 
header nav ul li a {
  color: black;
}
header
└─ nav
   └─ ul
      └─ li
         └─ a

セレクタを半角スペースで区切ると、親要素の内側にある要素へ対象を絞れます。

ただし、長いセレクタが必ず良いわけではありません。必要な範囲を読みやすく指定します。

複数の対象をまとめて指定する 
h1,
h2 {
  color: #333;
}

カンマで区切ると、複数の対象に同じCSSを指定できます。

header h1
→ headerの中のh1

h1, h2
→ h1とh2の両方

その他のセレクタ・優先順位 
div > p {
}

div + p {
}

div ~ p {
}

input[type="text"] {
}

>は直接の子、+は直後の要素、~は後に続く兄弟要素を選ぶ書き方です。属性セレクタは、特定の属性を持つ要素を選べます。

Version 1では、まずこのような指定方法があることを知れば十分です。

優先順位は、同じ要素に複数の指定が重なったとき、どのCSSが採用されるかというルールです。

制作ではcontainer・wrapper・inner・content・item・nav・menu・image・title・button・activeなどのclass名を見かけます。

button → btn、image → img、navigation → nav、previous → prev、favorite → favのように省略することもあります。

これらは必須ルールではありません。内容や役割が読み取れる名前を付けるための参考例です。
