イベント

イベントとは？

イベントは、Webページの中で「何かが起きたこと」です。

clickイベント
→ ボタンなどがクリックされた

inputイベント
→ 入力内容が変わるたびに発生

changeイベント
→ 値の変更が確定したときに発生

submitイベント
→ フォームが送信された

このページでは、まずclickイベントを中心に学びます。

JavaScriptが「クリックされたかな？」と繰り返し確認しているわけではありません。

「クリックされたら、この処理をしてね」とあらかじめ登録する
↓
ユーザーがクリックする
↓
登録しておいた処理が実行される

BACKボタンの例

BACKボタンをクリック
↓
clickイベントが起きる
↓
登録していた処理を実行
↓
前のページへ戻る

自由メモの例

保存ボタンをクリック
↓
clickイベントが起きる
↓
入力された文章を取得
↓
localStorageへ保存
↓
「保存しました」と表示

ここでは、保存の仕組みよりも、クリックをきっかけに処理が始まることを意識します。

イベントの基本的な流れ

イベントのコードは、「どの要素で」「何が起きたら」「何をするか」の3つに分けると読みやすくなります。

① HTML要素を見つける
↓
② その要素にイベントを登録する
↓
③ ユーザーが操作する
↓
④ イベントが起きる
↓
⑤ 登録しておいた処理が実行される

addEventListener()とは？

addEventListener()は、HTML要素へ「このイベントが起きたら、この処理を実行してね」と登録するためのメソッドです。

backButton.addEventListener("click", function () {
  history.back();
});

backButton
→ イベントを登録するHTML要素

.
→ 左側の要素が持っている機能へつなぐ記号

addEventListener()
→ イベントを登録するメソッド

"click"
→ どんなイベントが起きたら？

function () {
  history.back();
}

→ そのとき実行する処理

backButton.addEventListener()は、以前学んだ「オブジェクト名.メソッド名()」という形で読むことができます。

addEventListener()の中身

addEventListener("click", function () {
  // あとで実行する処理
});

1つ目の"click"
→ 何が起きたら？

2つ目のfunction () { ... }
→ そのとき何をする？

イベントとコールバック関数

addEventListener()では、イベントが起きたときに実行してほしい関数を渡します。

別の処理へ渡して、あとから呼び出してもらう関数をコールバック関数といいます。

backButton.addEventListener("click", function () {
  history.back();
});

この中の次の部分がコールバック関数です。

function () {
  history.back();
}

「あとから実行する」の流れ

「BACKボタンがクリックされたら、この関数を実行してね」と登録
↓
ユーザーがクリック
↓
clickイベントが起きる
↓
登録していたコールバック関数を実行
↓
history.back()を実行

ページを読み込んだときに、history.back()がすぐ実行されるわけではありません。

このfunction () { ... }は、名前を付けずにその場で書いているため、無名関数や匿名関数と呼ばれることもあります。

コールバック関数の詳しい仕組みや関数の細かな違いは、後の「関数・コールバック」ページで学びます。

このアプリで使っているイベント

1. BACKボタン

BACKボタンへclickイベントを登録し、クリックされたら前のページへ戻ります。

HTMLのid="back-button"
↓
JavaScriptで要素を取得
↓
clickイベントを登録
↓
ユーザーがクリック
↓
history.back()
↓
前のページへ戻る

実際のコードを見る

HTML：

<button type="button" id="back-button" class="nav-button">BACK</button>

JavaScript：

// HTMLからBACKボタンを取得します。
const backButton = document.getElementById("back-button");

// クリックされたときに前のページへ戻る処理を登録します。
backButton.addEventListener("click", function () {
  history.back();
});

2. Destyleのコピーボタン

コピーボタンへclickイベントを登録し、クリックされたことをきっかけにコピー処理を始めます。

コピーボタン
↓
clickイベントを登録
↓
ユーザーがクリック
↓
コピー処理
↓
「コピーしました」と表示

実際のコードを見る

HTML：

<pre><code id="destyle-cdn-code">&lt;link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css@4.0.1/destyle.min.css"&gt;</code></pre>

<button type="button" id="copy-destyle-button" class="nav-button copy-button">コードをコピー</button>
<p id="copy-status" class="copy-status" role="status" aria-live="polite"></p>

JavaScript：

// HTMLからコピーボタン・コード・結果表示を取得します。
const copyDestyleButton = document.getElementById("copy-destyle-button");
const destyleCdnCode = document.getElementById("destyle-cdn-code");
const copyStatus = document.getElementById("copy-status");

if (copyDestyleButton && destyleCdnCode && copyStatus) {
  // クリックされたときにコピーする処理を登録します。
  copyDestyleButton.addEventListener("click", function () {
    if (!navigator.clipboard) {
      copyStatus.textContent = "このブラウザではコピーできませんでした";
      return;
    }

    navigator.clipboard.writeText(destyleCdnCode.textContent)
      .then(function () {
        copyStatus.textContent = "コピーしました";
      })
      .catch(function () {
        copyStatus.textContent = "コピーできませんでした";
      });
  });
}

3. 自由メモの保存ボタン

保存ボタンへclickイベントを登録し、クリックされたら入力値の取得・保存・結果表示を行います。

保存ボタン
↓
clickイベントを登録
↓
ユーザーがクリック
↓
<textarea>の値を取得
↓
localStorageへ保存
↓
「保存しました」と表示

実際のコードを見る

HTML：

<textarea id="free-memo-input" class="free-memo-input" aria-label="自由メモ"></textarea>

<button type="button" id="save-free-memo-button" class="nav-button free-memo-save-button">保存</button>

<p id="free-memo-status" class="free-memo-status" aria-live="polite"></p>

JavaScript：

// アプリ全体の自由メモで共通して使用する保存キーです。
const freeMemoStorageKey = "my-web-study-app:free-memo";

// HTMLから自由メモの要素を取得します。
const freeMemoInput = document.getElementById("free-memo-input");
const saveFreeMemoButton = document.getElementById("save-free-memo-button");
const freeMemoStatus = document.getElementById("free-memo-status");

if (freeMemoInput && saveFreeMemoButton && freeMemoStatus) {
  // クリックされたときにメモを保存する処理を登録します。
  saveFreeMemoButton.addEventListener("click", function () {
    const freeMemoText = freeMemoInput.value;

    localStorage.setItem(freeMemoStorageKey, freeMemoText);
    freeMemoStatus.textContent = "保存しました";
  });
}

3つの共通点

BACKボタン・Destyleコピー・自由メモ保存は機能が違いますが、すべて同じイベントの仕組みで動いています。

ボタン
↓
click
↓
コールバック関数
↓
処理を実行

「どの要素で」「何が起きたら」「何をする」に分けると、機能が違っても同じ考え方でイベントコードを読めます。

これから学ぶこと

イベントの種類
→ click・input・change・submitなど

イベントを登録する
→ addEventListener()

コールバック関数
→ イベントが起きたときに、あとから実行される処理

フォーム・入力
→ <input>や<textarea>の値をイベントをきっかけに扱う

submitイベント
→ フォームが送信されたときの処理

イベントのコードを読むときは、「どの要素で → 何が起きたら → 何をする？」の3つに分けると理解しやすくなります。
