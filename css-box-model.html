余白・ボックスモデル

ボックスモデルとは？

HTML要素は、内容・内側の余白・境界線・外側の余白を持つ箱として考えられます。

margin
└─ border
   └─ padding
      └─ content

content
→ 文字や画像などの中身

padding
→ 境界線の内側の余白

border
→ 箱の境界線

margin
→ 境界線の外側の余白

margin と padding 
.box {
  margin: 20px;
  padding: 16px;
}

marginは他の要素との外側の間隔、paddingは内容と境界線の内側の間隔を作ります。

値を1〜4個書くとき

margin: 10px;
→ 上下左右

margin: 10px 20px;
→ 上下 / 左右

margin: 10px 20px 30px;
→ 上 / 左右 / 下

margin: 10px 20px 30px 40px;
→ 上 / 右 / 下 / 左

4つの値は、上から時計回りに読みます。paddingも同じ順番です。

border 
.box {
  border: 1px solid black;
}

1px
→ 線の太さ

solid
→ 線の種類

black
→ 線の色

borderは上下左右に付く

border: 1px solid black;を指定すると、上下左右の4辺に同じ線が付きます。

top → 1px
right → 1px
bottom → 1px
left → 1px

全体で合計1pxという意味ではなく、上下左右それぞれの境界線の太さが1pxです。

1辺だけ指定できる

.box {
  border-top: 1px solid black;
}

top → 1px
right → なし
bottom → なし
left → なし

border-top・border-right・border-bottom・border-leftを使うと、4辺を個別に指定できます。

.box {
  border-top: 1px solid black;
  border-right: 1px solid black;
  border-bottom: 1px solid black;
  border-left: 1px solid black;
}

<hr>との違い

<hr>
→ HTMLで内容・話題の区切りを表す

border / border-top
→ CSSで要素に線・枠線という見た目を付ける

横線のような見た目が似る場合はありますが、HTMLの<hr>とCSSのborderでは役割が違います。

box-sizing: border-box 
* {
  box-sizing: border-box;
}

border-boxを指定すると、指定したwidthやheightの内側にpaddingとborderを含めて計算します。

paddingやborderを追加したときのサイズを考えやすくなります。

margin: 0 auto 
.container {
  max-width: 700px;
  margin: 0 auto;
}

0
→ 上下のmargin

auto
→ 左右のmarginを自動計算

横幅やmax-widthが決まったブロック要素を、左右中央へ配置するときによく使います。何でも自動的に中央になる指定ではありません。

実際に使った例

Black Coffeeでは、ABOUT部分に内側の余白を作り、内容の横幅を制限して中央へ配置しています。

main .about {
  padding: 30px;
}

main .about .container {
  width: 100%;
  max-width: 700px;
  margin: 0 auto;
}

Progate模写では、全要素にbox-sizing: border-box;を指定しています。

* {
  box-sizing: border-box;
}
