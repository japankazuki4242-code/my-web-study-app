input・changeイベント

inputイベントとは？

inputイベントは、入力内容が変わるたびに発生します。

文字を入力したり削除したりするたびに、その時点の入力値を使って処理できます。

nameInput.addEventListener("input", function () {
  console.log(nameInput.value);
});

この例では、入力内容が変わるたびにnameInput.valueで現在の値を取得し、コンソールへ表示します。

changeイベントとは？

changeイベントは、値の変更が確定したときに発生します。

文字入力欄では、内容を変更してから入力欄の外へ移動したときなどに発生します。

nameInput.addEventListener("change", function () {
  console.log(nameInput.value);
});

この例では、値の変更が確定したときにnameInput.valueで現在の値を取得し、コンソールへ表示します。

inputとchangeの違い
イベント 発生するタイミング
input 入力内容が変わるたび
change 値の変更が確定したとき

入力中にすぐ反応させたい場合はinput、変更が確定したときに処理したい場合はchangeを使います。

HTML要素を見つけてイベントを登録する

イベントを登録する前に、HTMLの入力欄をJavaScriptで見つけます。

HTML：

<input id="user-name" type="text">

JavaScript：

const nameInput =
  document.getElementById("user-name");

nameInput.addEventListener("input", function () {
  console.log(nameInput.value);
});

nameInput.addEventListener("change", function () {
  console.log(nameInput.value);
});

nameInput
→ HTMLから見つけた入力欄

addEventListener()
→ 入力欄にイベントを登録するメソッド

nameInput.value
→ 入力欄の現在の値

イベント処理の流れ

入力値をイベントに合わせて取得する流れは、次のとおりです。

HTML要素を見つける
↓
addEventListener()でイベントを登録
↓
ユーザーが入力
↓
inputまたはchangeイベントが発生
↓
.valueで現在値を取得
↓
取得した値を使って処理する

イベント学習とのつながり

inputとchangeも、既存の「イベント」ページで学んだaddEventListener()を使って登録します。

click
→ 要素がクリックされたとき

input
→ 入力内容が変わるたび

change
→ 値の変更が確定したとき

イベント名は違っても、「どの要素で → 何が起きたら → 何をする」という基本の読み方は同じです。
