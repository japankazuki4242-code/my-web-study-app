submitイベント

submitイベントとは？

submitイベントは、<form>が送信されたときに発生するイベントです。

フォーム送信時の処理は、送信ボタンだけではなく、<form>へsubmitイベントを登録するのが基本です。

HTMLの基本形 
<form id="contact-form">
  <input id="user-name" type="text">
  <button type="submit">送信</button>
</form>

<form>の中に入力欄と送信ボタンを入れています。

type="submit"のボタンは、フォームを送信するためのボタンです。

JavaScriptの基本形 
const contactForm =
  document.getElementById("contact-form");

contactForm.addEventListener("submit", function () {
  // フォーム送信時の処理
});

getElementById("contact-form")でフォームを見つけ、contactFormという変数へ入れています。

addEventListener("submit", ...)で、フォームが送信されたときの処理を登録しています。

clickとsubmitの違い
イベント 発生するタイミング
click 要素がクリックされた
submit <form>が送信された

clickは、ボタンなどの要素がクリックされたことを扱います。

submitは、フォームが送信されたことを扱います。

formへ登録する理由

フォームは、送信ボタンのクリック以外の操作でも送信されることがあります。

そのため、フォーム送信時の処理は、ボタンのclickイベントではなく、<form>のsubmitイベントとして登録するのが基本です。

<form>
↓ submitイベントを登録
ユーザーがフォームを送信
↓
登録した処理を実行

処理の流れ

① HTMLに<form>を作る
↓
② フォームへidを付ける
↓
③ getElementById()でフォームを見つける
↓
④ addEventListener()でsubmitイベントを登録する
↓
⑤ ユーザーがフォームを送信する
↓
⑥ 登録しておいた処理が実行される
