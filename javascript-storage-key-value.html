keyとvalueとは？

localStorageは、keyとvalueをセットにしてデータを保存します。

key
→ 保存する場所の名前

value
→ その場所へ保存する中身

どの場所に、どの中身を保存するのかを2つセットで指定します。

名前を書いた引き出しのイメージ

localStorageは、名前を書いた引き出しにデータを入れるようなイメージです。

引き出しに書かれた名前
→ key

引き出しの中へ入れるもの
→ value

後からkeyを使って引き出しを探すと、その中に保存したvalueを読み出せます。

基本の例 
localStorage.setItem("userName", "かず");
書き方 役割
"userName" 保存する場所の名前であるkey
"かず" 保存する中身であるvalue

この例では、"userName"という名前の場所へ、"かず"という文字を保存しています。

このアプリの自由メモのkey

このアプリでは、自由メモ用のkeyを次のように変数へ入れています。

const freeMemoStorageKey =
  "my-web-study-app:free-memo";

"my-web-study-app:free-memo"が、自由メモを保存する場所の名前であるkeyです。

freeMemoStorageKeyという変数を使うことで、保存するときも読み出すときも同じkeyを指定できます。

keyとvalueをセットで考える

localStorageで大切なのは、keyとvalueをセットで考えることです。

① keyで保存する場所に名前を付ける
↓
② その場所へvalueを保存する
↓
③ 同じkeyを使ってvalueを読み出す

keyが違うと別の保存場所になるため、保存時と読み出し時には同じkeyを使います。
