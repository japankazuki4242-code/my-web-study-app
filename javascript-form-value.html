入力された値を取得する

HTMLに入力欄を作る

まず、HTMLで名前を入力するための入力欄を作ります。

<input id="user-name" type="text">

id="user-name"は、JavaScriptからこの入力欄を見つけるための目印になります。

JavaScriptで入力欄を見つける

document.getElementById()を使い、HTMLのidから入力欄を見つけます。

const userNameInput =
  document.getElementById("user-name");

HTMLのid="user-name"
↓ 同じ名前でつながる
JavaScriptのgetElementById("user-name")

userNameInputには、入力された文字ではなく、HTMLの<input>要素そのものが入ります。

.valueで入力値を取得する

入力欄に現在入力されている値は、.valueで取得できます。

const userName =
  userNameInput.value;

userNameInput.valueで取得した値を、userNameという変数へ保存しています。

たとえば入力欄に「山田太郎」と入力されていれば、userNameには文字列の「山田太郎」が入ります。

3つの名前の違い
書き方 表しているもの
userNameInput HTMLの<input>要素そのもの
userNameInput.value 入力欄に現在入力されている値
userName 取得した値を保存する変数

要素を入れる変数と、入力値を入れる変数を分けて考えると、コードの流れを追いやすくなります。

コードを書く順番

入力値を取得するときは、次の順番で考えます。

① HTMLに入力欄を作る

② 入力欄にidを付ける

③ getElementById()で入力欄を見つける

④ 見つけたHTML要素を変数へ入れる

⑤ .valueで現在の入力値を取得する

⑥ 取得した値を使って処理する

HTML：

<input id="user-name" type="text">

JavaScript：

const userNameInput =
  document.getElementById("user-name");

const userName =
  userNameInput.value;
