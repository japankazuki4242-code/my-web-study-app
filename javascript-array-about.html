配列とは？

学習目標

配列は、複数の値を順番にまとめて扱う仕組みです。

このページでは、値を1つずつ別の変数へ入れる場合と、配列へまとめる場合の違いを確認します。

配列を使わない場合

3つの果物を別々に管理するときは、次のように3つの変数が必要です。

const fruit1 = "りんご";
const fruit2 = "みかん";
const fruit3 = "バナナ";

fruit1・fruit2・fruit3へ、果物の名前を1つずつ入れています。

値が増えるたびに変数も増えるため、複数の値が1つのまとまりだと分かりにくくなります。

配列を使う場合

配列を使うと、3つの果物を次のように1つへまとめられます。

const fruits = ["りんご", "みかん", "バナナ"];

fruitsという1つの変数で、「りんご」「みかん」「バナナ」をまとめて管理しています。

角括弧[ ]の中に、まとめたい値をカンマ,で区切って書きます。

配列にまとめる良さ

配列を使うと、関係のある複数の値を1つのまとまりとして扱えます。

配列を使わない場合
fruit1・fruit2・fruit3という別々の変数で管理する

配列を使う場合
fruitsという1つの変数でまとめて管理する

「果物の一覧」のように、同じ目的で使う値をまとめたいときに便利です。

要素と順番

配列の中にある1つ1つの値を「要素」と呼びます。

const fruits = ["りんご", "みかん", "バナナ"];

"りんご"
→ 1つ目の要素

"みかん"
→ 2つ目の要素

"バナナ"
→ 3つ目の要素

配列には左から右への順番があります。この順番を使った値の指定方法は、後の「要素とインデックス」で学びます。

今回の学習ポイント

配列は、複数の値を1つの長い文字列にするものではありません。1つ1つの値を要素として分けたまま、順番にまとめる仕組みです。

このページでは、次の4点を覚えておきましょう。

  • 複数の値を1つにまとめられる
  • 1つの変数で管理できる
  • 1つ1つの値を要素と呼ぶ
  • 配列には順番がある

要素の番号や要素数の調べ方は、後のページで確認します。
