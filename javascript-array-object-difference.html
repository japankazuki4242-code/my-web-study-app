配列とオブジェクトの違い

配列とオブジェクトを比べる

配列

const userArray = ["かず", 50];

オブジェクト

const userObject = {
  name: "かず",
  age: 50
};

どちらも名前と年齢をまとめていますが、データを管理する方法が違います。

配列は順番で管理する 
const userArray = ["かず", 50];

配列は、値を順番で管理します。値を指定するときは、0から始まるindexを使います。

userArray[0]

→ 配列のindex 0にある要素を見る
→ 結果は"かず"

オブジェクトは項目名で管理する 
const userObject = {
  name: "かず",
  age: 50
};

オブジェクトは、値を意味のある項目名で管理します。値を指定するときは、プロパティ名を使います。

userObject.name

→ オブジェクトのnameプロパティを見る
→ 結果は"かず"

管理方法と取り出し方の違い
配列 オブジェクト
順番で管理する 項目名で管理する
indexを使う プロパティ名を使う
userArray[0] userObject.name

順番で値を選ぶのが配列、意味のある項目名で値を選ぶのがオブジェクトです。

配列の中にオブジェクトを入れた例 
const users = [
  { name: "かず", age: 50 },
  { name: "太郎", age: 30 }
];

usersは配列です。その配列の各要素として、ユーザー情報をまとめたオブジェクトが入っています。

配列とオブジェクトを組み合わせた場合も、左から順番にたどると読みやすくなります。

users[1].nameを順番に読む 
users[1].name

users
→ 配列

[1]
→ index 1の要素

{ name: "太郎", age: 30 }
→ index 1に入っているオブジェクト

name
→ プロパティ名

"太郎"
→ 最後に取り出される値

確認問題 
users[1].name

① usersは何ですか？

② [1]は何を指定していますか？

③ nameは何ですか？

④ 最後に取り出される値は何ですか？

確認問題の答え

users
→ 配列

[1]
→ index 1の要素を指定

name
→ プロパティ名

結果
→ "太郎"

今回の学習ポイント

配列
→ 順番で管理し、indexで値を指定する

オブジェクト
→ 項目名で管理し、プロパティ名で値を指定する

配列の中にオブジェクトがある場合は、「配列 → indexの要素 → オブジェクト → プロパティ」と1段ずつたどりましょう。
