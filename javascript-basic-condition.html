if・elseと比較・論理演算子

trueとfalse

条件式を確認した結果は、trueまたはfalseになります。

true
→ 条件が成り立つ

false
→ 条件が成り立たない

20 >= 18

20は18以上なので、この条件式の結果はtrueです。

if文とは？

if文は、条件がtrueのときだけ、波括弧{ }の中の処理を実行します。

const age = 20;

if (age >= 18) {
  console.log("18歳以上です");
}

age >= 18はtrueなので、「18歳以上です」と表示されます。

if文を分けて読む

if
→ 条件によって処理を分ける

(age >= 18)
→ 確認する条件式

{
→ 条件がtrueのときに実行する処理の始まり

console.log("18歳以上です");
→ 条件がtrueなら実行する

}
→ 処理の終わり

elseを使う

elseを使うと、if文の条件がfalseだったときの処理を書けます。

const age = 16;

if (age >= 18) {
  console.log("18歳以上です");
} else {
  console.log("18歳未満です");
}

age >= 18はfalseなので、elseの処理が実行されます。

else ifで条件を追加する

else ifを使うと、最初の条件がfalseだったときに、次の条件を確認できます。

const score = 75;

if (score >= 80) {
  console.log("評価A");
} else if (score >= 60) {
  console.log("合格");
} else {
  console.log("再挑戦");
}

条件は上から順番に確認され、最初にtrueになった部分の処理だけが実行されます。

実行される順番を確認する

scoreの値が75の場合を、上から順番に読みます。

① score >= 80
→ 75は80以上ではない
→ false

② score >= 60
→ 75は60以上
→ true

③ 「合格」と表示する

1つの条件がtrueになったため、その後のelseは実行されません。

比較演算子

比較演算子は、左側と右側の値を比べ、結果をtrueまたはfalseにします。

書き方 意味
< 左側が右側より小さい
<= 左側が右側以下
> 左側が右側より大きい
>= 左側が右側以上
=== 値とデータの種類が同じ
!== 値またはデータの種類が同じではない

20 === 20
→ true

20 === "20"
→ 数値と文字列でデータの種類が違うためfalse

=は代入、===は比較に使います。役割を区別しましょう。

&&で2つの条件を両方確認する

&&は、左右の条件が両方ともtrueのとき、全体がtrueになります。

const age = 20;
const hasTicket = true;

if (age >= 18 && hasTicket === true) {
  console.log("入場できます");
}

age >= 18とhasTicket === trueが両方とも成り立つため、処理が実行されます。

||でどちらかの条件を確認する

||は、左右の条件のどちらか一方でもtrueなら、全体がtrueになります。

const day = "日";

if (day === "土" || day === "日") {
  console.log("休日です");
}

day === "日"が成り立つため、「休日です」と表示されます。

確認問題 
const temperature = 25;

if (temperature >= 30) {
  console.log("暑いです");
} else if (temperature >= 20) {
  console.log("過ごしやすいです");
} else {
  console.log("寒いです");
}

① 最初に確認する条件は何ですか？

② どの処理が実行されますか？

確認問題の答え

① temperature >= 30

② 最初の条件はfalse、次のtemperature >= 20はtrueなので、「過ごしやすいです」と表示されます。

今回の学習ポイント

ifは条件がtrueのときに処理を実行します。

else ifで次の条件、elseでどの条件にも当てはまらなかった場合の処理を書けます。

条件は上から順番に、比較演算子や&&・||を1つずつ読みましょう。
