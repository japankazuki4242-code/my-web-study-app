<form>

何をするタグ？

<form>は、ユーザーに情報を入力してもらう入力欄やボタンなどをまとめる、フォーム全体の親となるタグです。

<form>だけでは通常、中身は完成しません。<label>・<input>・<textarea>・<select>・<button>などを組み合わせます。

HTMLだけで、入力データの保存やメール送信まで必ず完成するわけではありません。実際の処理にはサーバー側などの仕組みが必要です。

基本の書き方

フォーム全体の親子構造：

<form>
├─ <label> ── 入力欄が何の項目かを示す
├─ <input> ── 1行入力など
├─ <label>
├─ <textarea> ── 複数行の文章入力
├─ <label>
├─ <select> ── 選択肢全体
│   ├─ <option> ── 1つの選択肢
│   └─ <option>
├─ <fieldset> ── 関連する入力項目をまとめる
│   ├─ <legend> ── グループが何かを示す
│   └─ 入力項目
└─ <button> ── 送信などの操作

完成したお問い合わせフォームの学習例：

<!-- HTMLのフォーム開始タグ -->
<form action="#" method="post">
  <!-- 一行テキスト -->
  <div>
    <label for="name">お名前：</label>
    <input type="text" id="name" name="user_name" required>
  </div>

  <!-- メールアドレス -->
  <div>
    <label for="email">メールアドレス：</label>
    <input type="email" id="email" name="user_email" required>
  </div>

  <!-- セレクトボックス -->
  <div>
    <label for="category">お問い合わせ種別：</label>
    <select id="category" name="category">
      <option value="service">サービスについて</option>
      <option value="price">料金について</option>
      <option value="other">その他</option>
    </select>
  </div>

  <!-- 複数行テキスト -->
  <div>
    <label for="message">お問い合わせ内容：</label>
    <textarea id="message" name="user_message" rows="5"></textarea>
  </div>

  <!-- 送信ボタン -->
  <button type="submit">送信する</button>
</form>

action="#"は学習用の仮の送信先で、これだけで本物の送信機能は完成しません。method="post"は送信方法の1つです。

for="name"とid="name"がlabelと入力欄を関連付けます。name="user_name"は送信時のデータ名です。

requiredは入力必須をブラウザに伝える、値を書かずに使えるboolean属性です。

属性名・属性値の例 
<form action="#" method="post">
  ...
</form>

action
→ 送信先。ここでの#は学習用の仮指定です。

method
→ 送信方法。基本としてgetとpostがあります。

getは送信内容がURLに含まれる方法、postは送信内容をリクエストの本文に含める方法です。Version 1では違いを高度に掘り下げません。

よく使う場面

<form>は、ユーザーから情報を受け取る画面に使います。

  • お問い合わせ
  • ログインや会員登録
  • 検索
  • アンケートや申込み

idはHTML内で要素を識別したりlabelと関連付けたりするために使えます。

nameは、フォーム送信時に値が何のデータかを識別する名前です。同じ役割ではありません。

お問い合わせフォームをページの主要な内容として扱う場合は、<main>内の<section>に置く形が基本例の1つです。

<body>
  <header>
    ...
  </header>

  <main>
    <section>
      <h2>お問い合わせ</h2>
      <form>
        ...
      </form>
    </section>
  </main>

  <footer>
    ...
  </footer>
</body>

<main>内のお問い合わせフォームはページの主要コンテンツ、<footer>はコピーライト・補助リンク・会社情報など、ページ末尾の補足情報をまとめる役割があります。

画面の下の方に表示されることと、HTMLで<footer>の中に入れることは同じ意味ではありません。

デザイン上はフォームをページ下部やfooterの直前に配置することもありますが、「ページ下部にあるからfooterに入れる」とは判断しません。HTML要素は内容の意味や役割で選びます。

フォームを必ずmain内に置くという断定ではありません。サイトの構造やフォームの役割に応じて適切な位置は変わります。
