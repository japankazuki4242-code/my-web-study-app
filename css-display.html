Display・横並び

displayとは？

displayは、要素をどのような箱として表示するかを指定します。

Version 1では、block・inline・inline-block・noneを中心に学びます。

block 
.box {
  display: block;
}

block要素は新しい行から始まり、基本的に利用できる横幅へ広がります。

width・height・余白などを指定できます。

inline 
.text {
  display: inline;
}

inline要素は、文章の一部分のように横へ並びます。

block要素と同じ感覚ではwidthやheightを指定できません。

inline-block 
.btn {
  display: inline-block;
  padding: 8px 24px;
}

inline-blockは、横へ並びながら、width・height・paddingなどを扱いやすい表示方法です。

display: none 
.menu {
  display: none;
}

display: none;を指定すると、要素が非表示になり、レイアウト上からも取り除かれます。

opacity: 0;は透明になりますが、要素があった領域は残ります。

float と clear

Progate模写では、4つのレッスンを横並びにするためにfloatを使っています。

.lesson {
  float: left;
  width: 25%;
}

float: left;で左へ寄せ、width: 25%;で4つ分の横幅にしています。

.clear {
  clear: left;
}

clearは、floatによる回り込みの影響を解除するために使います。

現在の単純な横並びではFlexboxやGridを使うことも多いですが、この教材のfloatによる実装も横並びを作る方法の1つです。

実際に使った例

Black Coffeeの予約ボタンは、リンクをinline-blockにして余白や境界線を指定しています。

aside .btn {
  display: inline-block;
  padding: 20px 80px;
  border: 5px solid black;
}

Progate模写でも、共通のボタンclassへinline-blockを指定しています。

.btn {
  padding: 8px 24px;
  display: inline-block;
}

狭い画面では、通常メニューとメニューアイコンの表示を切り替えています。

.header-right {
  display: none;
}

.menu-icon {
  display: block;
}
